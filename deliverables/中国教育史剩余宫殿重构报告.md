## 二、处理方式

- 保留原导图的语义层级，不强行改写成另一套分类；只做“清洗 + 拆卡 + 补考点”。
- HTML 高亮转为 Memory Anki 的 `data-emphasis="highlight"`；旧 `richText` 不再保留。
- 长段按句号、分号、逗号、顿号拆成短卡；冒号标签统一拆父子。
- 删除列表编号、占位节点（“新节点”）、“以下几个方面”“主要表现在”等过渡句、纯评价性套话。
- 保留所有题目绑定节点的原 uid；新拆出的节点使用 `new-<hash>`。
- 题目绑定节点与原始高亮节点自动高亮；**每个题目绑定节点都打标签**：绑定 ≥2 题 → `[高频考点]`，绑定 1 题 → `[解题关键]`，含“易错/区别/注意/混淆” → `[易错点]`（优先）。根节点不打标签。
- 20 宫共 267 个标签：`[高频考点]` 86、`[解题关键]` 155、`[易错点]` 26；连同第五章 84/263/85/86，四个既有宫殿与本轮 20 宫合计 404 个标签（137 / 221 / 46）。所有非根绑定节点均已覆盖，零漏标。
