# 考研备考工具：背景介绍（补充翻卡流程与随心模式）

我是一名考研备考者，自己在用一款自制的学习工具备考。下面是我为这次讨论准备的全部背景，数字都来自我本机的真实数据。请先完整读完，再按最后一节的要求回答。

> 说明：这次我在原来的基础上补了两块最核心的交互——**翻卡流程**（第三节）和**随心模式**（第五节），并顺手校正了两处与当前实现不一致的旧描述（做题范围和「冲刺模式」的叫法）。

## 一、我在准备什么

2027 考研，初试日期 2026-12-20（距离现在约 7 周）。

专业课是 333 教育综合，四门：中国教育史、外国教育史、教育学原理、教育心理学。这四门在工具里共 3959 道题。

另外还在准备 **政治（101 思想政治理论）**，题库 2564 道题；以及 **843**（374 道）和两门科学教育科目「科学教育与科学传播概论」「科学教育研究方法」（136 + 218 道）。

工具里已经打开「冲刺模式」：复习间隔不会被排到考试之后，只会把卡往考前拉；本该排到考后的卡会提前到考前最后一周，并按单元错开，不会全堆在考前一天。

## 二、这个工具是什么

Memory Anki 是我个人自用的「记忆宫殿 + 间隔重复 + 做题」工具，本地运行，单用户，没有云端，不对外提供服务。它有三个核心概念：

### 1）宫殿 = 一张思维导图

每座宫殿对应教材的一节或一个专题，导图节点是知识点，可以带备注、重点高亮。目前有 210 座宫殿。

### 2）复习单元 = 用「永久标记」在导图上切出来的知识块

一个永久标记连同它下游的节点构成一个独立单元，一个单元就是一张复习卡，独立排期。一座宫殿通常被切成 3–6 个单元。目前全库有 310 个活跃复习单元。

### 3）题库 = 挂在宫殿（并绑定到导图节点）上的题目

每道题属于一座宫殿，同时可绑定一个或多个导图节点，用来实现「做题时能跳回知识点」「在导图上看到这个节点有几道题」。全库共 7251 道题：客观题（选择题）5517 道，主观题（简答）1734 道。

### 做题和复习是两套独立的东西

- **复习**：打开一张单元卡 → 在脑图上翻卡回忆 → 点「忘记 / 困难 / 记得 / 轻松」，改变这张卡的复习间隔。
- **做题**：在复习卡片上点工具栏「做题」，弹出题目，逐题作答，答完显示对错和解析，可以标记题目。答题进度只在本轮内保存，**不影响复习排期**。

> 校正一处旧描述：现在「做题」默认的出题范围**不是整座宫殿**，而是「本轮已排期的复习单元，加上从宫殿根到该单元永久标记的整条路径」；只有主动在「出题范围」页打开「整个宫殿」，才会抽全宫的题。这个设计是为了让做题和这一轮实际复习过的内容对齐。

## 三、翻卡流程：一张卡是怎么「想」出来的

这是整个工具里最核心、也最容易被外人误解的交互。它的目的不是「展示答案」，而是**强制先回忆、再揭示**。

### 3.1 三种卡片状态

脑图上的每张知识卡只有三种状态：

| 状态 | 看到什么 | 含义 |
|---|---|---|
| 隐藏 | 画布上根本没有这张卡 | 还没走到这一层 |
| 待回忆 | 卡片轮廓出现，正文只写「待回忆」，备注和重点高亮都藏起来 | 知道这里有个知识点，但还没翻 |
| 已揭示 | 完整正文、备注、黄色重点高亮全部显示 | 翻开了 |

根节点永远可见，作为整张脑图的上下文。也就是说，**隐藏不是把内容打码，而是整张卡不出现**——所以翻卡的过程是脑图一层一层「长出来」的过程。

### 3.2 一次翻卡到底发生了什么

有两种揭示方式，在「翻卡设置」里切换：

- **两阶段（默认）**：第一次操作只让下一层卡片以「待回忆」出现；再操作一次，这些卡片才一起翻出正文。它的价值是留出「先自己回想」的时间，而不是一眼看到答案。
- **直接显示**：没有待回忆阶段，一次操作直接出内容。适合快速过已经熟悉的内容。

还有两种颗粒度：

- **同层批量（默认）**：一次把这一层所有待翻的卡片一起处理。
- **逐张**：一次只处理这一层里的第一张。

翻卡的推进是**按层级**的：点一张已经揭示的卡，它下面「下一层还没翻的卡」才会出现；再点一次，这一层一起翻出内容；然后才轮到更下一层。所以一张 20 个节点的卡，通常不是点 20 次，而是按层点——比如 3 层，每层「出现一下、揭示一下」，大约 6 次就翻完了。

### 3.3 鼠标/触屏与键盘，是两条不同的翻卡路径

- **点击**：指哪翻哪。点「待回忆」的卡 → 揭示这张；点「已揭示」的卡 → 推进它下面的下一层。
- **Enter（翻卡）**：沿着**当前复习单元的锚点**往下翻。如果锚点上面的路径还没翻，会先自动补齐路径，再翻锚点这一层。连续按 Enter 就是一层一层往下走。这是为纯键盘学习设计的。
- **Backspace（收卡）**：把当前锚点以下全部折起，锚点本身回到该模式规定的状态——两阶段回到「待回忆」，直接显示回到「隐藏」。快速连按 Enter 产生的未处理翻卡会被丢弃，所以收卡之后不会又被上一帧的 Enter 弹开。
- **Shift+H**：隐藏子级知识点（和右键菜单里的「隐藏子级」同款），它只是把子卡收起来，不等于「收卡」。
- 手机上另有一套导引条：**上级 / 下一个 / 揭示 / 全局**，四个大按钮；随心模式的紧凑布局则没有这一排，直接点节点翻，翻页用右侧按钮。

### 3.4 翻卡进度徽标

单元标题旁边有一个 `已翻/需翻` 的计数徽标，只统计**这个复习单元的成员节点加上它的锚点**。0 张是红色，部分翻是黄色，全部翻完是绿色。它回答的是「这个单元我翻到哪了」，不是「我记住了多少」。

注意：在随心的「随心模式」可翻范围下，整座宫殿的节点都能翻，但徽标仍然只数本单元——因为评分范围只作用于本单元。

### 3.5 翻卡不写排期，也不跨访问记忆

- 翻卡**不是评分**。翻完不会自动记「记得」，也不会改变间隔；评分必须自己点 1–4。
- 翻卡进度只属于**这次打开这张卡**。不写本地存储、不进数据库、不参与跨设备同步。关掉重开、换一轮、换一张卡，都从全部折叠重新开始。
- 这样设计是为了避免「上次翻到哪」污染这一次的回忆判断，也避免两台设备互相覆盖一个纯本地的阅读状态。

### 3.6 翻卡和编辑的关系

- 双击空白画布进入编辑；再双击（或点「返回学习」）回到复习。
- 编辑范围可选「当前专线」或「整座宫殿」。
- 进入编辑时，脑图只展开到当前翻卡进度：翻到过的分支打开，没翻到的分支保持折叠。所以编辑看到的是「翻卡进度 + 可编辑结构」，不是整座宫殿摊开。
- 复习 ↔ 编辑来回切换，翻卡进度保留；但在编辑里改卡、删卡不会重新套用翻卡进度。
- 节点上如果挂了题目卡，父节点被揭示时，题目正文会自动翻出来。

### 3.7 手感与无障碍

翻卡有声音反馈（90ms 限速，避免快速翻卡变成噪音）和果冻式回弹动画；尊重系统的「减少动态效果」设置。没有粒子、没有 canvas 特效。

### 3.8 键盘总表（可改，但默认是这样）

| 键 | 作用 |
|---|---|
| Enter | 翻卡（沿单元锚点） |
| Backspace | 收卡 |
| Shift+H | 隐藏子级 |
| ↑ / ↓ | 上一张 / 下一张（可改） |
| PageUp / PageDown、← / → | 固定翻页，不能被翻卡占用 |
| 空格 | **不翻页**，它是编辑器里的输入字符 |
| W / A / S / D | 固定平移画布，不能绑定翻卡 |

编辑器打开时（哪怕焦点已经跑出输入框），所有翻页、翻卡、评分键都会暂停——这是之前「编辑到一半空格把卡翻过去」的根因修复。卡片激活时会主动释放按钮焦点，保证 Enter 归卡片，而不是又触发一次「下一张」。

## 四、复习是怎么走的

排期用 FSRS，目标记忆率 90%，最长间隔 365 天。

新卡只有两次固定闹钟：当天 20 分钟复查 → 第 2 天隔夜检验 → 点「记得」+3 天、「轻松」+5 天，然后完全交给算法（首次就点「轻松」可以跳过 20 分钟复查，直接 +3 天）。

之后一次「记得」大约按 3 天 → 7 天 → 17 天 → 更长 的速度拉开；间隔达到 30 天、60 天、120 天时，同一座宫殿会被反复打开，但每次只打开其中一个单元。

间隔 ≥7 天时会有 ±5% 的抖动，避免同一天学的卡永远同一天到期。

关键矛盾在这里：复习是按「单元」打开的，间隔会越来越长；但做题抽的是题目池。于是一座 129 道题的宫殿，复到第三、第四遍时，你面对的还是同一批题。（现在默认题池已收窄到本轮单元及其根路径，但同一单元反复复习时，题池本身仍然不变。）

## 五、随心模式：把「今天要复习的东西」排成一条流

如果说翻卡是「一张卡内部怎么学」，随心就是「一天之内先学哪张、后学哪张」。

### 5.1 它是什么

随心是工具里唯一的沉浸式学习工作区：**一次只显示一张卡**，上下滑动/按键翻页，像一条信息流。它同时承载复习单元卡、做题卡、重练卡和睡前复习卡。

### 5.2 和「正式复习」是什么关系

不是两个系统。复习书架上的「立即复习」打开的是**同一条随心信息流，只是把范围锁定到那一座宫殿**；宫殿编辑器里的「开始随心复习」也是进入同一条流。旧版单独的复习页面已经不存在了。所以：**正式复习 = 随心信息流 + 单宫殿锁定**，评分、翻卡、结算全部共用同一套。

### 5.3 开始页

每天第一次进入先看到概览：

- **待复习**：N 座宫殿 / M 个单元
- **第一次学**：N 座宫殿 / M 个单元
- **近期里程碑**：倒计时和最近要完成的事
- **昨天的回顾**：昨天学了哪些宫殿/单元，以及当时评为「忘记/困难」的薄弱单元
- 下方是队列配置预览：训练方向（记忆宫殿 / 做题 / 混合）、学科标签、宫殿范围、队列长度、随机或顺序；点「开始学习」进入信息流。

### 5.4 队列怎么组

- 复习侧只取**今天真正到期的复习单元**，没有每日配额，也不做「积压释放」——到期集合就是整块。
- 做题侧可以独立成流，也可以按比例或顺序和复习单元交错（比如 2:1）。
- 队列构建顺序可以是「一座宫殿刷完再换下一座」，也可以是交错；单元顺序可以按宫殿自身的深度优先顺序，也可以随机。
- **忘记**产生的重练会插入当前卡之后，不占原始队列位置。
- 刷新、重启、次日重开都会恢复**同一个轮次**（同一个 `round_id`），不会重新洗牌；只有显式点「再来一轮」才会铸新轮。

### 5.5 四种卡片

1. **复习单元卡**：脑图 + 单元标题 + 翻卡进度徽标 + 底部 1–4 评分坞。这是主力。
2. **做题卡**：题干、选项、对错、解析、标记；没有 1–4 评分，不影响复习排期。
3. **重练卡**：琥珀色，角标数字是「本轮第几次重练」。
4. **睡前复习卡**：进度条上有月亮标记，详见 5.10。

### 5.6 一张卡的界面

从上到下：

- **顶部 HUD**：一条 20px 的进度细线（每刻度一张卡）、当前宫殿和轮次（如 29/55）、倒计时和最近里程碑。
- **进度条**：每根刻度是一张卡，颜色是宫殿色；淡色=未完成，实心=本轮已评分；「今天」有一条分隔线；琥珀圆点=重练；月亮=睡前复习。点刻度直接跳到那张卡。
- **脑图工具栏**：做题、英语、文字、翻卡设置、全屏等。
- **单元身份行**：单元标题 + 翻卡进度徽标。
- **脑图本体**：翻卡在这里发生。
- **底部评分坞**：忘记 / 困难 / 记得 / 轻松。
- **右侧翻页器**：上一张 / 下一张 / 完成，垂直居中；其上方是月亮按钮。

### 5.7 评分规则

- **忘记**：不通过，创建一个重练，10 分钟后、再 1 小时后、再 3 小时后各可再出现一次（每个学习日至多 3 次）。源卡片不会立刻前进，要等你离开这张卡。
- **困难**：算通过，但间隔被压短（约为上次间隔的 0.8–1.0 倍，绝不拉长）。
- **记得 / 轻松**：通过。
- 再点一次当前已选中的分数 = 撤销，回到未评分。
- 评分是**先上屏、再保存**：点了立刻有反馈；保存失败会保留选中状态并明确提示「未保存」，再点一次重试，不会假装已通过。
- 评分默认**停在原卡**，不自动翻页；想要「评完自动去下一张」可以在翻卡设置里打开。
- 一次评分只作用于当前这一个复习单元，不会把兄弟单元一起批量通过。

### 5.8 「完成」按钮

- 轮次没结束时，跳到**最早还没评分的单元**；如果已经停在未评分单元上，再按就去下一个未评分单元，末尾回绕。
- 所有卡都评完时，按「完成」进入**收尾结算**。

### 5.9 本轮安排与结算

- **本轮安排**（点 HUD 的轮次数字）：可以在「按宫殿」和「按进度」两种视图间切换；支持拖拽排序（桌面）或上移/下移（触屏）、批量排除/恢复、重置轮次。
- **移除本队列**：不评分，本轮不再排它，进度条上留一个实心刻度；以后轮次仍可能到期。
- **永久移除**：真正不再安排这个单元，即使标记删了再加也不会回来。
- **小结算「结算已完成单元」**：把已经处理完的分组从本轮压缩掉，分母变小；取消则不压缩。
- **收尾结算页**：本轮通过/重练/做题统计、本次专注时长、按学科的明细和宫殿行；底部是「再来一轮」；还可以选择清空本轮做题进度。

### 5.10 睡前复习

右侧翻页器上方的月亮按钮。它会把**当天至少评过一次的每个宫殿各追加一张卡**到队尾，一张卡覆盖整座宫殿的脑图。

它的评分**只记录、不写复习排期**：不写 Reviews 会话、不写 FSRS、不改到期日。所以睡前这一遍是纯复习，不会打乱第二天的安排。跨过凌晨 3 点的学习日边界后，前一天的睡前卡会自动失效；其间已经评过的卡保留真实评分。

### 5.11 随心内编辑

在卡片上双击空白画布就进入编辑，不用离开当前轮次：

- 编辑范围可选「当前专线」（只显示当前单元及其到根的路径）或「整座宫殿」。
- 「永久标记」是一个独立开关（图钉 + 已标计数），每次切换立即保存。
- 保存状态会显示「保存中… / 已保存 / 保存失败，重试」；保存失败不会把你踢回复习，也不会替换本地内容。
- 冲突时以当前设备为准，刷新令牌后重试一次；编辑成功不会重建队列、不会重置翻卡进度。

### 5.12 「可翻范围」：随心模式 vs 专线模式

这是翻卡设置里最容易被忽略、但直接影响体验的一项：

- **随心模式（默认）**：整座宫殿每个节点都能翻。适合自由浏览、补漏、按自己的思路回忆。
- **专线模式**：只能翻当前单元及其到根的路径，兄弟分支翻不开。适合严格按单元范围复习，避免注意力跑偏。

注意：它只影响「能翻哪些卡」，不影响评分范围——评分永远只作用于当前这个复习单元。

### 5.13 工具栏「做题」叠加层

- 从卡片工具栏打开，不改变训练方向，也不把信息流变成做题卡。
- 出题范围：**本轮复习单元（默认，含根→锚点路径）** 或 **整座宫殿**（主动开启）。
- 可按客观/主观筛选，可设混合/先客观/先主观、宫殿优先；已答进度存在本轮，重启和次日恢复，「再来一轮」时清空。
- 题目上方会显示它绑定知识点在本轮的**最低评分**；该知识点本轮还没复习时显示「本轮尚未复习」，而不是 0 分。
- 点这个徽标可以直接打开「查看宫殿」并聚焦到那个知识点。

### 5.14 数据与跨设备

- 轮次计划（卡片顺序、当前卡、完成/排除/重练）由本机后端 SQLite 权威保存；浏览器本地只存显示偏好和离线草稿，不决定复习顺序。
- 刷新、重启、次日打开都不会换轮次；「更新队列」会重规划但保留已评分；「同步进度」会读取另一台设备的活跃轮次并替换本地账本（会丢弃只存在于本地的评分）。
- 学习日以凌晨 3 点为界：3 点前算「昨天」。
- 同一时间只允许一台设备写入数据；跨设备靠外部同步盘，同步发生在应用之外。

### 5.15 随心不是「刷题模式」

随心里的做题卡和复习单元卡是两条独立证据链：做题不会改变宫殿复习单元的排期，复习评分也不会因为做题对错而变。混合队列只是把两种卡排在同一条流里，方便一天内切换。

## 六、几个容易混淆的边界

| 容易混的两件事 | 区别 |
|---|---|
| 翻卡 vs 评分 | 翻卡只是揭示内容，不改排期；评分是 1–4，才改间隔 |
| 翻卡进度 vs 掌握度 | 翻卡进度是本次访问的阅读状态，不存储、不统计、不跨设备 |
| 正式复习 vs 随心 | 同一个信息流；正式复习只是把范围锁到一座宫殿 |
| 复习单元 vs 做题 | 单元有排期、可评分；题只记录对错和标记，不影响排期 |
| 小结算 vs 通过 | 结算只是把已完成的分组从本轮移走，不等于全部通过 |
| 移除本队列 vs 永久移除 | 前者只影响本轮，后者永久不再安排 |
| 睡前复习 vs 正式复习 | 睡前只记录评分，不改任何到期日 |
| 忘记 vs 困难 | 忘记是不通过并产生重练；困难是通过，只是间隔压短 |
