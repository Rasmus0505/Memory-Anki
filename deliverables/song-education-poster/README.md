# 宋代教育图鉴 · 从科举取士到书院讲学

一张 A2 单页学习海报，版式参照「宋职图鉴」信息图（竖排标题 + 长卷底图 + 放射圆盘 + 点阵时间轴 + 双分组柱图 + 摘要），内容换成中国教育史第五章第二节「学校教育制度的发展」。

## 三个文件怎么用

| 文件 | 用途 |
| --- | --- |
| `宋代教育图鉴.html` | 主文件。双击用浏览器打开即可，图片已内嵌，单个文件可随意拷贝、发人。窗口缩放到任意宽度会自动等比缩放；浏览器打印（Ctrl+P）选 A2 即可直接出图。 |
| `宋代教育图鉴-A2.pdf` | 印刷版。已按 420×594mm 单页排版，文字是矢量，直接送打印店。 |
| `宋代教育图鉴-预览.jpg` | 1800px 宽预览图，发微信、贴文档用。 |

## 改内容

海报是「模板 + 数据」生成的，**不要直接改最终 HTML**（会被覆盖）：

1. 文案、版式、位置：改 `_work/template.html`（绝对定位，坐标都用 px，画布 1600×2263）。
2. 图表数据：改 `_work/build.py` 里的 `SECTORS`（六域）、`EVENTS`（时间轴）、`CLUSTERS`（柱图）。
3. 重新生成：在 `_work` 目录下运行

   ```
   python build.py
   python render.py     # 出 PDF / PNG / 分块检查图
   ```

只改几个字的话，直接编辑 `宋代教育图鉴.html` 的纯文本部分也可以，但下次重新生成就会被覆盖。

## 素材与口径

- 底图：《清明上河图》清院本（清·陈枚等摹本，原作已入公有领域），从公开扫描件裁切，经棕墨色阶处理以接近宋画气质。**注意：不是张择端宋本**，故页面标注为「清院本」；画面编号是概念索引，不是画中原有场景。
- 时间轴年份均取常见通行纪年（庆历四年 1044、熙宁二年 1069、元丰二年 1079 三舍法学额、崇宁元年 1102、崇宁三年 1104 罢科举由学校取士）。
- 柱状图统计的是「本节梳理出的举措条目数」，按官学/取士两类分色，不是统计抽样数据，图下已注明。

## 版式参数

- 画布 1600 × 2263 px（√2 比例），对应 A2；打印时等比放大。
- 主色：纸 #efe6d2、墨 #3b352a、金 #b08b3e、褐 #8a6a45、紫 #6f6aa8、印 #9d3a2c。
- 字体走系统宋体栈：Songti SC / 思源宋体 / SimSun，引文用楷体栈。
