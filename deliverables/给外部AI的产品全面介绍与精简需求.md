## 一、这是什么产品

**Memory Anki**：给一个人用的「记忆宫殿 + 间隔重复 + 做题」学习工具。

- 用户只有我一个。不是对外产品，没有注册、没有多用户、没有云端、没有社交、没有分享。
- 运行在两台 Windows 电脑上；数据放在两台电脑各自同步的一个文件夹里，由外部同步盘负责搬运，应用本身不做同步。同一时间只有一台电脑在写。
- 桌面端是本地应用；手机通过私有网络打开同一套网页界面，主要用「随心」复习。桌面和手机是同一个前端，不是两个产品。
- 我的考试：2027 考研，初试 2026-12-20。专业课 333 教育综合（中国教育史、外国教育史、教育学原理、教育心理学），加政治、843 和两门科学教育科目。

产品的一句话：**把教材拆成一张张思维导图（宫殿），用永久标记切成复习单元，按 FSRS 排期复习；题目挂在导图节点上，复习时顺手做题。**

题库里的 7251 道题全部来自真人老师和历年真题（冬青、腿姐、肖秀荣、丹丹、凯程，以及 2008–2024 的 311 真题），没有 AI 生成的题；真题、机构自编题、阶段测试混在同一座宫殿里，只能靠题干开头的来源标签区分。

## 二、我每天怎么用它

**工作日的晚上（约 40–90 分钟）**
打开应用 → 默认落在「随心」开始页，看到今天有多少张卡、昨天复习了什么、考试倒计时 → 进入卡片流，一张卡是一个复习单元：上面是这张单元对应的脑图（可以翻看、展开），下面是「忘记 / 困难 / 记得 / 轻松」四个按钮，按钮上直接写着"这一下会排到哪天" → 评完一张滑到下一张 → 遇到需要练手的单元，点工具栏「做题」，弹出这座宫殿的题，做完看解析 → 全部评完进结算页，看到本轮学科和宫殿的完成情况。

**碎片时间（手机）**
只开「随心」，刷卡、评分，偶尔做题。手机上不做编辑。

**周末（1–3 小时）**
新建/修改宫殿：建一座空宫殿，或者把 Markdown / JSON / 一段文字转成脑图初稿，然后在脑图编辑器里整理层级、加备注、打永久标记（决定复习单元怎么切）→ 顺手在编辑页给刚整理完的单元评分（因为刚整理完其实已经回忆过一遍）→ 维护章节结构、给宫殿归章 → 偶尔在设置的迁移入口导入整库 ZIP 或做备份。

**考前**
用「考试作战室」看全局掌握度、按考试重要度排序、给章节打星级、看遗忘曲线预测、做导图抽查。

**很少用**：英语听力/完形、命令面板、提醒、反馈设置、AI 模型设置。

## 三、功能全景（当前真实存在的界面）

### 一级入口（侧边栏 6 个）

**1）随心 `/freestyle`（默认首页）**
- 开始页：今日复习概览、昨日回顾、考期倒计时、里程碑、本轮安排入口。
- 卡片流：一张卡 = 一个复习单元，展示该单元的脑图局部；四个评分按钮 + 下次间隔预告；滑动/翻页。
- 卡片工具栏：做题、英语、文字、查看宫殿、缩放。
- 本轮相关：本轮计划、更新队列、同步进度、再来一轮、移除本队列、永久移除、批量评分（本宫殿）、重练卡（10 分钟 / 1 小时 / 3 小时）、睡前复习（月亮，追加今天学过的宫殿）、复习等级进度条（拖动直接改到期日）。
- 结算：小结算、大结算；按学科和宫殿两个粒度展示。
- 做题浮层：本轮复习宫殿的全部题目，客观/主观可筛，显示已做进度，可标记、清空做题进度；浮层里还能复制题目、复制导图、调字号、改快捷键。

**2）知识 `/palaces`**
- 学科书架（封面式、可切布局和密度、按章节展开、搜索）。
- 列表视图 `/palaces/list`。
- 宫殿详情 `/palaces/:id`：只读脑图 + 概要 + 附件 + 全屏编辑。
- 宫殿复习 `/palaces/:id/review`：复用随心的卡片流，只锁这一座宫殿。
- 宫殿题库 `/palaces/:id/quiz`：独立做题页（与随心里的做题浮层是两套界面）。
- 知识体系 `/knowledge`：学科—章节树，看章节信息、备注、宫殿归属、删除章节。

**3）英语 `/english/listening` + `/english/cloze`**
- 片库、导入课程、听力敲字幕课程页、完形练习。

**4）创建 `/palaces/new`**
- 新建宫殿：空宫殿、导入导图文件（JSON / Markdown 等）、"文字转脑图"（粘贴一段文字生成脑图）。整库导入不在这里，在设置的数据迁移入口。

**5）进度 `/progress`**
- 知识进度浏览器：按学科/章节逐层展开，看到记忆掌握、已作答、待复习、题目进度；可筛选、排序、批量展开。

**6）洞察 `/dashboard`（次级入口）**
- 今日与近期状态、薄弱点、学习动态。
- 考试作战室 `/exam`：考期设置、倒计时、章节和宫殿按掌握度着色、星级重要度、遗忘曲线预测、导图抽查、按考试优先开始复习。

### 常驻能力
- 设置 `/profile`：偏好、复习与调度、复习参数、快捷键、数据库位置、PWA 更新与缓存、清库；子页：反馈与声音、提醒、AI 模型、备份。
- 迁移与导入导出入口（整库 ZIP、宫殿导入导出）。
- 全局命令面板（搜索宫殿、开始随心、新建宫殿）、全局返回、最近访问。
- 启动 / 关闭 / 周期性备份、宫殿版本快照。

### 复习与做题的产品规则（现状）
- 一个复习单元一张卡，独立排期；FSRS，目标记忆率 90%，最长 365 天。
- 新卡两次固定节点：当天 20 分钟复查、第 2 天隔夜检验；之后交给算法。
- 四个按钮：忘记（当天重练，最多 3 次）、困难（算通过但压短间隔）、记得、轻松。
- 提前复习只记录不改期；间隔 ≥7 天有 ±5% 抖动；考试冲刺只把卡往考前拉。
- 编辑宫殿时可以直接给单元评分；也可以在等级进度条上拖动改期（最长一年）。
- 做题：题目归属宫殿并绑定导图节点；随心做题抽的是**整座宫殿**的题，不是当前单元的题；答题进度只在本轮内保存，**不进 FSRS 排期**。

### 内容生产
- 手动增删改题；从 PDF / 图片批量识别生成题（离线 AI）；整库导入导出；章节归并。
- 内置的 AI 出题、AI 讲解、AI 纠错、自由提问入口**已经全部关闭**，点了不可用。
- 目前题库 7251 道全部来自真人老师和历年真题，无 AI 生成题。

## 六、我为什么想再做大扫除（我自己的感受，供你验证）

1. **同一件事有多个入口**：改一个单元的到期日，在随心的等级条和单元评分页各有一套（同一件事两个界面）；做一座宫殿的题，可以在随心浮层和宫殿题库页两处做；看宫殿可以走书架、列表、宫殿详情、知识体系四个地方。
2. **一级入口之间的边界说不清**：「知识」和「创建」和「知识体系」到底谁负责什么；「进度」和「洞察」和「考试作战室」都在讲掌握度。
3. **设置比功能多**：设置首页 + 4 个子页，而其中 AI 模型、提醒、反馈声音我几乎不打开。
4. **有些页面是"为了完整"而存在**：迷你宫殿 0 个、附件 0 个、英语 1 门课，相关界面却都保留着。
5. **手机端只想要一件事**：刷卡评分。但手机上仍然能看到整套桌面界面。
6. **每次加功能都很快，每次删功能都很痛**，所以我想先请一个外人从全局判断：哪些东西本来就不该独立存在。

## 七、这次的任务与边界

请只做三件事：**合并、删除、优化**。

- **合并**：两个或多个东西本质是同一件事，应该收成一个入口/一个界面/一套流程。
- **删除**：整块去掉，不替代。
- **优化**：保留，但减少步骤、减少重复展示、减少需要理解的概念。

**禁止**：
- 不要建议新增功能、页面、入口、模块、设置项、AI 能力。
- 不要建议"再做一个仪表盘/助手/推荐系统"来解决问题。
- 不要建议换技术栈、换存储、上云、做多用户。
- 不要用"可以加一个开关"来回避取舍。

**必须遵守的产品约束**：
- 数据是唯一资产：删界面可以，删数据要单独标出来，并说明是否可恢复。
- 两台电脑 + 手机共用同一份数据；任何"删"都要考虑另一台设备上的历史记录。
- 复习排期的正确性不能动（FSRS、两次固定节点、四个按钮语义、提前复习不改期）。
- 桌面端功能可以比手机多，但手机端不应该承受桌面端的复杂度。
- 我是唯一用户，不需要考虑"新用户引导""权限""多人协作"。
