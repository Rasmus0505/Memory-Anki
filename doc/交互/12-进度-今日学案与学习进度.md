# 12 · 进度 · 今日学案与学习进度

> 路由：`/dashboard`（今日学案）· `/progress`（学习进度）。两页与 `/exam` 共用同一条页内导航：`学习进度 / 今日学案 / 考试作战室`。
> 最后核对：2026-11-24。

## 一、今日学案 `/dashboard`

### 页头

`今日学案` + 中文日期（月日星期）。窄屏用分段开关 `考试 / 动态 / 宫殿` 切换；宽屏三栏同屏。

### 主块：今天该学什么

- 大数字：`N 个单元到期`。
- 右侧最多 3 座宫殿（星级 + 标题），点进去看宫殿。
- 按钮 `开始今日复习` → 随心。
- 提示：`在随心配置里选「考试优先」，会按这个顺序出卡`。

### 左栏

**离考试还差多少**：`距考试 N 天` / `今天考试` / `未设置考试`；当前掌握率 → 考前预测 X%；双色进度条；`按目前每天新学 N 个学完剩余需要每天 N 个`；右上 `作战室 →`。

**哪里最薄弱**：最多 8 行，序号 + 星级 + 宫殿名 + `记住 X% · 已学/总单元`；记住率低于三成的已学宫殿标红。

### 右栏

**最近学得怎么样**（账本三行）：`累计学习天数` · `近 7 天学习 n/7` · `近 7 天通过率`；脚注 `今天已评分 N 次`。

**学习热力图**：卡头右侧 `连续 N 天 · 最长 N 天 · 近半年学习 N 天`；半年格子按复习次数着色，每格提示 `日期：复习 N 次`。

**上周摘要**（热力图下方）：起止日期 + `复习次数 N 次` · `平均分 X` · `新建宫殿 N 个`；无记录时 `上周没有学习记录`。

> 现状提示：后端目前没有算上周平均分，这一格恒为 0.0。产品上应先隐藏或修好，不要让客户看到「平均分 0.0」。

### 新增宫殿卡

标题 `新增章节数量：N`（实际统计今天新建的宫殿数），右上 `新建`。列表按学科/章节分组，每项两行（学科·章节 / 宫殿标题），点进编辑器。空态 `今天还没有新增记忆宫殿`。

### 异常

- 整页失败：`今日学案加载失败` + 错误信息 + `重新加载`。
- 考试概览失败只降级成一条 `考试概览加载失败：…`，不影响其他块。

## 二、学习进度 `/progress`

### 定位

只读快照，回答「走过哪里、练过哪里」。页脚两句话把它和随心区分开：

> 复习记录 ≠ 记忆掌握 · 已作答 ≠ 已答对
> 快照更新于 … · 当前范围统计不随筛选改变

### 页头

`学习进度` + `刷新`（刷新中显示 `更新中`）。

### 快照概览

- 大数字：`已复习的记忆点 X / Y` + `个记忆点已有复习记录。` + 覆盖条。
- 圆环：`复习覆盖率`。
- 三块：`题目已作答 X/Y` · `待复习记忆点 N 个` · `当前范围宫殿 N 座`。
- 切到某学科或章节时，标题换成该节点名。

### 知识版图浏览器

- 视图切换：`层级 / 分布 / 题目`。
- 面包屑：`全部学科 › 学科 › 章节`。
- 搜索：`搜索学科、宫殿或记忆点…`。
- 筛选：`全部状态 / 待复习 / 尚未覆盖 / 有未做题目`。
- 排序：`知识顺序 / 覆盖从少到多 / 待复习优先`。
- 层级模式可一次展开到一 / 二 / 三级。
- 有筛选时提示 `结果包含当前范围内匹配的下级内容。` + `清除筛选`。
- 范围失效：`原范围已不存在，已回到全部学科。`

**层级视图**：表头 `知识结构 / 复习覆盖 / 题目作答`。每行：名称、子项数、待复习数、复习覆盖 `x/y + %`、题目 `x/y`。学科行带一条「记忆阶梯」。

**分布视图**：每格一个真实记忆点；琥珀=到了复习时间，图例原文 `琥珀色表示到了复习时间，不等于已经遗忘`；另外两档是「有复习记录」「暂无复习记录」。

**题目视图**：按范围比较题目已作答数，说明 `同一道题反复作答仍计为一道；父级按题目去重`。

分页：`N 个条目 / 记忆点 · 第 x / y 页`。

### 右侧详情

- 节点名 + 路径 + 类型。
- 覆盖条与四格：`有复习记录` · `待复习记忆点` · `已作答题目` · `尚未作答`。
- 动作：`聚焦这一范围` · `进入所属宫殿复习` · `打开宫殿题库`（有题时）· `打开知识书架`（无选中时）。
- 说明：`学习入口打开整个所属宫殿，不会自动限定为当前记忆点。`
- 说明卡「积累，不止一个百分比」，可展开「这些数字如何计算？」。

### 空态

`还没有宫殿` / `建立知识结构后，这里会呈现记忆点和题目进度。` + `前往知识书架`。

## 三、冲刺与里程碑

进度页里有一块 `冲刺与里程碑`（内容属于考试域，见 [13-进度-考试作战室.md](13-进度-考试作战室.md)）：

- **冲刺开关** + 考试日期。
- 开启且设了日期：`距离考试 N 天 · 所有复习都会排在 YYYY-MM-DD 之前`。
- 开启但没日期：`已打开，但还没有考试日期，暂时不生效`。
- 未开启：`未开启：按记忆状态排期`。
- 里程碑列表：日期、标题、分类、提前 N 天提醒、状态（`已完成` / `已过期` / `快到了` / `未到期`）、距今天数、完成勾、删除；`新增里程碑` / `保存里程碑`；头部计数 `3/5 完成 · 1 项已过期 · 2 项临近`。
- 明确写着：`里程碑不改复习间隔；冲刺模式把排到考后的卡提前到考前最后一周。`
