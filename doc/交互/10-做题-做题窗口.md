# 10 · 做题 · 做题窗口

> 入口：随心页眉「做题」、卡片工具栏「做题」、节点题目徽章、宫殿做题页、编辑器「做题训练」、右键菜单「做题」。
> 所有入口打开的是**同一个窗口**，只是来源与范围不同。
> 最后核对：2026-11-24。

---

## 一、两种来源

| 来源 | 从哪来 | 题目池 | 能不能影响排期 |
|---|---|---|---|
| **随心轮次** | 随心里的任何「做题」入口 | 本轮已排期的复习单元相关的题 | 能：错题优先会提前对应单元 |
| **直接题集** | 节点徽章、右键「做题」、宫殿做题页选中的题 | 明确的题目 id | 不能：只做题，不改排期 |

窗口本体（工具栏、题号轨道、作答区、页脚、尺寸与位置记忆）完全相同。

## 二、首次打开：做题配置

随心轮次来源会先给配置面板：

| 设置 | 选项 | 说明原文 |
|---|---|---|
| 出题范围 | `本轮复习单元` / `整个宫殿` | 「只出本轮复习单元和从根节点到它的路径上的题」/「整个宫殿里所有题都出，范围大、重复多」 |
| 本次做题范围 | 可勾选的宫殿与单元列表 | 逐项解释为什么没出题：`还没有题目` / `本轮单元没有题目` / `题型未勾选` / `已移除队列` / `已从做题删除` |
| 出题顺序 | `跨宫殿乱序` / `一个宫殿刷完再换` | — |
| 题型 | 客观 / 主观，可混选 | — |
| 题型顺序 | `混合插入` / `先客观后主观` / `先主观后客观` | — |
| 题目分数 | `跟着已复习的最低分` / `保持空白` | — |

底部 `开始做题` / `保存并继续`。直接题集来源只显示一行 `出题范围：当前卡片关联的 N 道题`。

## 三、窗口内

### 顶部

`错题优先` · `查看宫殿` · `复制题目` · `清除进度` · `更多`。

- **错题优先**：`答错后只把这道题对应的复习单元排到前面，同一宫殿的其他单元不动`。
- **复制题目**：导出本题 / 全部题 / 全部错题 / 错题 + 完整宫殿；可附带导图与答题信息。
- **清除进度**：范围可选当前宫殿 / 全部宫殿，说明 `题目保留，作答次数不变。`

### 题目区

- 题号翻页轨道：状态点为未做 / 已答 / 错 / 标记。
- 题头：题型徽章、`答对 x · 作答 y`、变体切换、`已标记`、结果徽章（`已答对` / `已作答`）。
- 本轮最低评分徽章：`本轮最低 N · 忘记` 之类；本轮还没排到时显示 `本轮尚未复习`。
- 动作：`编辑本题`（就地改题干/选项/答案/解析）、`移除本宫殿`（`只从本轮随心做题移除这座宫殿的题，不影响复习评分`）、`删除本题`（进回收站）。

### 题型与判分

| 题型 | 怎么答 | 判法 |
|---|---|---|
| 选择题（单选） | 点选项 | 立即判 |
| 选择题（多选） | 选完点 `提交答案` | 选项集合完全一致 |
| 判断题 | 对 / 错 | 立即判，错时给「错误点」 |
| 填空题 | 逐空输入，`Enter` 提交此空 / `提交全部` | 别名也算对 |
| 连线题 | 左选右配，`提交连线` | — |
| 排序题 | 拖拽或上移/下移，`提交排序` | 展示正确顺序 |
| 归类题 | 拖入或点选，`提交归类` | 展示正确归类 |
| 简答题 | 主观输入，`Enter` 提交、`Shift+Enter` 换行 | 给参考答案与解析；有 AI 点评（基本正确 / 部分正确 / 需要重学，含答到的要点、遗漏或有偏差、建议、实际模型） |

选择题可以切成「选择 / 主观」两种作答方式：同一道题改写成主观题作答。

### 判后

- 固定展示 `回答正确` / `回答错误` / `再调整一下` + `正确答案：…` + `解析：…`（没有则 `暂无解析`）。
- 答题耗时气泡。
- 连续答对 ≥2 显示 `连对 N`。
- 题号轨道与节点绑定点按当前答案着色：答错红，改对即恢复；一个单元全部绑定题答对时单元标绿，红色优先。

### 底部

`已答 x / y · 范围名`；`上一题` / `下一题`；最后一题答完出现 `完成`。

## 四、键盘

| 键 | 行为 |
|---|---|
| 数字 / 字母 | 直接选选项 |
| `Enter` | 提交；答案出现后同键下一题 |
| 空格 | 下一题（固定） |
| `↑` | 标记 / 取消标记 |
| `Backspace` | 打开删除确认 |
| `Ctrl+Z` | 重新作答当前题 |
| 滚轮 | 字号 70%–180%，右上角浮出百分比 |

整套键可在配置面板里改，说明「随心做题和关联题目共用，改完即保存」。

## 五、进度与保存

- 作答进度防抖保存，断网重试、冲突重试、离开页面冲刷。
- 随本轮保存，刷新与换设备都能接上。
- 开新一轮或结算时按宫殿选择保留或清空；结算页的清空是一次显式二次确认。

## 六、宫殿做题页 `/palaces/:id/quiz`

页头 `{宫殿} · 配套习题` / `宫殿配套习题`，徽章 `N 题`，动作 `查看记忆宫殿`。两个页签：

**做题**：范围 chips `全部` / `大宫殿（N）` / 各学习组（N）；`清空当前范围进度`（确认 `只清空筛选范围内的答对、答错和作答次数，不删除题目。`）；搜索 `搜索题目`；汇总行 `N 道关联题目` + `开始做题`；每题一行（题型 + 题干），点击即做；`查看知识点` 打开绑定节点。

**管理**：`题库列表`；范围 chips；全选 / `已选 N 题` / 清空选择；`批量删除所选` / `新增题目`；每题徽章（类型、归属章节题/学习组/大宫殿、变体、对错计数）、`编辑`、`删除`；右侧「手动新增题目 / 编辑题目」表单：题型、题干、选项与正确答案、参考答案、解析、`保存题目` / `重置表单`；下方「原始 OCR」来源列表（来源集 · 页码 · 导入批次，可展开原文）。

题目的右键菜单：`编辑题目` / `再做一次` / `标记` / `选择题目` / `复制题干` / `删除题目`。
