## 一、听写片库 `/english/listening`

页头说明原文：

> 上传视频与英文字幕，一句一句把台词拼出来。中文字幕可选，全键盘操作，鼠标可以完全不碰。

`导入课程` 是主按钮。

### 继续卡

有未完成课程时：「已完成 x/y 句 · 时长」+ 进度条 + `继续听写 →` + `导入新的`。
全部完成时：
> **手头的课程都完成了**
> 从下面的片库挑一部再练一轮，或者导入新的视频与字幕。
> `导入新的`

空库：
> **片库还是空的**
> 准备一个视频和它的英文字幕文件，剩下的交给本地解析。不需要联网，也不会上传素材到任何云端 AI。
> `导入第一部`

### 片库

统计 `共 N 门 · 未完成 N · 已完成 N`；搜索 `搜索课程`；筛选 `全部 / 未完成 / 已完成`。
课程卡：标题、`已完成` / `进行中`、句数、时长、更新时间、百分比、删除；右键 `打开课程` / `删除课程`。

### 导入

弹窗 `导入一部听写课程`，说明「视频和字幕都在本机解析，不调用 ASR，也不上传到云端。」

| 投放位 | 要求 |
|---|---|
| 视频 | MP4 / MKV / MOV / WebM，≤ 1 GB |
| 英文字幕 | 必需，SRT / VTT / ASS（双语字幕也可以） |
| 中文字幕 | 可选 |

课程标题默认取视频文件名。
提示：「英文按句号、问号、感叹号切句，跨字幕条的半句会自动合并。」「中文字幕条数不同也没关系，会按时间重叠匹配。」
按钮 `取消` / `导入并开始`（导入中显示 `正在解析并建立课程…`）。
成功提示 `已导入 N 句，译文已对齐`。

## 二、听写台 `/english/listening/courses/:id`

### 一句一练

- 默认单句模式：视频只播这一句；连播模式连续播放。
- 下方逐词拼写，**整词判定**：输满一个单词才比较；大小写、弯引号、破折号归一化；多词答案以词为单位。
- 输错：单词标红，错误音，约半秒后自动清空该词重来。
- 输对：进入下一个词。整句所有词正确 = 本句完成，保存进度，完成音。

### 键位

| 键 | 作用 |
|---|---|
| 任意字母 | 输入 |
| 空格 | 播放 / 翻页 |
| `Backspace` | 退格 |
| `↑` | 揭示一个字母 |
| `↓` | 揭示当前单词 |
| `Home` | 清空重输本句（已完成的句子会被重新计为未完成并清掉该句统计） |
| `Enter` | 显示 / 隐藏译文（本句完成后才显示） |
| `Esc` | 暂停 / 继续 |
| `F3` | 单句 / 连播 |
| `F2` | 切换布局 |
| `PageUp` / `PageDown` | 调速 |
| `` ` `` | 遮挡板 |
| `F8` | 声音 |
| `F1` | 快捷键面板 |
| `←` / `→` | 上 / 下一句 |

### 布局

- **影视全屏**：视频为底，拼写浮在底部。
- **经典双栏**：左视频右拼写。
- **沉浸单栏**。
- 可选「显示句子胶片条」：底部一条句号条，已完成打勾，点击跳句。

### 遮挡板

可拖动、八向缩放；播放时加深，暂停时模糊。设置里可改默认开启、模糊 px、不透明度、重置位置。

### 暂停

`已暂停` / `视频与听写都停在这一刻。按 Esc 或 Space 继续。` + `继续 Esc`。

### 本句完成

状态行 `本句完成 · Space 重播 / Home 清空重输 / → 下一句`。可选「完成后自动下一句」「完成后自动重播」「单句循环」（均只在单句模式下有效）。

### 整课完成：CURTAIN CALL

整课拼完后约 0.9 秒弹出复盘：

- 标题 `CURTAIN CALL` + 课程名。
- 一句结论：`这一轮把 N 句全部拼完了。` / `这门课已经完成；这次新拼了 N 句。` / `这门课已经完成。可以再练一轮，或回到片库挑选下一部。`
- 四格：**一次通过** · **用过提示** · **输错次数** · **本轮用时**。
- `值得再听一遍`：错得最多、提示最多的前 5 句原文。
- 按钮 `再练一遍 Enter` / `返回片库 Esc`。

### 异常

`无效的课程编号` / `课程没有加载出来` / `课程里没有句子`，均带 `返回片库`。进度保存失败提示 `进度保存失败，稍后会自动重试。`

## 三、完形阅读 `/english/cloze`

说明原文：

> 浅蓝是难词，琥珀是你标的；点一下切换，再点取消。

- 年份切换。
- `查词` 开关：开启后点任意单词弹出查词面板。
- `复制` 菜单：复制这篇文章 / 这年的生词 / 全部生词 / 选项。
- 文章里空格以虚线下划线显示；右侧「选项 · 正确答案已标出」，正确项绿色高亮；窄屏可 `收起选项`。
- 生词计数 `这一年 N 个生词。`
- 空态 `文章还在准备，刷新后就能按年份读。`；错态 `完形文章暂时打不开，过一会儿再试。`

这一页是**阅读与整理**，不判分、不排期。
