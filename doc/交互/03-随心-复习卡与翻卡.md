# 03 · 随心 · 复习卡与翻卡

> 一屏一张卡。界面退到边缘，只留页眉、卡面、评分坞与右侧翻页器。
> 最后核对：2026-11-24。

---

## 这一页回答什么

「这一段，我现在能不能不看就想起它的结构。」翻卡是这一页唯一的正文动作。

## 版面（自上而下）

│ 北宋三次兴学     29/55        ⚙  ⋯            │
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │ 工具栏：编辑 文字 做题 …                  │ │  ← 脑图工具栏占卡面顶边
│ │ ● 北宋三次兴学   2/9   补充   [撤销]      │ │  ← 单元身份行
│ │                                          │ │

| 元素 | 文案 | 行为 |
|---|---|---|
| 进度细线 | — | 本轮全部卡片摊成刻度；可点格跳转，播放头跟着手指走 |
| 宫殿名 | 当前宫殿 | 只读 |
| 轮次计数 | `29/55` | 点击打开「随心配置」 |
| 配置按钮 | 图标 | 打开「随心配置」 |
| 更多（⋯） | 菜单 | 更新队列 / 同步进度 / 历史 / 返回书架 / 知识 / 英语 / 创建 / 进度 |
| 里程碑 | `08/12 3 天后` | 宽屏内联、超出截断；手机隐去 |
| 会话录制圆点 | 可拖动小圆点 | 手机右上有自己的拖动通道，不挡「更多」 |

## 卡片外框

- 顶部一条 1px 类型色：**新学=蓝、复习=琥珀**；已评分不透明，未评分 35% 透明，「完成度=透明度」。
- 评分确认时卡片边缘有一圈「呼吸」光，不占屏幕中心。
- 右上角可能有考试星（1–3 星）。
- 卡片进出有深度叠层动效；背景环境色随卡片类型变化。

## 单元身份行

通栏一行，位于脑图工具栏下方（不是浮起的小胶囊）：

- 左侧一个松墨小圆点，代表「这颗是永久标记」。
- 单元标题，一行截断。
- 翻卡徽标 `2/9`：只统计本单元成员与锚点。0 张红、部分赭、全翻完绿。悬停说明分别是「尚未翻卡 0/9」「已翻 2 / 需翻 9」「翻卡完成 9/9」。
- 「补充」徽标：这一张是补充练习，记得/轻松只记下、不改下次到期日。
- 「撤销」：评分后 5 秒内出现，点它回到上一评分状态。

## 卡片类型

| 类型 | 外观 | 能做什么 |
|---|---|---|
| 复习单元卡 | 纸色脑图 + 评分坞 | 翻卡、评分、编辑、做题 |
| 重练卡 | 同款，角标写 `↻ 重练第 N 次`（已评过则 `重练第 N 次 · 已过`）；可带源卡标题 | 同上；评分后进入下一处 |
| 整宫通过卡 | 标题为宫殿名 | 与普通卡相同 |
| 只看不评 | 「这张已经评过，当前只看不评」 | 「改评分」「跳过这张」 |
| 补充练习卡 | 带「补充」徽标 | 只记分，不改期 |
| 黄卡提示 | 亮黄渐变，例如 `下一张：正式复习` / `路径到此为止，接下来是正式复习单元` | 四档只用来「继续」翻页，不写评分 |

## 翻卡

**默认状态**：只显示本单元锚点与它的结构，子卡折叠。

**翻卡**（默认回车，也可点节点）：
- 两阶段模式：先出「待回忆」占位，再翻出内容。
- 直接显示模式：一次出全部内容，适合对照阅读。
- 子卡按层级逐张翻开；一次翻一层或一次批量，取决于「翻卡颗粒度」。

**收卡**（默认退格）：折回当前卡与它翻开的子卡。两阶段模式回到「待回忆」；直接显示模式整张收起。可以再按翻卡重来。

**镜头跟随**：翻出的卡片自动移入视野，可以在「翻卡设置」里关掉。鼠标点节点不移动视野，只有键盘翻卡才跟随。

**隐藏子级**（默认 Shift+H）：对当前锚点执行与右键相同的「隐藏子级」操作。

## 视图

- **W / A / S / D**：固定为画布平移，激活卡才生效，不参与任何翻卡动作。
- **缩放、拖动画布**：鼠标滚轮 / 拖动；脑图区域内滚轮让给地图平移。
- **全屏与半屏**：工具栏切换；全屏用 Esc 退出；沉浸信息流时隐藏左侧面板而不是压缩舞台。

## 飞卡与滑动

- 上下滑：整页吸附翻卡，一次一页。
- 鼠标滚轮（卡片外区域）：一格翻一页。
- 到边界继续拉：iOS 式回弹 + 提示 `已经是第一张` / `已经是本轮最后一张`。
- 快速翻卡和拖动进度条跳转**不会**给只是被翻过的卡片打开回忆会话；只有评分、或在某张卡上停留之后才打开。

## 脑图工具栏

- 模式：`编辑` / `复习`。
- 画布工具：刷新脑图、适应整树、适应当前分支（手机隐藏）、展开本支、展开全部、折叠深层、撤销、重做、全屏。
- 居中 **复习等级条**：`等级 N · 标签` + `今天到期` / `间隔 N天`；滑块从「首学」到「365天以上」。
  - 拖动松手后弹「调整复习等级」：显示目标等级、日期与间隔；三个快捷项（明天 / 3 天后 / 7 天后）、一个「精确日期」输入；`应用` 才写。
  - 说明原文：`只改排期，不改记忆评估；下次评分会按新间隔继续。`
  - 本轮关联题答错时，等级条整体变红提示「本轮关联题目答错」。
  - 失败提示 `调整失败，请重试`。
- `做题`。
- `更多`：`进入编辑` / `返回学习` · `复习进度` · `复制导图`（可带本宫殿全部题） · `文字转脑图` · `导出脑图` · `翻卡设置`。
- 编辑态额外有 `永久标记` 开关。

## 翻卡设置（在工具栏「更多 → 翻卡设置」里改，不在卡片上改）

| 设置 | 选项 | 默认 |
|---|---|---|
| 翻卡颗粒度 | 逐张 / 同层批量 | 逐张 |
| 揭示方式 | 两阶段 / 直接显示 | 两阶段 |
| 可翻范围 | 专线模式（只翻本单元这条线）/ 随心模式（整座宫殿） | 专线模式 |
| 进入编辑范围 | 当前专线 / 整座宫殿 | 当前专线 |
| 翻出的卡片自动移入视野 | 开 / 关 | 开 |
| 评分后自动翻页 | 关（默认，留出改判时间）/ 开（评完跳到最早未评分的单元） | 关 |

快捷键可在同一处整套改：翻卡、收卡、上一张、下一张、隐藏子级。空格固定「下一张」，方向键 ← → 也固定翻页，它们不会被绑定占用。

## 键盘与触屏的等价

| 动作 | 键盘（默认） | 触屏 |
|---|---|---|
| 翻卡 | 回车（或点节点） | 点节点 |
| 收卡 | 退格 | 再点一次 / 长按菜单 |
| 隐藏子级 | Shift+H | 长按节点菜单 |
| 下一张 / 上一张 | 空格 / ↓、← 或 PageDown / PageUp | 右侧翻页器、上下滑 |
| 评分 | `1` `2` `3` `4` | 评分坞按钮 |
| 移除本队列 | `5`，再按一次确认 | 「移除这张…」 |
| 平移视图 | W A S D | 单指拖动画布 |
| 进入编辑 | 双击节点或空白 | 双击 |
| 退出全屏 | Esc | — |

输入框、脑图编辑器、弹窗打开时，学习快捷键全部让路。按键可以整套改（翻卡设置 → 快捷键），空格、方向键、PageUp/PageDown、W A S D 是固定键不可占用。

## 卡打不开时

四件事按严重程度排：**重试** / **跳过这张** / **重建本轮** / **只看不评**，另有一句「复制给助手」把错误原文复制走，不要求学习者重启应用。正在更新复习安排时显示「正在更新复习安排，请稍候。」而不是英文错误。
