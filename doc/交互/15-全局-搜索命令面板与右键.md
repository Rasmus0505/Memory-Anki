# 15 · 全局 · 搜索、命令面板与右键

> 跨页面共用的四处「随时可到的入口」。
> 最后核对：2026-11-24。

---

## 一、侧栏与分区

左侧书脊式导航，五格：**随心 / 知识 / 英语 / 创建 / 进度**。顶部是产品名与实时时钟，下面是全局后退/前进；底部是「设置」、工具菜单（会话录制、调用与错误日志、当前版本）与收起导航。

- 宽度可拖拽，双击恢复默认；可收成 60px 窄轨。
- 每格记住上次停留的页内地址；已经在这一格时再点一次回到分区根。
- 后台任务进行中时，对应导航项显示数字气泡（`N 个后台任务进行中`）。
- 手机换成底部标签：`随心 / 知识 / 英语 / 进度 / 更多`；`更多` 抽屉里放创建、设置等其余入口。
- 沉浸复习时侧栏退让；全屏时隐藏。

**前进 / 后退**只在当前分区内生效，不跨区。分区起点时提示 `已在分区起点（不会跨到其他侧栏）`。

## 二、命令面板

呼出：`Ctrl/Cmd + K` 切换，`?` 打开。

内容分四组：

1. **最近访问**：最近打开过的页面，自动记录。
2. **操作**：`开始随心复习`、`新建宫殿`（`Ctrl+N`）、`搜索宫殿`（`/`）。
3. **快捷键**：翻卡相关动作及其当前绑定，选中跳到设置。
4. **页面**：五个分区 + 今日学案、学习进度、考试作战室、宫殿列表、知识树、英语听力、英语完形、设置。

输入两个字以上开始搜索，结果分四类：**宫殿 / 记忆桩 / 题目 / 章节**。每条可直接打开，也可右键走同一套菜单（搜索命中里隐藏改名、移动、删除）。

搜索范围：宫殿标题与描述、记忆桩名称与内容、题目题干、章节名。不搜导图的普通节点全文，也不搜英语课程。

页面内另有局部搜索：书架（`搜索学科或宫殿`）、列表（`搜索标题`）、进度（`搜索学科、宫殿或记忆点`）、题库（`搜索题目`）、英语片库（`搜索课程`）、编辑器（`搜索全局记忆宫殿`，打开记忆宫殿查找，可在其中查看脑图并直接标注评分）。

## 三、右键 / 长按菜单

鼠标右键与触屏长按打开同一个菜单；行的单击行为不变；菜单打开时行保持高亮。

| 对象 | 菜单 |
|---|---|
| 宫殿 | 打开 / 单独编辑 / 复习进度 / 做题 / 开始随心复习 ｜ 重命名 / 移动到… / 收藏 / 复制链接 ｜ 删除宫殿 |
| 章节 | 在此章节新建宫殿 / 开始随心复习 ｜ 重命名 ｜ 删除章节 |
| 学科 | 打开学科书架 / 在知识库编辑章节 / 在此学科新建宫殿 ｜ 重命名 ｜ 删除学科 |
| 题目 | 编辑题目 / 再做一次 / 标记 / 选择题目 / 复制题干 / 删除题目 |
| 英语课程 | 打开课程 / 删除课程 |
| 模板 | 使用模板 / 删除模板 |

同一套菜单也出现在考试知识地图的宫殿块、知识页的章节与学科行、搜索结果上。

## 四、键盘的统一约定

| 场景 | 约定 |
|---|---|
| 空格 | 固定「下一张 / 下一题」；焦点在按钮或链接上时归控件 |
| ← → · PageUp / PageDown | 固定翻页 |
| W A S D | 固定视图平移（只在随心激活卡时生效） |
| 输入框 / 编辑器 / 弹窗 | 学习快捷键全部让路 |
| 评分 | 默认 1 2 3 4；可改 |
| `Ctrl/Cmd + K` | 命令面板 |
| `Ctrl/Cmd + N` | 新建宫殿 |

焦点环始终可见；主要动作都能只用键盘完成。

## 五、位置记忆

- 每个分区记住上次停留的路由。
- 从列表进详情再返回，滚动位置与展开状态保留。
- 打开产品时回到上次停留的页面；没有记录则进随心。
- 关闭每日回顾卡片、折叠目录、收起面板这类偏好都按「这台设备 + 这个视图」记，不跨视图串。
