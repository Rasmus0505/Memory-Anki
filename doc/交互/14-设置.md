## 一、复习与偏好 `/profile`

三个页签。

### 复习与调度

- **外观**：浅色 / 深色 / 跟随系统。说明「只对这台设备生效，桌面和手机可以各自设置。」沉浸舞台不受影响，固定深色。
- **宫殿复习排期**：一张说明卡，讲清目标记忆率、最长间隔、新学两段定锚与四档评分的语义。这里**不改参数**，只是解释。
- **待换题自动检测**：累计作答次数、连续答对次数、本次作答耗时（秒）→ `保存检测规则`。说明「只负责提醒，不改变复习排期。」默认 3 / 3 / 5 秒。

### 快捷键

`翻卡快捷键`：翻卡 / 收卡 / 上一张 / 下一张 / 隐藏子级知识点，录制即保存。空格、方向键、PageUp/PageDown、W A S D 是固定键，不可占用。

### 本机运行时

- **数据库位置** + `保存` + `修改后请重启应用。`
- **PWA 更新**：说明 + `手动更新 PWA`。
- **数据迁移入口已移动** → `打开迁移与导入导出`（跳到备份页）。

## 二、复习提醒 `/profile/reminders`

Bark 推送。每一类都有 `预览`。

| 区块 | 能改什么 |
|---|---|
| 推送通道 | 启用、Bark 地址、`清除`、`发送测试通知`、通知图标 |
| 每日两次 | 早上概览时间（`错过后 12:00 前开机补发`）、晚上催促（`只在今天还没复习时发；23:00 前开机补发`）、到期阈值 |
| 闲置拉回 | 停下来就叫你、多久算停下、升级间隔、最多提醒几次、只在今天动过之后盯防 |
| 到期就绪 | 攒够多少张才提醒、两条之间至少隔多久 |
| 整点小结 | 开关与时段 |
| 免打扰 | 免打扰时段、每日上限，并预估 `按当前设置，今天最多还会收到 N 条` |
| 通知内容 | `具体数字` / `模糊文案` |
| 当前状态 | 下次提醒、今天已发、最近一次；说明「提醒由电脑上的 Memory Anki 服务发出…」 |

## 三、反馈中心 `/profile/feedback`

- 声音反馈总开关。
- `试听答对` / `试听答错`。
- `当前组合`：单一风格 / N 种风格等概率混合。
- `全局音量` 滑杆。
- 三张音色卡（复选，至少保留一种），每张可 `试听这套`。
- `恢复默认`。
- 自动保存：`正在保存…` / `已保存` / `保存失败…`。
- 说明：`勾选的风格会随机轮换，同一段连弹不中途换声。`
- 屏幕震动、动效强度、场景音量按默认值参与，不在这页编辑；系统「减少动态效果」永远优先。

## 四、AI 管理 `/profile/ai`

五个页签：`接入 / 模型 / 场景 / 提示词块 / 观测`。

- **接入**：概览（Provider 数 / 活跃模型数 / 场景数 / 最近成功调用）；各 Provider 的 API Key、测试连接、全部临时停用。
- **模型**：模型目录，可按 Provider / 类型 / 来源 / 能力筛选；新增与编辑（key、显示名、价格、视觉、思考、温度）；显示「被场景使用 N / 最近调用」；删除前说明影响。
- **场景**：场景分类、默认模型与思考、批量切换、单个场景恢复默认；显示「已单独配置 / 当前生效 / 最近调用」。
- **提示词块**：按场景列出提示词块与预估 Token、推荐、场景特殊提示词、编译结果、版本历史、`设为以后默认`；共享块显示影响多少个场景。
- **观测**：近 7 / 30 天用量与错误、修复率、分类错误；调用日志（按 Provider / Model / Feature / 状态筛选，可看详情）。

AI 只为内容生产与整理服务；答题时的 AI 出题、讲解、纠错、自由提问已关闭，不会在作答中突然调用模型。

## 五、数据与备份 `/profile/backups`

四个页签。

**备份与恢复**
- 说明「自动和手动备份都只保存 SQLite 进度库…」，附运行目录与覆盖项。
- `立即备份`。
- 备份列表：类型筛选（全部 / 整库备份 / 数据库备份 / 事故快照）、搜索、内容 chip（数据库 / 附件 / 英语数据）、路径与覆盖项；`整库恢复`，或标注「该快照不含数据库」。

**迁移与导入导出**
- `JSON 导出 / 迁移`、`Markdown 导出 / 迁移`、`全库 zip（含附件）`。
- `导入宫殿（JSON / Markdown）`：`追加导入，不会清空现有数据。`

**回收站**
- 题目回收站：预览、恢复、永久删除、清空。

**危险区**
- `导入全库 zip`：会清空当前设备全部数据。导入前先校验文件结构、显示数据摘要，并自动建一份逃生备份。
