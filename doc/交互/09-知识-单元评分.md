# 09 · 知识 · 单元评分

> 路由 `/palaces/:id/units`，从编辑器左侧「单元评分」进入。
> 最后核对：2026-11-24。

---

## 它解决什么

在编辑器里顺手回忆过的单元，如果不在随心再问一遍，就白回忆了。这一页把「编辑时看到的」直接转成一次正式评分。它也是唯一一个**只看一座宫殿、只看今天到期**的评分入口。

## 版面

左栏「复习单元」列表，右栏只读脑图 + 进度条 + 评分条。

```text
┌── 页头：← 返回编辑   单元评分 · 宫殿名 ──────────────┐
├──────────────┬───────────────────────────────────┤
│ 复习单元      │  只读脑图（只显示这个单元范围）        │
│ 12 个·今日到期 3│  [复习进度条：等级 4 · 间隔 7天]     │
│ ─────────    │  12 个节点 · 记忆等级 · 下次到期      │
│ 北宋三次兴学  │                                   │
│ 今天到期      │  [忘记] [困难] [记得] [轻松]         │
└──────────────┴───────────────────────────────────┘
```

## 左栏

- 标题 `复习单元`，副行 `12 个 · 今日到期 3`。
- 每行：单元标题 + `今天到期` 或 `间隔 X天` + 到期日。
- 空态：`这座宫殿还没有复习单元。标记永久标记后会出现。`

## 右栏

- 脑图只读，保持原有布局，只显示该单元范围。
- 工具栏中间是**复习进度条**：当前档位，可拖动调整档位或选精确日期；改动要点「应用」才写。说明原文：`只改排期，不改记忆评估；下次评分会按新间隔继续。`
- 标题行：`N 个节点 · 记忆等级 · 下次到期`。
- 底部四档评分条，与随心同款，每档预览评分后的间隔影响。

## 规则

- **只有到期的单元才能评分。** 未到期时按钮禁用，并说明 `这张卡 X月X日 才到期 · 可在上方进度条调整进度`。
- 没选单元时提示 `先选择一个复习单元`。
- 打开评分会开一次真实的回忆会话；切走未评分会被取消，已评分则关闭。
- 保存失败：`保存评分失败`。

## 与随心的关系

在这里评过的单元，本轮不会再问你第二次——随心看到的已经是「已评分」。这也是这条路径存在的意义：把编辑时已经付出的回忆变成证据，而不是浪费。
