# 08 · 知识 · 编辑器

> 路由：`/palaces/new`（新建）· `/palaces/:id/edit`（编辑）· `/knowledge`（知识树编辑器）
> 最后核对：2026-11-24。

---

## 一、新建宫殿 `/palaces/new`

页头 `新建宫殿`，右上 `从模板创建`。

表单：
- **宫殿名**：占位 `例如：教育心理学核心理论`。说明「首次关联主章节后名称会跟随主章节；手动改名后转为手动名称。」
- **所属学科**：多选，已选显示数量；可搜索；每科旁 `编辑导图`（→ 知识库）；下方 `管理学科思维导图`；还可以当场 `新建并选择` 一个学科。
- 主按钮 `创建并进入编辑器`。未填名或未选学科时禁用，并说明 `请先填写宫殿名。` / `请至少选择一个所属学科。`

**从模板创建**：弹窗 `从模板创建宫殿`，输入「新宫殿标题（留空则使用模板名）」，下面模板列表，右键 `使用模板` / `删除模板`。空态：「还没有宫殿模板 / 先打开任意宫殿，在编辑页点“存为模板”。」

## 二、编辑器 `/palaces/:id/edit`

### 版面

```text
┌──── 页头：宫殿标题 · 存为模板 · 状态徽章 ─────────────┐
├────────────┬──────────────────────────────────────┤
│ 单元评分    │  脑图工具栏：搜索 永久标记 ⋯ 全屏      │
│ ─────────  │                                      │
│ 宫殿目录树  │           脑图画布                    │
│ （学科→章节）│                                      │
└────────────┴──────────────────────────────────────┘
```

从随心进来时页头左上多一个 `返回随心`。

### 保存

自动保存，没有「保存」按钮。页头徽章四种状态：`保存中` / `未保存` / `保存失败` / `已保存`。内容先写本地草稿，关页或刷新后可恢复。

### 左侧

- 顶部 **单元评分** 入口，副文案随状态变：`按单元评分与调整进度` / `N 个今天到期` / `N 个复习单元` → `/palaces/:id/units`。
- 下面是宫殿目录树（学科 → 章节 → 宫殿），可拖拽把宫殿绑定到章节。拖到别的学科会确认：`「X」将移动到另一个学科，它原有的学科关联会被替换。继续吗？`
- 目录本身有收起轨道，不跟随应用侧栏。

### 脑图工具栏

- 全局宫殿搜索（打开记忆宫殿查找）、聚焦节点、全屏/沉浸、清屏、适应视图。
- **永久标记 / 退出永久标记（已标 N）**：进入标记模式后点节点即标记，级别自动推导（L1/L2/…），标记即保存。
- `⋯` 菜单：`恢复点` · `复习进度` · `结构检查（N）` · `复制导图` · `文字转脑图` · `题库结合`。
- 构建 / 学习两种模式切换；学习模式只读，并出现三张入口卡：`主动回忆`、`开始随心复习`、`做题训练`。

### 永久标记与复习单元

- 标记即成为独立排期的复习单元。
- 退出标记模式时提示 `已退出永久标记（已标 N）；复习进度整理中`。
- 节点上的标记 chip 可点开「复习单元」摘要：范围 N 节点、记忆等级、下次到期、`去评分`。
- 在随心轮次内临时标记不写进文档。

### 题库结合

弹窗里手动把题目绑到脑图节点（可搜索节点）。保存后节点显示题目数徽章与完成进度色，点徽章直接打开该节点的做题窗口。

删除仍带绑定题目的卡片时，先弹「题目去向」，必须逐题重新安置或丢弃才能删。

### 导入与导出

- **文字转脑图**：读剪贴板或粘贴 JSON / 缩进大纲，或选 `.json/.txt/.md` 文件；`解析为脑图草稿`。支持 source-tree JSON、导出 JSON、编辑器文档 JSON、Markdown 大纲。生成后提示 `已生成草稿，共 N 个知识点（手动导入，未调用 AI）`。底部：`撤销最近一次导入` / `追加到选中知识点` / `应用到宫殿（覆盖）`。
- `复制提示词`：给外部工具整理格式用。
- **复制导图** / **导出脑图**：导出文件，成功 `脑图已导出`。

### 恢复点

弹窗 `宫殿恢复点`：每条写 `自动恢复点 / 触发原因 · 时间 · 恢复点 #id`，可 `预览`（只读看整张图）或 `恢复这个版本`。空态 `当前还没有可恢复的有效快照。`

### 结构检查

`结构检查（N）` 列出可疑结构，例如节点标题过长会提示「节点标题 N 字，建议拆分」。

## 三、知识树编辑器 `/knowledge`

维护「学科 → 章节」的骨架，不编辑宫殿内容。

**页头**：`知识树编辑器` + `返回学科书架` + 保存状态徽章。

**左侧「学科」栏**：
- 学科列表（带色块）；右键：`打开学科书架` / `在知识库编辑章节` / `在此学科新建宫殿` / `重命名` / `删除学科`。
- 底部输入框 + `创建学科`。
- 当前学科：名称、颜色、`保存学科信息`、`删除`。
- 当前章节：名称、面包屑、备注、`删除章节`；关联宫殿列表每行带复习徽章、`到期/总 单元`、`查看宫殿`；底部 `开始随心复习`。

**画布**：
- 任务切换 `构建 / 学习`（学习模式只读）。
- 画布内搜索：`定位结果`、`适应视图`。
- `⋯`：`结构检查（N）` / `沉浸模式` / `原生全屏` / `清屏`。

**删除保护**：
- 学科还有内容：`该学科仍包含 N 个章节并归属 N 个宫殿，请先调整宫殿归属并清理章节。`
- 章节：`该章节及其子章节共 N 个，关联了 M 个宫殿、K 道题目。删除后题目将一并删除且不可恢复，确定删除吗？`

两边共用同一棵目录树：改名、移动在任一侧做，另一边同步。
