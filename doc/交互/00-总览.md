# 交互总览

> 这一组文档按页面拆开写：每份说明「这一页有什么、怎么用、什么状态下显示什么」。
> 只写产品可感知的行为与文案，不写技术实现。产品需求见 [../PRD.md](../PRD.md)。
> 最后核对：2026-11-24。

---

## 1. 产品骨架

五个一级入口，顺序固定：

| 入口 | 地址 | 这一区回答的问题 |
|---|---|---|
| **随心** | `/freestyle` | 现在该学什么，以及学得怎么样 |
| **知识** | `/palaces` | 我有哪些宫殿，每一座现在什么状态 |
| **英语** | `/english/listening` | 听写与完形练习 |
| **创建** | `/palaces/new` | 新建与改一座宫殿 |
| **进度** | `/dashboard` | 整体走到哪、离考试还差多少 |

个性设置不在主导航里，从侧栏底部的「设置」进入（`/profile` 系列）。

打开产品时，如果有上次停留的页面就直接回到那里；否则进入随心。旧的今日工作台、成长页、随心 2 等入口都已经并入上面五个，访问旧地址会落到对应新页面，不出现空白页。

## 3. 跨页面一致的约定

**外壳**：左侧是书脊式导航（可收起，宽度可拖拽，双击恢复默认），手机换成底部标签栏。进入沉浸复习后，外壳退让，界面只留下内容与评分。

**位置记忆**：每个一级入口记住上次停留的页面，切换回来继续在那里；从列表进详情再返回，滚动位置与展开状态保留。

**加载与失败**：页面先给结构骨架再填内容，不用空白屏；单块数据读取失败只影响那一块，其余照常可用，并给「重试」。随心开始页尤其明确：概览读不到时仍然可以直接开始学习。

**空态**：每种空都有自己的说法与下一步，例如没有到期内容时按钮写「暂无需要学习的内容」，列表无内容时说明为什么空，而不是只显示 0。

**保存**：编辑与复习都是自动保存，界面显示「保存中 / 已保存 / 保存失败，重试」。任何失败都可以原地重试，不会把已输入的内容丢掉。

**多设备**：同一轮、同一座宫殿在两台设备上打开时，以先确认的写入为准；后写入的会被提示冲突或「同步进度」，不静默覆盖。

**键盘**：主要动作都可以只用键盘完成，焦点环始终可见。输入框与脑图编辑器取得焦点时，学习快捷键自动让路；空格固定为「下一张 / 下一题」，在控件上时仍然激活控件。

## 4. 反馈语言

产品用同一套反馈词汇贯穿所有页面：

| 动作 | 反馈 |
|---|---|
| 翻卡落定 | 一次轻响 + 卡片弹一下；翻卡徽标跳一下 |
| 评分提交 | 四档不同的手感；连击越高越亮 |
| 一个单元翻完 | 更高的一声收尾铃 |
| 撤销评分 | 短促回落音 |
| 进度跨过 25% / 50% / 75% | 音高逐级上升，进度线上闪一下 |
| 移出卡片 | 卡片被抽走的轻响 |
| 本轮完成 | 一次压印式的完成动效，全页只此一次 |

声音、屏幕震动、动效都可以分别调；系统开启「减少动态效果」时，所有动效自动降级为静态但保留声音和颜色反馈。
