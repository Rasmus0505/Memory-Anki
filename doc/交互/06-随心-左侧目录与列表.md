## 面板本身

- 有自己的收起轨道：可折叠成一条窄轨，也可以完全收起。
- 收起/展开互不影响：收起应用侧栏不会带走它，收起它也不会影响应用侧栏。

## 一、目录

### 结构

学科 → 章节 → 宫殿，与脑图编辑器同一棵树。每级可折叠；收藏的宫殿带黄星；章节、学科也可带状态点。

### 状态点：颜色即进度

本轮还在队列里的宫殿，行尾有个小圆点：

| 颜色 | 含义 |
|---|---|
| 蓝 | 还有没评分的卡 |
| 琥珀 | 有卡待重练 |
| 绿 | 本轮都评过了 |

父级（章节、学科、未分类栏）不自己判断，只取子级里**最低**的那个状态：只要底下还有一张没评分的卡，整条折叠着的分支就是蓝的。所以「这一章还剩什么」不用展开就能看到。

当前卡片所属宫殿另有一处整行主色高亮，与其他宫殿区分。结算和移除的卡不在分段里，宫殿随之消失。

### 点宫殿的四种结果

| 情况 | 结果 |
|---|---|
| 就是当前卡所在宫殿 | 不动 |
| 在单宫复习页（`/palaces/:id/review`） | 继续以宫殿复习路由打开另一座宫殿 |
| 已在本轮、还有未评分的卡 | 跳到它最早一张未评分卡 |
| 已在本轮、但每一张都评过了 | 弹窗「本轮已评完」，给「重新评分」（把已评分卡放回队列），并提示跳到它最后一张 |
| 已标记、今天到期、但不在本轮 | 弹窗询问加入：`「X」不在本轮。加入后，今天到期的单元排进队列，以后每轮都包含它。` → `加入本轮` / `单独编辑` / `取消` |
| 还没标记 | `标记会把整座宫殿作为一个复习单元，并加入本轮。` → `标记并加入` |
| 已标记但今天不到期 | `「X」下次复习 M月D日。` → `知道了` / `单独编辑` |
| 没有可用的复习单元 | `「X」没有可用的复习单元。` → `知道了` |

加入的动作是**并集**：今天到期的单元追加到队尾，不重排已有卡，并持久化到随心设置，以后每轮都包含它。加入后 8 秒内没排进来，提示 `还没排进来：可能不在「新学 / 复习」范围，或队列仍在更新`。

「单独编辑」跳到编辑器（带返回随心的入口），不加入、不改本轮范围，回来继续原来那一轮。

### 折叠与滚动

只有第一次拿到当前宫殿时展开它的祖先路径，之后翻卡不再改折叠状态、也不再滚动列表。这样快速翻页时目录不会一直跳。

## 二、随心列表

本轮卡片的可编辑清单。

### 头部

- 搜索框：`搜记忆点或宫殿`。
- 状态标签：`待评分 N` · `已移出 N` · `已评分 N` · `全部`。
- 宫殿下拉：`所有宫殿` + 具体宫殿。
- 「全选」（已选时显示「全选 · 已选 N」）与「清空」。

### 行

序号 · 复选框 · 标题（最多两行，已移出的加删除线）· `宫殿名 · 状态`。
- 行尾小标：`当前` / `重练` / `保存中` / `未保存`。
- 状态文案：`待评分` / 具体档位（如「记得」）/ `已移出` / `待重练` / `待更新`。
- 已评分行的复选框画成勾圈；已移出行的复选框变成恢复图标。

### 排序

- 桌面拖拽抓手，手机与桌面都可用上下箭头。
- 只有「待评分且没评过」的行能移动。
- 排序持久化到本轮，只调整未评分项的位置，不动已处理槽位和当前卡。

### 批量操作

勾选后在底部出现操作条 `已选 N 项`：
- `移出本轮` / `恢复`（按选中项状态）。
- 待评分行下方出现四档按钮：`忘记` / `困难` / `记得` / `轻松`。

批量评分先确认：

> 确认批量评分为「记得」？
> 将对选中的 6 张记忆点逐张保存「记得」，并按各自的评分规则更新复习安排。
> `取消` / `确认评分 6 张`

提交后提示 `已提交 6 张，正在按「记得」保存`；没有可提交项时 `所选卡片没有可提交的评分`。

### 边界

- 列表里的选择、筛选、排序**都不改变**右侧当前卡片；只有明确点「跳到剩余卡」才会转过去。
- 已评分项只读；重练与整宫通过项保持原位置。
- 批量评分后台确认不会触发自动翻页；保存中与未保存分别显示，失败沿用原评分重试机制。

### 空态

`没有符合条件的项目` / `没有移出本轮的项目` / `还没有已评分的项目` / `本轮没有待评分项目` —— 每种空都说清是哪种空。
