# 07 · 知识 · 书架与宫殿详情

> 路由：`/palaces`（学科书架）· `/palaces/list`（单学科列表）· `/palaces/:id`（宫殿详情）· `/palaces/:id/review`（单宫复习）
> 最后核对：2026-11-24。

---

## 这一区回答什么

「我有哪些宫殿，每座现在什么状态，我要不要现在进去。」

---

## 一、学科书架 `/palaces`

### 页头

标题 `学科书架`；右上两个按钮：`知识树编辑`（→ 知识库）、`新建宫殿`。

### 检索

搜索框 `搜索学科或宫殿...`；右侧 `全部收起`。搜索时自动展开全部并高亮匹配。

### 树

`学科 → 章节 → 宫殿`，文件管理器式折叠。每一行底部一条题目占比细线，右端写百分比：学科是本学科题数占全书架比例，章节是本章题数占本学科比例，宫殿是本宫题数占所属章节比例。它衡量的是**题目绑定得全不全**，不是做了多少题。

| 层级 | 行上看到什么 |
|---|---|
| 学科 | `N 座宫殿`、到期气泡（`N 个现在可以复习` / `N 个今天稍后可以复习`）、`打开这本书` |
| 章节 | 宫殿数、到期数 |
| 宫殿 | 收藏星、考试重要度 1–3 星、`到期/总 单元`、复习 chip、`做题N`、`•••`（复习进度 / 删除） |

### 宫殿的复习 chip

| chip | 含义 | 点击 |
|---|---|---|
| `开始标记` | 还没钉永久标记，不会出现在今天的复习里 | 进编辑页的标记模式 |
| `立即复习` | 今天有到期 | 进单宫复习 |
| `X月X日复习` | 还没到复习日，今天不会出现 | 禁用，说明下次日期 |

tooltip 原文分别是「还没标记，不会出现在今天的复习里」「还没到复习日（X月X日），今天不会出现」「今天有 N 个到期，会出现在今天的复习里」。

### 空态

没有宫殿时：
> **先从一本书开始**
> 把一个章节建成宫殿：导图就是复习单元，之后每天回来翻卡。
> 01 新建宫殿，绑定一个章节 · 02 在导图里写下知识节点 · 03 回到随心，开始第一次翻卡
> `[ 创建第一个宫殿 ]`

搜索无结果：`没有匹配的学科或宫殿 / 换一个关键词试试。`

## 二、单学科列表 `/palaces/list`

书架里点「打开这本书」进来。区别：

- 只显示这一个学科（或「未分类」），顶部有记忆阶梯。
- **记忆阶梯**：按间隔档位分段（首学 / 1–2 天 / 3–6 天 / … / 365 天以上）显示宫殿分布，点某一档即筛选；筛后显示 `「3–6 天」：下方只显示这一档的 N 座宫殿 · N 个记忆单元` + `查看全部`。
- 树隐藏学科行，默认展开。
- 空态分开说：`「X」间隔段没有宫殿` / `没有匹配的记忆宫殿` / `这个书架还没有宫殿`。

## 三、宫殿详情 `/palaces/:id`

页头：`宫殿详情` + 标题 + 徽章 `只读脑图`。

**主画布**：只读脑图。节点上显示题目占比徽章与复习进度色。点节点进入行内回忆（就地翻卡揭示），右键同款菜单。

**顶部工具栏**：`做题`（打开做题窗口）、`半屏编辑`、`全屏编辑 / 退出全屏`、`清屏 / 恢复界面`。

**右侧「宫殿信息」面板**（可收起）：
- 概要（没有描述时 `当前宫殿没有补充描述。`）
- 关联章节（空时 `该宫殿还没有关联章节。`）
- 附件（点击新窗口打开；空时 `没有附件。`）

冲突时弹文档冲突对话框，让学习者选保留哪份。

## 四、单宫复习 `/palaces/:id/review`

书架上的「立即复习」打开这里。它**复用的是同一个随心信息流**，只是把范围瞬时锁在这一座宫殿：

- 使用独立的轮次工作区，不写入全局随心选择。
- 自己保存的随心宫殿/学科选择不会被它覆盖，反过来它也不改偏好。
- 页眉「更多」里会多一项 `返回书架`。
- 没有独立的完成页——结算与随心一致。

另外两种进入复习的方式不同：
- 编辑器里的「开始随心复习」→ `/freestyle?palaceId=<id>`，这是有意的随心启动，会写回随心范围。
- 记忆阶段复习可以一次带多座宫殿进来，在一轮内锁定，保存时仍写回已存储的随心选择。

## 五、右键 / 长按菜单

书架、列表、搜索命中、考试知识地图上的宫殿块共用一套菜单：

**打开** · **单独编辑** · **复习进度** · **做题** · **开始随心复习** ｜ **重命名** · **移动到…** · **收藏 / 取消收藏** · **复制链接** ｜ **删除宫殿**

删除确认：`删除宫殿「X」？脑图、章节绑定和练习记录会一起删除。`

章节：`在此章节新建宫殿` / `开始随心复习` ｜ `重命名` ｜ `删除章节`
学科：`打开学科书架` / `在知识库编辑章节` / `在此学科新建宫殿` ｜ `重命名` ｜ `删除学科`

触屏长按打开同一菜单；菜单打开时行保持高亮；行的单击行为不变。
