# 01 · 随心 · 开始页

> 路由 `/freestyle`。它是一层全屏覆盖层，标题 `今天的学习`，右侧是当天日期。
> 出现时机：每次进入随心页面时先出现（点「开始学习」关掉）；以及结算并开下一轮、但当天已经没有内容时。
> 其中「昨日回顾」卡片每天只出一次，点「知道了」后当天不再出现。
> 最后核对：2026-11-24。

---

## 这一页回答什么

「今天到底有多少活，值不值得现在坐下。」一屏之内给数字、给最近的截止、给昨晚的结果，底部只有一个按钮。

## 版面

桌面两栏，手机单栏（380px 以下数字区改为上下排列）：

```text
┌──────────────────────────────────────────────┐
│ 待复习         │ 近期里程碑  08/12 3 天后 …   │
│ 8 座 / 63      │ 昨天的回顾                   │
│ ───────────    │ 学了 5 座 / 31 个            │
│ 第一次学       │ 还比较薄弱                   │
│ 2 座 / 12      │ 北宋三次兴学 · 忘记 60%      │
├──────────────────────────────────────────────┤
│ 本轮还剩 42 个单元                            │
│            [ 开始学习 ]                       │
└──────────────────────────────────────────────┘
```

## 元素与文案

| 元素 | 内容 | 说明 |
|---|---|---|
| 待复习 | 「宫殿 / 复习单元」两个数字，衬线大字 | 有到期时数字用主色，没有时保持弱化 |
| 第一次学 | 同样两个数字 | 有内容时用苔绿，没有时弱化 |
| 近期里程碑 | `08/12 3 天后 英语四级` 这样的行，按日期分组 | 没有里程碑时整块消失，不占位 |
| 昨天的回顾 | 「学了 5 座 / 31 个」＋最多 3 条薄弱单元 | 薄弱行右端写「忘记 60%」，用朱砂色 |
| 昨日回顾卡片 | 独立可关闭的卡片，右上角「知道了」 | 关闭后本日不再出现；包含同样的薄弱列表 |
| 续轮提示 | 「本轮还剩 N 个单元」或「按今日到期顺序开始」 | 只有本轮还没结束才出现 |
| 主按钮 | 「开始学习」 | 无内容时改为「暂无需要学习的内容」并禁用 |

## 状态

**首次读取中**：数字区显示占位，按钮已经是「直接开始学习」——不让人等数据。

**读取失败**：整块换成一句「概览暂时读取失败，仍可直接开始学习。」加两个动作：「直接开始学习」与「重试概览」。这一页永远保留直接开始的路径。

**没有需要学习的内容**：按钮写「暂无需要学习的内容」并不可点。不跳空页，不给鼓励语。

**本轮未完成**：按钮写「开始学习」，上方一行「本轮还剩 N 个单元」，点进去继续原来那一轮，不会新开。

**昨天没有记录**：回顾区写「昨天没有学习记录」。

## 交互

- 点「开始学习」：关掉这层概览，直接进入本轮信息流（接着当前那一张，不会新开轮）。要改范围与顺序，用页眉的「随心配置」。
- 点里程碑条目：跳到对应考试（进度 → 考试作战室）。
- 「知道了」关掉昨日回顾卡片；概览里的回顾块仍在。

## 不做什么

- 不放鼓励语、不放连续打卡天数。
- 不在没内容时把按钮变成「去逛逛」，只说明没有内容。
- 概览失败不升级成整页错误。
