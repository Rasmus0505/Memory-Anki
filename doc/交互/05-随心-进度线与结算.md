# 05 · 随心 · 进度线与结算

> 页眉那条细线是整轮的地图；最后一页是这一轮的收据。两者说的是同一件事：这一轮走到哪、还剩什么。
> 最后核对：2026-11-24。

---

## 一、进度线

### 形状

一卡一格，横向铺满页眉。每格是细竖线：

| 状态 | 表现 |
|---|---|
| 已评分 | 填实色 |
| 未评分 | 淡色 |
| 当前卡 | 更大 + 描边呼吸 |
| 新学 | 蓝 |
| 复习 | 琥珀 |
| 关联题答错 | 红；题目改对后立即消失 |
| 关联题全对 | 绿 |
| 重练 | 圆圈节点，圈里写这是第几次重练 |

位置读作 `29/55`；跨学习日时附「跨了 N 天」。

### 学习日分界

今天之前进入这一轮的卡整体变暗，今天的起点有一条亮线并写「今天」。悬停分界处提示 `昨天 · 还剩 3 张 · 点此跳到这一天的第一张`。

### 操作

- 点某一格：跳到那张卡。
- 点线外空白：打开「随心配置」。
- 上下滑卡片时，线上的播放头**跟着手指走**，不跳到别处；手指停下才落位。
- 评分后的重排只把视口钉回当前卡，播放头跟着回到这张，绝不因此换卡。
- 刻度太密时自动收成可跟随的滑块形态。

> 调整某张卡的下次复习档位不在线上做，而在卡片脑图工具栏中间的「复习等级条」上做（见 [03 篇](03-随心-复习卡与翻卡.md)）。

### 四分之一标记

本轮格数 ≥ 8 时，跨过 25% / 50% / 75% 会浮出标签 **四分之一** / **过半了** / **最后四分之一**，约 1.6 秒，音高逐级上升，线上脉冲一次。手机上标签居中在页眉下方，不挡卡面。

### 横幅

两种一过性横幅，出现后点一下关闭：
- 宫殿清空：`《宫殿名》今日到期已清`（还有剩余时写「今日到期已清，还剩 N」）。
- 新学完成：`今日新学已完成，接下来只复习`。每轮最多出现一次。

## 二、页眉与「更多」

页眉除进度线与轮次计数外，右侧有两个按钮：**随心配置**（齿轮）与**更多**（⋯）。

「更多」菜单：

| 项 | 行为与提示 |
|---|---|
| 更新队列 | 按最新到期重排本轮，保留已评分。`已经是最新的` / `某宫殿多了 N 张 · 少了 N 张，已评的还在` / 编辑中时 `先退出这张的编辑，再更新队列` / 失败 `没能更新队列，请再试一次` |
| 本轮摘要行 | 只读，写 `导图 N · 候选 M`（空轮时 `本轮 0 张 · 候选 M`） |
| 同步进度 | 从另一台设备拉本轮：`电脑还没有这一轮进度` / `已同步电脑进度，还有 N 张未评分` / `已同步电脑进度，这一轮已经评完` / `同步失败，请确认手机连的是这台电脑` |
| 历史 | 打开「随心历史」 |
| 返回书架 | 只在单宫复习时出现 |
| 切换模块 | `知识` / `英语` / `创建` / `进度` |

**随心历史**弹窗：
- 顶部三块摘要：`新记录`（做题与讲解数）· `旧题库统计`（已答/总题 · 次数）· `旧 AI 日志`（条数 · 讲解数）。
- 筛选：`全部` / `当前宫殿` / `当前题`；有刷新按钮。
- 每条记录：`正确` / `错误` / `已提交` 徽章、`今日训练` 或 `自由随心`、宫殿、时间、题干、答案摘要。
- 空态 `还没有做题记录`。

## 三、右侧翻页列

自上而下：**上一张** · **下一张** · **完成**。

**上一张 / 下一张**：一次一页；到边界继续拉会有回弹，并提示 `已经是第一张` / `已经是本轮最后一张`。

**完成**永远先找出「下一件该做的事」，文案随情况变：

| 情况 | 按钮文案 | 点了去哪 |
|---|---|---|
| 还有未评分卡，当前不在未评分卡上 | 定位到最早还没评分的单元 | 最早一张未评分 |
| 当前已在未评分卡上，且还有别的 | 定位到下一张还没评分的单元 | 下一张未评分 |
| 有未完成的重练 | 定位到最早的重练 / 定位到下一张重练 | 最早一张重练 |
| 全部评完、但还有没到点的重练 | 去看还没到点的重练 | 等待页 |
| 全部结束 | 进入本轮结算 | 结算页 |

完成按钮不会把人带进死路：每种情况都有去处。

## 四、等待页

出现条件：能做的卡都评完，但今天还欠着没到点的重练。此时最后一页不是奖杯。

```text
              ⏱
        还有 3 张重练
   21:40 到点 · 剩余 40 分钟，到点自动回到队列
        本轮已评分 32 个单元

          [ 回去等它们 ]
          [ 今天到此为止 ]
   今天到此为止会结束本轮，这些重练今天不再安排。
```

- 到点后标题行改为 `21:40 已到点，正在取回`，队列自动刷新。
- 时间未知时写 `稍后自动回到队列`。
- 「今天到此为止」是一次**显式取舍**，说明写在按钮下面，不藏在确认框里。

如果整轮卡片列表已经被清空、只剩等待项，则显示独立等待态：`还有 N 张要稍后再看` / `最早 21:40 到点；到点会自动回到队列，先不用手动刷新。` / 按钮 `21:40 后可刷新`，到点变 `现在刷新`。

## 五、结算页

### 版面（自上而下）

1. `返回上一张`（取消结算，回到最后一张卡）。
2. 奖杯圆环：环按本轮已评/涉及单元填充；右上一枚小节点写「跳过」（跳过庆祝音效与动效）。
3. `本轮完成` + 大数字 `N` + `个单元`。
4. 摘要一行：`新学 8 · 复习 24 · 3 个宫殿 · 32 个单元`。
5. 若有宫殿今天清空：绿色胶囊 `2 个宫殿今日已清`。
6. 三格统计：**已通过**（绿）· **新学**（琥珀）· **重练**（赭）。
7. `宫殿总进度`：`32 / 55 单元 · 58%` + 进度条。
8. 保存状态：`数据已保存成功` / `保存失败，数据未改动`（可重试）/ `正在确认保存结果…` / 冲突时说明「另一处已更新这一轮，请刷新后再结算」。
9. 状态行（拼成一行）：`还剩 2/9 待下一轮`（或「本轮已全部完成」）· `今日还剩 12 → 5 复习单元` · `明天 7 个复习单元要复习`。
10. 两个动作（并排）：**清空做题进度** / **结算**。没有做题进度时只留「结算」。
11. 折叠区：`按学科看明细（N）` → 学科下再列宫殿，各自 `X / Y · Z%`。
12. 折叠区：`下次复习（N）`，默认 6 条，可「展开全部 N 项」。

### 动作说明

**清空做题进度**：第一次点变「再点确认清空」，再点变「正在清空…」→「已清空做题进度」。成功后一行说明 `已清空做题进度，学习历史和复习安排保持不变。` 失败写 `清空做题进度失败。`

**结算**：结束本轮，并按当前配置开下一轮；今天已经没有内容时回到「今天的学习」开始页。结算不会把上一轮的评分带进新轮。

### 动效

全页只安排一次：数字从 0 滚上来（约 1.1 秒），圆环画一圈，奖杯弹出，朱砂小印证一下。任何一次点击都能跳过；系统开了「减少动态效果」则全部静态，只保留颜色与文字。

## 六、小结算（结算已完成单元）

在「随心配置」底部：`结算已完成 N`（没有可结算时写「没有可结算的」并禁用）。

确认弹窗：
- 标题 `结算已完成`，副标题 `12 张 · 2 个学科 · 3 座宫殿`。
- `内容`：新学 / 复习。
- `结果`：通过 / 重练。
- 按学科列出 `2 座 · 5 张`。
- 按钮 `取消` / `结算这 12 张`。

它的效果是**分母变小、本轮继续**：这些卡离开进度线、滑屏和随心列表，不出现庆祝动效。和结算页的区别是「这只是账本收一行」，不是「这一轮结束了」。

## 七、页级异常

| 情况 | 界面 |
|---|---|
| 队列加载失败 | `队列加载失败` + `重试` / `复制诊断` / `清理 PWA 缓存` |
| 本轮暂时没有可刷的卡 | 说明 `本轮已完成 N · 已隐藏 N · 少看 N 座宫殿。可以改范围或等新的到期。` + `去改配置` |
| 今天没有到期 | `今天没有到期。点顶上进度可以改配置。` |
| 多张卡已在其他设备复习 | `多张卡片已在其他设备复习，或内容刚被改过` + `跳过这张` / `重建队列` / `打开配置` |
| 某次评分没存上 | 页眉附近 `N 项没存上 · 点此重试`；翻走后提示 `第 N 个单元没有保存成功` + `回到这张` |
