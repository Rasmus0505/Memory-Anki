# 16 · 全局 · 运行、跨设备与提醒

> 这些不在界面里点，但决定了「数据会不会丢、手机上能不能接着学」。写成产品语言，参数见技术文档。
> 最后核对：2026-11-24。

---

## 一、数据在哪

- 学习数据（宫殿、题目、评分、做题记录、随心轮次）存在**本机的数据文件夹**里，不上云、不建账号。
- 附件（PDF 资料、英语视频）也在本机，体积大但不常变。
- 应用本身不搬文件；跨设备靠应用外的一次同步动作完成。

## 二、手机怎么用

- 手机不是另一套 App，而是通过私有网络打开**同一套界面**，默认落在随心。
- 首次访问后在浏览器里「添加到主屏幕」，之后像普通应用一样打开。
- 电脑和手机同时打开时，随心的当前卡与翻面会互相跟随，不需要手动刷新任一端。
- 手机断开电脑时，随心给出明确提示（如「同步失败，请确认手机连的是这台电脑」），不假装成功。

## 三、跨设备同步学习进度

**一次只有一台设备在学。** 同步是「整份替换」而不是「合并」，两台同时学，后同步的那台会覆盖先前的进度。

操作上只要记住三步：

1. 学完，关掉页面，停止服务。
2. 等两边的同步都显示完成。
3. 在另一台电脑启动，重新打开随心，本轮会重建。

**同步什么**：宫殿、脑图、题库与题目绑定、复习状态、评分与做题记录、随心轮次与偏好。
**不同步什么**：PDF 资料、英语视频、日志与历史备份。

**三道护栏**（产品上表现为提示，而不是隐藏行为）：

| 时机 | 护栏 |
|---|---|
| 上传前 | 远端比本机上次同步更新 → 先提醒，不直接覆盖 |
| 下载前 | 本机上次同步后又有新的学习记录 → 先提醒 |
| 导入前 | 程序版本不一致 → 拒绝并说明先升级 |

导入是一次完整替换，失败会回滚；附件不参与校验，缺 PDF 时题目照常能做，只是打不开资料。

## 四、备份与恢复

三层：

1. **自动备份**：启动、关闭与周期性进行。只备份进度数据库。
2. **救援快照**：关键或危险操作前自动留一份。
3. **宫殿版本快照**：编辑器里「恢复点」，可以预览整张图再决定是否恢复。

手动入口在 `设置 → 数据与备份`：`立即备份`、整库恢复、JSON / Markdown 导出与导入、全库 zip。
「导入全库 zip」是危险区：会清空本机全部数据，导入前先校验文件结构、显示摘要，并自动留逃生备份。

**回收站**：删除的题目先进回收站，可以预览、恢复或永久删除。

## 五、提醒

提醒由电脑上的服务发出，手机通过推送收到，不需要手机一直开着应用。

四类提醒可以分别调：

| 类型 | 什么时候来 |
|---|---|
| 每日概览 | 早上固定时间（错过后中午前开机补发） |
| 晚间催促 | 只在今天还没复习时发 |
| 闲置拉回 | 停下来了就叫你，并逐级升级 |
| 到期就绪 | 攒够一定数量的到期卡才提醒 |

另有整点小结、免打扰时段与每日上限；通知文案可选「具体数字」或「模糊文案」。设置页会直接预估「今天最多还会收到 N 条」。

## 六、失败时的态度

- 保存失败：说清楚「数据未改动」并给重试，不让人猜。
- 同步冲突：给出选择，不静默取舍。
- 队列过期：说明「已在其他设备复习，或内容刚被改过」，给跳过 / 重建 / 打开配置。
- 任何异常都给一条「复制给助手」的出口，不要求学习者重启应用。
