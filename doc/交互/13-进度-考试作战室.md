# 13 · 进度 · 考试作战室

> 路由 `/exam`。与今日学案、学习进度共用页内导航。
> 最后核对：2026-11-24。

---

## 这一页回答什么

「离考试还有多远，哪些章节该先补。」它负责**设置与复盘**，不在这里开始复习。

## 页头

`考试作战室`；两个按钮：`考试设置`（跳到页内锚点）、`按考试优先开始复习`（→ 随心）。

## 四格总览

| 格 | 内容 | 说明 |
|---|---|---|
| 考试倒计时 | 考试名（或 `考试倒计时`）、`N 天` / `已结束`、日期 | — |
| 当前掌握率 | 百分比 + `已学 x/y 单元` | — |
| 考前预测掌握率 | 百分比 + `若从今天起停学：X%` | — |
| 每日新学进度 | `N/天` + `学完需要 N/天` 或 `累计学习 N 天` | — |

## 记忆保留曲线

- 绿实线：过去 30 天实际通过率。
- 蓝虚线：从今天起不复习的预测保留。
- 横向 90% 目标线；两条竖线标 `今天` 与 `考试`。

## 各科进度

每科一行：`占 X%`、掌握 → 预测、双色条。空态 `暂无学科数据。`

## 知识地图

- 学科标签页（`学科 · 掌握率`）。
- 章节树 + 宫殿块，按掌握度着色（红 → 主色 → 琥珀 → 绿）。
- 每块写 `x/y 单元 · 掌握 X%`。
- 块上星级可**直接点改**（1–3 星）。星级来源标签：`手动` / `AI 写入` / `继承章节` / `按题目推算` / `未设置`。章节星级可被未单独设置的宫殿继承。
- `未归入章节` 单独一组。宫殿块右键 = 宫殿菜单。

## 星级分布

每档：`N 宫殿 · N 单元 · 掌握 X%`。规则原文：

> 未写入星级时：分值 = 题目数 + 2 × 主观题数；≥12 为 3 星，≥5 为 2 星，其余 1 星。

## 最该补的地方

按「星级 × 遗忘程度 × 学科占比」排序；行尾 `记住 X% · x/y`。

## 导图抽查

`只练不评分，不影响复习排期。`

- 选宫殿；模式 `随机抽节点` / `路径追问`。
- 节点题：`「X」下面有哪些？` + `先在心里说出全部 N 项，再展开核对` + `展开核对`。
- 路径题：`「X」属于哪一支？` 四选一 + `完整路径：…`。
- `下一题`。

## 考试设置

- 考试名称、考试日期。
- 学科勾选 + 分值占比（`不勾选 = 全部学科；占比留空 = 平均分配`）。
- `保存考试设置`。

## 冲刺

冲刺开关在进度页的「冲刺与里程碑」里（见 13 篇）。产品规则：

- 冲刺**只缩短、不延长**：任何一次复习都不会被排到考试之后。
- 该排到很远的内容被拉回考前最后一周，并按单元错开。
- 打开时会把已经排到考后的日期一次性拉回来。

## 随心里的考试信息

随心不为考试单独开一页，只借三处：

- 页眉里程碑行：`距考试 N 天` + 最近一个里程碑日；点击展开全量列表，底部 `打开考试作战室`。
- 开始页「近期里程碑」。
- 结算页考试摘要：离考试目标 / 这轮点亮 / 薄弱点 / `打开考试作战室 →`。
