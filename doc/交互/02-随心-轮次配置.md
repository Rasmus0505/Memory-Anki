# 02 · 随心 · 轮次配置

> 打开方式：页眉的「随心配置」按钮、点页眉的轮次计数、点进度线外的空白处、空态里的「去改配置」、卡片加载失败面板的「打开配置」。
> 最后核对：2026-11-24。

---

## 这一页回答什么

「这一轮练哪些、按什么顺序练。」配置与学习分开：看配置是一秒的事，改配置是一次有意为之的编辑，所以放在独立弹窗里，不与本轮列表挤在一个界面。

## 弹窗结构

标题「随心配置」。标题下一句说明原文：`保存后会询问是否保留和新配置重复的进度。保留则继续这一轮，只重排还没开始的卡片。`

再往下是一行实时摘要「本轮将这样出题」（两行：`学什么` 与 `宫殿`，随改动同步），然后左边三块「学什么」「多座宫殿时」「宫殿内顺序」、右边「宫殿」勾选树。

底部三个按钮：`结算已完成 N`（没有可结算项时写「没有可结算的」并禁用）· `关闭` · `保存配置并重排`。

### 学什么

两个可同时勾选的按钮：**新学** / **复习**，副注一行「新学＝一次都没通过过的单元。」至少保留一个——两个都关就没有东西可练。

### 多座宫殿时

三选一：
- **一个刷完再换**
- **多宫殿轮流**
- **考试优先**

### 宫殿内顺序

二选一：
- **按知识结构**
- **随机打乱**

### 宫殿

- 顶部计数：「全部 N 座」或「已选 N 座」，另有「额外 N 座」表示从目录临时加入的宫殿。
- 三个快捷按钮：**全选**、**只选到期**（没有到期的宫殿时禁用）、**重置**；存在额外宫殿时多一个**清除额外加入**。
- 下面是「学科 → 章节 → 宫殿」勾选树，可折叠；收藏的宫殿有标记。

## 保存时的分支

| 情况 | 发生什么 |
|---|---|
| 本轮还没有进度 | 直接保存并按新配置排本轮 |
| 本轮已有进度 | 先问「保留重复的进度？」 |
| 单宫复习 | 宫殿范围锁定，只显示「只复习当前宫殿」，不能改成别宫 |

**「保留重复的进度？」** 的说明原文：

> 和新配置重复的部分，已完成、已排除和重练会留在这一轮，做题已答也还在。保留则继续这一轮，只重排还没开始的卡片。不保留则按这份配置开启全新一轮，这些进度不再带入。

两个出口：**保留，继续这一轮** 与 **不保留，开启新一轮**。

收尾结算页的「结算」不走这个弹窗，它直接结束本轮并按当前配置开下一轮（见 [05-随心-进度线与结算.md](05-随心-进度线与结算.md)）。

## 本轮预览

新配置生效后，先给一张「本轮预览」：
- 标题 `这一轮将学习 N 张`；副句 `另有 N 张不在本轮，会留到之后的轮次。` 或 `本轮会包含所有待学内容，没有跳过。`
- 三个数字：`新学` / `复习` / `跳过`，新学与复习之间一条比例条。
- 宫殿分布：每座宫殿一行，写它在本轮的张数与位置。
- 学习顺序：`宫殿内按知识结构` / `宫殿内随机`，以及 `先学后复` / `先复后学` / `按比例穿插`；顺序列表可「展开全部 N 张」。
- 底部 `开始学习`。

宁可先看一眼再进卡，也不让人进去才发现这一轮只有三张。

## 小结算确认

弹窗底部的「结算已完成 N」是一次账本写入，不是仪式：
- 标题「结算已完成」，一行 `12 张 · 2 个学科 · 3 座宫殿`。
- 「内容」：`新学 4 · 复习 6`。
- 「结果」：`通过 8 · 重练 2`。
- 按学科列出 `2 座 · 5 张`。
- 底部：**取消** / **结算这 12 张**。

## 不做

- 不在配置弹窗里顺手改评分、改卡，配置只决定范围与顺序。
- 不在有进度时静默重置。
