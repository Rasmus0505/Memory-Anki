# Memory Anki 产品需求文档

> 读者：产品客户、评审者、后续接手的同学。
> 范围：只写产品**现在成立**的能力与规则；不含排期参数、算法公式、接口与实现。
> 逐页的界面与交互见 [交互/00-总览.md](交互/00-总览.md)。
> 最后核对：2026-11-24。

**全文结构**：定位 → 用户与场景 → 需求层级 → 核心闭环 → 功能需求 → 规则 → 原则 → 非目标 → 术语。
越是上层越回答「为什么做」，越是下层越回答「具体有什么」。

---

## 1. 产品定位

### 1.1 根问题

考研备考真正的难点不是「资料不够」，而是三件事同时失控：

1. **记不住**——书看完了，第二天只剩模糊印象；
2. **不知道学什么**——打开书桌，面对几百页内容无法判断此刻最该看哪一段；
3. **坚持不下去**——计划表撑不过两周，因为没有任何东西在每天结束时告诉你「今天确实有进展」。

Memory Anki 不做资料库，也不做刷题器。它把三件事收进同一张书桌：**知识先长成结构，结构自己排期，排期自己生成今天的队列，队列反馈当天的成绩**。学习者每天只需要做一个动作：坐下，开始。

### 1.2 一句话定义

> 一个把教材拆成记忆宫殿、按记忆规律逐张翻卡、并每天告诉你「现在该学哪一段」的个人学习产品。

### 1.3 三根支柱

| 支柱 | 回答的质疑 | 落在产品上的东西 |
|---|---|---|
| **方法科学** | 凭什么相信这样学有效 | 结构化的记忆宫殿、先回忆再核对、按记忆规律排期、忘记当天重练 |
| **反馈丰富** | 凭什么知道我学得好不好 | 动作级声音与动效、过程级进度与连击、结果级结算、回顾级昨日与历史 |
| **容易坚持** | 凭什么明天还会打开 | 打开即可开始、无需决策、忘记不算失败、每天都有可见的收尾 |

三者缺一不可：只有方法科学会枯燥，只有反馈会变成游戏，只有激励会空转。

## 2. 用户与场景

### 2.1 用户

- 一名独立备考的学习者：自己拆教材、自己录题、自己复习，没有老师、班级和同学。
- 原料是教材、真题 PDF、错题本和自己划的章节，而不是别人做好的卡片包。
- 每天投入有限且分散，常在夜间使用，注意力在一天结束时已经下降。

### 2.2 典型一天

| 时段 | 场景 | 产品里发生什么 |
|---|---|---|
| 白天碎片 | 通勤、课间、饭后 | 手机打开，接上同一轮进度，翻几张卡 |
| 晚间主时段 | 坐在电脑前 | 完成当天队列的整轮复习，做题查漏，看结算与明天的工作量 |
| 深夜收尾 | 关灯前的十分钟 | 回到随心，把这一轮里还没评分或刚重练的卡收掉 |
| 每周 | 整理与规划 | 新建或修订宫殿、整理题库、看进度与考试倒计时 |

### 2.3 设备与环境

桌面为主，手机与平板为补充；两端是同一套界面与同一份进度，随时切换不丢状态。夜间与低光是一等场景：沉浸复习界面常驻深色，不跟随浅色主题。

## 3. 需求层级

按「越根本越靠上」排列。每层都给出它对应到产品里的东西，下一层的每个功能都服务上一层的一个需求。

### 3.1 第一层：高效且科学地学（根本需求）

| 需求 | 产品里的回答 |
|---|---|
| 花的时间要落在真正会忘的地方 | 只有到期内容进今天的队列，没有到期就不打扰 |
| 记住靠回忆，不靠重读 | 翻卡是「先回忆、再翻开核对」，不是浏览 |
| 知识要有结构 | 每张卡是一段思维导图，位置、层级、关键词一起进入记忆 |
| 间隔要按真实记忆状态走 | 每个复习单元独立排期；忘记当天重练、困难只缩短、通过才推远 |
| 不要重复学已经会的 | 提前评分只记录不改期；已通过的内容不会留在今天 |
| 判断要能交叉验证 | 做题是独立的第二条证据链，不冒充记忆状态 |

### 3.2 第二层：反馈要丰富（体验需求）

四档反馈，缺一层就会「学得没感觉」：

| 层级 | 时间尺度 | 产品里的回答 |
|---|---|---|
| 动作级 | 一次点击 | 翻卡落定、评分、单元翻完、撤销、跨过进度节点都有各自的声音与动效 |
| 过程级 | 一张到一轮 | 进度线把整轮摊成刻度；连击、里程碑、四分之一标记 |
| 结果级 | 一轮结束 | 盖章式结算：本轮成绩、拆分、总进度、明日工作量 |
| 回顾级 | 一天到一月 | 昨日回顾指出薄弱；历史可回看每次评分；进度页可逐层下钻 |

### 3.3 第三层：容易坚持（留存需求）

产品不靠奖励、签到和恐吓，而是把「今天放弃」的每一个理由先消掉：

| 放弃的理由 | 产品里的处理 |
|---|---|
| 不知道从哪开始 | 打开就是某一轮的具体一张卡，不需要选 |
| 一坐下就累 | 翻卡与评分是同一个手势重复，界面只留必要动作 |
| 今天没学完，干脆不学 | 没有每日限额；收尾结算按已完成算，不留「欠账」压力 |
| 忘了就前功尽弃 | 忘记只是当天再见几次，不清零、不扣分、不中断什么 |
| 学了半天没证据 | 每轮结束有收据，每天有轨迹，退出前能看到自己做了什么 |
| 换设备就乱 | 一轮的进度是账本，手机接着电脑的那一张 |

### 3.4 三层如何咬合

一条典型的学习链路会把三层全部走一遍：

```text
坐下 → 一张卡（低决策成本）
     → 先回忆、再翻开（方法）
     → 四档评分，按钮写着后果（方法）
     → 声音、动效、刻度填实（反馈）
     → 全部评完 → 结算收据（反馈）
     → 明天到期的自动回来（方法）
     → 忘记的当天已重练过一遍（方法 + 反馈）
```

## 4. 核心闭环

### 4.1 五步

```text
① 建构   拆教材 → 编辑记忆宫殿 → 给要长期记的段落钉永久标记 → 生成复习单元
② 排期   每个单元按记忆规律获得下一次到期日
③ 复习   每天打开随心 → 回忆 → 翻卡 → 四档评分 → 当天忘记的当轮重练
④ 检验   做题（选择/简答）验证「是不是真的会了」，错题提示薄弱单元
⑤ 反馈   结算、进度、历史、昨日回顾、考试倒计时 → 决定下一轮学什么
```

闭环每天自动重启：到期单元回来，没到期的安静等待，学习者不需要重新排计划。

### 4.2 两条独立证据链

- **记忆链**：评分是唯一推进方式。翻卡只改变「看到多少」，不改变任何进度。
- **做题链**：对错只累积作答证据，不改变任何单元的记忆状态与到期日。

两条链互不冒充。做题答错可以让对应单元在本轮被优先提起，但不会因此把它的记忆状态判为通过或失败。

### 4.3 学习日

「今天」不按自然日计算，而是跨越午夜的一段连续时间：深夜仍在学习的人，其学习算作同一天。所有「今天到期」「昨天学了什么」「本轮是否重启」都以此为准。

## 5. 功能需求

编号规则 `P-章节.序号`（如 `P-5.2.13` 表示第 5 章第 2 节第 13 条），只写「用户能得到什么」，不写实现方式。全部为当前已成立的能力。

### 5.1 知识建构：把书变成可复习的结构

#### 5.1.1 记忆宫殿

- **P-5.1.1** 可以为一门课或一个专题建立一张记忆宫殿（思维导图），包含任意层级的节点、正文、图片与公式。
- **P-5.1.2** 宫殿归属「学科 → 章节 → 宫殿」三级知识树；可跨学科引用，但有一个主学科。
- **P-5.1.3** 宫殿支持收藏、考试重要度、版本快照、模板（新建与复用）、附件。
- **P-5.1.4** 从书架直接看到每座宫殿的状态：还没可复习段落、已到期、下次复习日期、复习单元数量、题量与题目绑定比例。

#### 5.1.2 结构化编辑

- **P-5.1.5** 编辑器提供增删改节点、拖动子树、折叠分支、缩放与拖拽画布、重点底纹标注、结构检查。
- **P-5.1.6** 编辑随时保存，无需按「保存」；保存状态（保存中/未保存/已保存/失败可重试）始终可见。
- **P-5.1.7** 编辑内容有本地草稿，意外关闭后可以恢复；多设备同时改同一座宫殿时给出冲突提示并让学习者选择保留哪一份，不静默覆盖。
- **P-5.1.8** 复习过程中可以直接进入轻量编辑：双击节点即改，改完回到复习，已翻开的枝干保持原样。
- **P-5.1.9** 一条知识线的清空可以视为删除该节点，子节点上移，可撤销。

#### 5.1.3 复习单元

- **P-5.1.10** 学习者在节点上钉「永久标记」，该节点连同其下游内容成为一个复习单元（一张卡）。
- **P-5.1.11** 在根节点钉标记，整座宫殿成为一个复习单元（「整宫」），适合体量小或需整体回忆的宫殿。
- **P-5.1.12** 同父的多个标记各自独立成为单元；改文字、加子节点、临时取消标记都**不会**重置已获得的记忆状态与到期日。
- **P-5.1.13** 学习者可以在编辑器里给到期单元评分，也可以查看并手动调整它的复习等级档位。

#### 5.1.4 内容生产

- **P-5.1.14** 支持从结构化文本、Markdown、整库文件导入宫殿；「文字转脑图」把一段结构化文字直接生成导图草稿，可撤销、可追加、可覆盖。
- **P-5.1.15** 支持导出与整库备份，内容可以搬走、可以带走。
- **P-5.1.16** 题库支持选择题与简答题的手动录入、编辑、版本管理与批量维护；题目可绑定到知识节点，节点上显示题目数。

### 5.2 复习：每天的主入口

#### 5.2.1 随心

- **P-5.2.1** 随心是产品默认首页，也是唯一的沉浸式复习界面：一屏一张卡片，界面退到边缘。
- **P-5.2.2** 每次进入随心先给一层开始概览：待复习多少座宫殿与单元、今天第一次学多少、近期里程碑、昨日回顾与最薄弱单元；点「开始学习」关掉它就进入卡片。
- **P-5.2.3** 概览读取失败不阻断学习，页面始终保留直接开始的入口。
- **P-5.2.4** 没有需要学习的内容时，按钮直接说明「暂无需要学习的内容」，而不是引导到空页面。

#### 5.2.2 一轮开始前

- **P-5.2.5** 一轮只练记忆宫殿（翻卡）；做题是独立入口，不混进翻卡队列，避免一边回忆一边被题目打断。
- **P-5.2.6** 可配置「学什么」（新学 / 复习，至少留一个）、宫殿范围（学科-章节-宫殿树，全选 / 只选到期 / 重置）、多宫殿顺序（一个刷完再换 / 多宫殿轮流 / 考试优先）与宫殿内单元顺序（按知识结构 / 随机打乱）。
- **P-5.2.7** 配置时实时显示「本轮将这样出题」摘要；保存后先给本轮预览（总数、新学、复习、宫殿分布、学习顺序），确认后才进卡。
- **P-5.2.8** 本轮已有进度时保存配置，必须让学习者选择「保留本轮继续」或「开一轮全新的」，不允许静默重置或静默延续。

#### 5.2.3 翻卡

- **P-5.2.9** 一张卡默认只显示节点标题与结构，子卡折叠；学习者主动「翻卡」逐层揭示，「收卡」回到未回忆状态。
- **P-5.2.10** 翻卡颗粒度、揭示方式（两阶段提示 / 直接显示）、可翻范围（当前单元专线 / 整座宫殿）、镜头是否跟随、评分后是否自动翻页，均可按习惯配置。
- **P-5.2.11** 键盘、鼠标与触屏都能完成翻卡、切卡与评分；快捷键可整套自定义，空格固定为「下一张」。
- **P-5.2.12** 单元标题旁显示「已翻 / 需翻」徽标，只说明这个单元翻到哪，不代表记住了多少。

#### 5.2.4 四档评分

- **P-5.2.13** 评分只有四档：忘记、困难、记得、轻松。评分是复习单元唯一的推进方式。
- **P-5.2.14** 每个评分按钮直接写出这一下的后果（下次什么时候回来），不需要学习者另外查规则。
- **P-5.2.15** 「困难」仍算通过，只让间隔收缩；「忘记」不清零既有记忆积累，而是当天重练。
- **P-5.2.16** 评分可改：离开卡片前再选是整体替换；再点已选中的档位可清除回未评分。只有最近一次真实练习可改，更早的只能回看。
- **P-5.2.17** 提前复习（还没到期就评分）只记录本次评分，不改到期日，按钮上写明「记下，不改期」。
- **P-5.2.18** 分数先上屏为「本次选择」，保存确认后才算数；保存失败时保留选择并明确提示未保存，要求再点一次，不重新加载卡片、不声称已通过。
- **P-5.2.19** 评分后短时间内可撤销；撤销和改判都有独立反馈，不与新评分混淆。

#### 5.2.5 忘记与重练

- **P-5.2.20** 评「忘记」的单元当天会被安排若干次重练，间隔逐次拉长；重练通过后排到次日确认，不再重复当天的复查。
- **P-5.2.21** 重练有上限；达到上限后直接排次日，界面说明「今天已重练 N 次 · 明天再练」。
- **P-5.2.22** 重练以独立卡片出现在本轮，插在源卡之后，带「第几次重练」角标；等待到点的重练不阻塞其他可做的卡。
- **P-5.2.23** 本轮还有等待中的重练时，完成按钮改写为「去看还没到点的重练」，并给等待页而不是庆祝页；等待页把「今天到此为止」作为显式取舍说清楚。
- **P-5.2.24** 成熟单元忘记后有一次「复活」通道：当天重练、次日确认，通过后直接恢复到过往间隔的合理比例，不从最短间隔重新爬。

#### 5.2.6 一轮的组织与边界

- **P-5.2.25** 顶部进度线把本轮全部卡片摊开为刻度：已评分填实、未评分留白、新学与复习用不同色、重练带圆圈编号、关联题答错标红。
- **P-5.2.26** 进度线按学习日分段，今天之前的部分变暗；可拖动、可点格跳转、可点空白打开配置。
- **P-5.2.27** 本轮进度是一份账本：刷新、重启、换设备都不会把已评分还原为未评分；只有结算或学习者主动压缩才移除。
- **P-5.2.28** 可随时「更新队列」按最新到期重排剩余工作、「同步进度」接过另一台设备的本轮，或直接开一个新队列。
- **P-5.2.29** 本轮可整体结算（收起已完成分组，分母变小但本轮继续），也可在完全处理完后进入收尾结算。
- **P-5.2.30** 复习单元可「移除本队列」（这一轮不练，不改排期）或「永久移除」（以后不再安排）；两者都需要二次确认，且可恢复或可解释。
- **P-5.2.31** 未评分、重练与已评分三类卡片在一轮里共存；评分后的重排只把视口钉回当前卡，绝不自动移动游标。

#### 5.2.7 左侧目录与随心列表

- **P-5.2.32** 左侧并列两个标签：「目录」是学科-章节-宫殿树，「随心列表」是本轮全部卡片；切换不压缩右侧脑图。
- **P-5.2.33** 目录用颜色标出每座宫殿在本轮的进度（还有未评分 / 有待重练 / 已评完），父级取子级里最落后的状态，折叠的章节也能看出剩余工作在哪。
- **P-5.2.34** 目录点击是只读导航：已在本轮则跳过去；已到期但不在本轮则询问是否加入；还没标记则提供「标记并加入」；未到期只说明下次日期；本轮已评完则提供「重新评分」。
- **P-5.2.35** 「加入本轮」是并集：今天到期的单元追加到队尾，不重排已有卡片，并且以后每轮都包含它。
- **P-5.2.36** 随心列表可按文字、宫殿、状态筛选，对未评分项排序、移出、恢复，也可多选后按同一档批量评分（先确认）；已评分项只读。
- **P-5.2.37** 列表上的选择、筛选、排序都不改变右侧当前卡片，除非学习者明确要求跳到剩余卡。

#### 5.2.8 单宫与整宫复习

- **P-5.2.38** 书架上的「立即复习」进入该宫殿专属复习页，复用同一套沉浸界面与评分规则，范围瞬时锁定在这座宫殿。
- **P-5.2.39** 单宫复习不改变随心的全局选择与已保存偏好；反过来随心的配置也不会被它悄悄改掉。
- **P-5.2.40** 整宫单元可以在编辑器的单元评分页一次评分，评过之后本轮不再问第二次。

#### 5.2.9 复习的收尾

- **P-5.2.41** 收尾结算是一张盖章式收据：本轮处理的单元数最醒目，其次是新学/复习/重练拆分、宫殿总进度、今日剩余与明日到期。
- **P-5.2.42** 结算页给两个出口：清空本轮做题进度（二次确认，学习历史与复习安排不变），以及结算并按配置开始下一轮。
- **P-5.2.43** 保存状态在结算页可见；保存失败必须可重试，且不遮挡主数字。
- **P-5.2.44** 结算页可展开按学科明细与「下次复习」清单，答完「明天还有多少」。

### 5.3 检验：做题

- **P-5.3.1** 做题与记忆宫殿是两套独立流程，但共用同一个做题窗口：页眉入口、卡片工具栏、节点题目徽章、宫殿做题页打开的是同一种窗口。
- **P-5.3.2** 出题范围由入口决定：本轮复习单元相关（默认）、整座宫殿（主动开启），或某张卡片、某个节点关联的题。
- **P-5.3.3** 支持多种题型：单选、多选、判断、填空、连线、排序、归类、简答；选择题可以切换成主观作答。
- **P-5.3.4** 判分即时或提交后判定；每题给正确答案与解析；简答给参考答案与要点点评。
- **P-5.3.5** 题号轨道与节点绑定点按当前答案着色：答错红、改对即恢复；一个单元的全部绑定题答对时单元标绿。
- **P-5.3.6** 错题会让对应复习单元在本轮被优先提起，不影响整座宫殿的排期。
- **P-5.3.7** 可以重新作答当前题（清空本题作答与草稿，不抹累计统计）；每题可标记、可查看与切换版本；答得又快又稳会被提示「待换题」。
- **P-5.3.8** 做题进度随本轮保存，刷新与换设备可接上；开新一轮或结算时按宫殿选择保留或清空。
- **P-5.3.9** 做题窗口可导出本题、全部题或错题集，可带导图与答题信息。

### 5.4 反馈：让每一步有回声

- **P-5.4.1** 动作级：翻卡落定、评分提交、单元翻完、撤销、移出卡片、进度跨过四分之一节点、本轮完成，各有可分辨的声音与动效。
- **P-5.4.2** 反馈强度随动作语义变化：四档评分手感不同，连击越高反馈越强，但都保持克制、不遮挡内容。
- **P-5.4.3** 所有声音、震动、动效可按场景与强度调节，尊重系统的「减少动态效果」。
- **P-5.4.4** 过程级：连击记录连续通过，忘记只让它安静淡出，不显示中断惩罚；里程碑条持续显示最近的考试与目标日期。
- **P-5.4.5** 过程级：进度跨过 25% / 50% / 75% 有独立提示；宫殿今日清空、今日新学完成各有一条一过性横幅。
- **P-5.4.6** 结果级：每轮结束给成绩、拆分、总进度与明天的工作量，可按学科与宫殿两级看明细。
- **P-5.4.7** 回顾级：开始页展示昨日回顾与最薄弱单元；随心历史可回看本轮与做题记录。
- **P-5.4.8** 回顾级：学习热力图展示连续天数、最长连续与近半年活跃；上周摘要给出复习次数与新建数量。

### 5.5 规划：进度与考试

- **P-5.5.1** 今日学案汇总今天该学什么、离考试还差多少、哪里最薄弱、最近学得怎么样、今天新增了哪些宫殿。
- **P-5.5.2** 学习进度可沿学科 → 章节 → 宫殿 → 记忆点逐层下钻，也可按「待复习 / 尚未覆盖 / 有未做题目」筛选。
- **P-5.5.3** 学习进度明确区分「复习记录」与「记忆掌握」、「已作答」与「已答对」，页脚直接写出这两句。
- **P-5.5.4** 考试作战室展示倒计时、当前掌握率、考前预测、每日新学节奏、记忆保留曲线、各科进度、知识地图、星级分布与最该补的地方。
- **P-5.5.5** 知识地图上可直接给宫殿或章节定考试重要度星级，未单独设置时按规则推算并可继承章节。
- **P-5.5.6** 导图抽查只练不评分：抽节点问「下面有哪些」或抽路径问「属于哪一支」，不影响复习排期。
- **P-5.5.7** 里程碑可设日期、分类与提前提醒；里程碑只做提醒，不改复习间隔。
- **P-5.5.8** 冲刺开关只缩短不延长：任何复习都不会被排到考试之后，过远的间隔被拉回考前并按单元错开。

### 5.6 数据与保障

- **P-5.6.1** 数据本地优先：内容、进度、附件都在学习者自己的设备上，不依赖云端账号。
- **P-5.6.2** 多设备之间由应用外的一次同步动作搬运数据；应用明确声明并遵守「同一时间只有一台设备写入」。
- **P-5.6.3** 同步是整份替换而非合并；上传前、下载前、导入前各有一道护栏，覆盖会先提醒而不是静默执行。
- **P-5.6.4** 启动、关闭与周期性备份自动进行，关键操作前留救援快照；宫殿另有版本快照，可预览后再恢复。
- **P-5.6.5** 删除的题目先进回收站，可预览、恢复或永久删除。
- **P-5.6.6** 可配置复习提醒与手机推送：每日概览、晚间催促、闲置拉回、到期就绪，另有免打扰时段与每日上限。
- **P-5.6.7** 支持安装到手机桌面与弱网使用；手机与电脑同时打开时，当前卡与翻面互相跟随。

### 5.7 专项轨道：英语

- **P-5.7.1** 听力课程支持本地视频与字幕导入、逐句听写、整词判定、提示、单句与连播、三种布局、遮挡板与全套键位。
- **P-5.7.2** 整课完成给复盘：一次通过、用过提示、输错次数、本轮用时，以及「值得再听一遍」的句子。
- **P-5.7.3** 完形阅读按年份读文章，可标生词、查词、复制素材；这一页是阅读与整理，不判分。
- **P-5.7.4** 英语练习与宫殿复习是两条互不干扰的轨道，进度各自计算。

### 5.8 全局能力

- **P-5.8.1** 全局搜索覆盖宫殿、记忆桩、题目与章节。
- **P-5.8.2** 命令面板可用键盘抵达主要操作、页面与最近访问。
- **P-5.8.3** 列表支持右键（桌面）与长按（手机）菜单，动作一致；宫殿、章节、学科、题目、课程、模板各有自己的菜单。
- **P-5.8.4** 每个一级分区记住上次停留的页内地址；从列表进详情再返回，滚动与展开状态保留。
- **P-5.8.5** 前进/后退只在当前分区内生效，不跨区。
- **P-5.8.6** 浅色「纸」与深色「灯」两套外观；沉浸舞台固定深色。
- **P-5.8.7** 正文对比度、键盘可达性、触控目标尺寸与手机输入框字号都有明确下限，动效在「减少动态效果」下降级。

## 6. 关键产品规则

1. **评分才写进度**：翻卡、看题、浏览都不产生记忆证据。
2. **没有每日限额**：到期多少就排多少，不切片、不延迟释放、不制造积压。
3. **任何通过都不留在当天**，唯一例外是新学之后的短期复查。
4. **困难不推远，忘记不清零**：困难只让间隔收缩；忘记保留既有记忆积累，只安排当天重练。
5. **提前复习不改期**。
6. **一条链只改自己的证据**：做题不改进度，评分不改题目的对错记录。
7. **本轮是账本**：轮次的顺序、评分与重练以记录为准，不随刷新、重启或换设备改变。
8. **改内容不重置进度**：编辑、增删子节点、临时取消标记都不影响已获得的记忆状态。
9. **一轮由人开始**：新一轮只在学习者明确确认后创建；刷新、重启、换设备都不得悄悄开新轮。
10. **所有反馈可关闭**：声音、震动、动效都能单独调到关，调低不影响任何功能。
11. **不静默取舍**：覆盖配置、覆盖数据、跨设备冲突，都必须让人选择。
12. **失败要说清楚**：任何保存或同步失败都要说明「数据有没有改动」并给重试，不让人猜。

## 7. 体验原则

1. **先开始，再解释**：入口先给「现在做什么」，规则说明放在后面或按钮上。
2. **内容在前，界面在后**：复习与导图时界面只保留必要动作，不抢注意力。
3. **数字要能看懂**：每个统计回答一个具体问题，不做装饰性指标。
4. **让布局解释关系**：不用层层小标题和说明文字堆砌层级。
5. **按钮自己说清**：评分按钮写后果，完成按钮写下一步，不需要旁注。
6. **跨设备不丢**：任何体验改动都不改变数据与同步语义。
7. **夜里也能用**：低光是一等场景，不是主题商店里的一个选项。

---

## 8. 非目标

- **不做多用户与账号体系**：这是个人产品，不涉及班级、教师端、社交与排行榜。
- **不做云端依赖**：不要求联网才能学习，也不把进度托管在第三方服务。
- **不做游戏化噪音**：没有金币、皮肤、抽卡、签到奖励，不靠外部激励替代记忆本身。
- **不做内容商店**：卡片来自学习者自己的教材，产品不提供别人整理好的题包。
- **不做答题时的 AI 代劳**：AI 只帮助生产与整理内容，不在作答过程中替学习者思考。
- **不做资料囤积**：不以收藏量、阅读量作为价值证明。

## 9. 术语

| 词 | 含义 |
|---|---|
| 记忆宫殿 | 一张思维导图，一个知识主题；产品里的知识单位 |
| 节点 / 卡 | 导图上的一张卡片，可以带正文、图片、公式和子卡 |
| 永久标记 | 学习者钉在节点上的「这一段要长期复习」 |
| 复习单元 | 由永久标记划分出的一段内容（含下游），一张卡对应一个单元；评分只作用于单元 |
| 整宫 | 在根节点钉标记后，整座宫殿作为一个复习单元 |
| 到期 | 单元的「下次该复习日期」不晚于今天 |
| 学习日 | 跨越午夜的连续时间，深夜学习仍算同一天 |
| 一轮 / 本轮 | 一次进入随心后连续处理的一批卡片，有开始、进度、结算 |
| 重练 | 忘记后当天追加的再次回忆 |
| 小结算 / 收尾结算 | 收起已完成分组继续本轮 / 本轮结束的成绩页 |
| 随心 | 沉浸式复习界面，默认入口 |
| 做题链 | 与记忆链独立的答题证据链 |
| 里程碑 | 考试或目标的日期节点，持续显示在复习过程中 |
| 连击 | 连续通过的计数，忘记只让它淡出 |
