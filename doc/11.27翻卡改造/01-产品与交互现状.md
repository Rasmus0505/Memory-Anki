# 产品与交互现状

证据日期：2026-11-27。以下区分代码事实、文档描述和待实测事项。

## 1. 产品对象与核心任务

Memory Anki 是具有知识宫殿、脑图和复习能力的学习项目。本次只聚焦随心模式的脑图复习单元卡及直接影响其体验的外层布局、评分、导航和编辑衔接，不泛化为全站重做。

```text
宫殿：一份具有树状结构的知识内容
  └─ 复习单元：通过锚点及成员节点确定的复习范围
       └─ 节点：可逐步揭示的知识内容

一轮随心复习
  └─ 多个复习单元卡（也有其他流程/题目卡）
       └─ 每张单元卡内运行脑图揭示过程
```

同一宫殿可以有多个复习单元。一个单元不一定等于整座宫殿，也不一定等于一个节点。

学习者的核心任务：在看答案之前回忆一部分知识的结构和内容，揭示后自评，再继续下一单元。

## 2. 两种不同的“翻”

1. 脑图内揭示：出现节点、显示占位、揭示内容、收起分支。
2. 单元间翻页：离开当前单元，切到另一个复习单元。

评分是第三件事。揭示内容、切换单元、提交评分不应在视觉和语义上混为一个动作。

## 3. 当前页面结构

以下是结构示意，不是实际截图，不代表精确像素和运行结果。

```text
┌──────────────────────────────────────────────────┐
│ 本轮进度轨道                                     │
│ 宫殿名 / 轮次计数                      配置 更多  │
├──────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────┐ │
│ │ 脑图工具栏：编辑 / 文字 / 画布工具 / 等级 / 做题│ │
│ ├──────────────────────────────────────────────┤ │
│ │ 单元标题     翻卡数量     补充 / 撤销等        │ │
│ │                                              │ │
│ │          可平移、缩放、交互的思维导图          │ │
│ │                                    上一单元 ↑│ │
│ │                                    下一单元 ↓│ │
│ │                                    完成      │ │
│ │                                              │ │
│ │          忘记   困难   记得   轻松            │ │
│ └──────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────┘
```

页眉属于文档流，不应盖住脑图标题。卡面主体依次为工具栏、单元身份行、脑图。评分区实际以绝对定位覆盖在卡面底部，不是画布下方独占高度的一栏。右侧另有纵向翻页器。

桌面有目录相关面板与沉浸展示能力；手机、PWA、全屏等状态需要分别检查。沉浸信息流时文档设计要求隐藏左侧面板而非持续挤压学习舞台。

### 页眉

文档描述包含本轮进度轨道、宫殿名、轮次计数、配置、更多菜单。进度轨道可跳转。更多菜单代码包含更新队列、同步进度、历史、模块切换等操作。具体拥挤程度与手机实际表现尚未截图验证。

### 单元身份行

单元标题会截断，含永久标记相关标识、翻卡计数、补充练习标识和条件出现的撤销入口。

翻卡计数只统计当前单元成员与锚点，不等于整座宫殿所有可见节点。文档规定未翻、部分、全翻完使用不同状态色，并有说明文字。

### 卡片视觉

当前样式体现深色石墨/暖黑舞台、纸面式脑图、厚度感评分按钮。新学与复习有不同颜色标识，评分确认有边缘呼吸反馈。

源码中卡面顶部类型条实际使用 `h-1`，未评分透明度 0.35、已评分透明度 1。旧文档写成 1px，不应将该文档尺寸当成当前实测尺寸。

这些是现有实现方向，不是最终升级必须沿用的风格。

## 4. 脑图揭示状态机

节点有三态：

```text
隐藏 hidden → 待回忆 placeholder → 已揭示 revealed
```

- 隐藏：还没有展开显示。
- 待回忆：节点已经出现，但用占位内容提示回忆。
- 已揭示：真实内容可读。

两种揭示模式：

- 两阶段：先出现待回忆节点，再揭示内容。
- 直接显示：省略占位阶段，直接显示内容。

两种颗粒度：

- 逐张。
- 同层批量。

常规推进按层查找下一批未完成节点。点击待回忆卡可揭示该卡；点击已揭示父卡会寻找后代中下一批待推进节点。另有直接子卡/全部后代的批量规则，不能把所有操作都理解成统一的一张卡动画。

### 代码默认值

| 设置 | 当前代码默认 |
|---|---|
| 揭示颗粒度 | 同层批量 |
| 揭示方式 | 两阶段 |
| 可翻范围 | 随心 / free |
| 进入编辑范围 | 当前单元 / unit |
| 键盘揭示后镜头跟随 | 开启 |
| 评分后自动切换单元 | 关闭 |

旧交互文档把颗粒度、可翻范围分别写成逐张、专线；此处以当前默认常量和显示设置代码为准。已有用户保存的个人设置可能覆盖默认值，截图时必须记录实际设置。

### 可翻范围

- 专线：限制在当前单元目标与必要祖先路径。
- 随心：不施加同样的目标节点限制，可以探索更大范围。
- 当前单元及其祖先上下文可保持强调，范围外节点弱化。

设计需要同时表达“现在考哪部分”与“这部分位于整个知识结构哪里”。

### 收卡与隐藏子级

收卡会折回后代，并根据揭示模式将目标回到占位或隐藏状态。隐藏子级与整张单元翻页、评分撤销是不同操作。

### 连续性

同轮同单元切回不应无缘无故重新开始。进入编辑再回到复习时会恢复揭示快照，并尽量保持视野。新一轮应重新开始，而不是继承上一轮揭示进度。

## 5. 操作方式

### 键盘

| 动作 | 默认/已有约定 |
|---|---|
| 推进脑图揭示 | Enter |
| 收卡 | Backspace |
| 隐藏子级 | Shift+H |
| 四档评分 | 1 / 2 / 3 / 4 |
| 移出本轮队列 | 5，再按确认 |
| 平移画布 | W / A / S / D |
| 切换单元 | 空格、方向键、PageUp/PageDown 等导航键 |
| 退出全屏 | Esc |

部分学习按键可配置，固定导航和平移键不能随意占用。旧文档的上一张/下一张键表存在容易误读的列法，实施时应核对快捷键映射，不能只照搬文档。

代码保护：只有当前活跃卡、当前路由接收揭示快捷键；编辑、输入、弹窗等场景让路；点击翻页按钮后释放焦点，避免下一次 Enter 再次翻页。

### 鼠标

点击节点揭示，右键执行分支相关操作；拖动和平移、滚轮地图操作与外层翻页存在事件边界。双击涉及编辑切换。

关键差异：鼠标点击节点默认保持视野；键盘揭示可跟随新内容进入视野。这是已有设计约束，不是疏漏。

### 触屏

需支持点节点、长按、画布拖动、双指缩放、外层单元切换、评分、安全区。

底层存在对特定嵌入场景的轴向手势分流及拖动后误点击抑制，但这不等于随心页面所有设备都已验证无冲突。需要实机查看用户何时是在移图、何时是在翻页。

## 6. 评分和排期

四档：忘记、困难、记得、轻松。按钮展示预计间隔/日期等后果，不只是彩色满意度按钮。

已有相关能力：

- 改判、某些状态下再次点击取消评分。
- 保存中、保存失败、重试、锁定、上次评分。
- 短时撤销；文档描述为评分后 5 秒窗口，实际使用应再核对运行行为。
- 自动翻页可选，默认关闭。
- 本单元与宫殿相关评分范围。
- 移出本轮与永久移除，两者语义不同且需要确认。
- 手机折叠低频移除操作，四档主评分保留至少约 44px 的触控目标。

需要区分：已点击、保存中、已保存、保存失败、不可再改。

当前父组件采用本地优先视觉响应，保存中的评分可以立即亮起，同时展示保存状态。因此不能将“亮起”直接解释为服务器确认保存成功，也不能只读评分子组件注释来推断整条调用链。

手动调整复习等级与普通四档评分也有不同语义：等级栏会先产生预览，确认后改变排期；文档强调不等同于改写记忆评估。当前单元卡会将手调结果计作本轮已处理。

## 7. 相邻能力及非理想状态

- 工具栏含编辑/复习切换、文字、做题、画布工具、更多等能力。
- 复习等级栏可调整排期，并有预览/确认；本轮关联题答错可提示。
- 编辑会保存知识内容并协调复习单元变化，不是无状态皮肤切换。
- 保存中、已保存、保存失败/重试有独立提示。
- 同一页面可能呈现重练卡、补充练习卡、只看不评状态、黄色流程提示卡、加载失败或失效恢复状态。
- 黄色提示卡的四档按钮只用于继续，不写入正常评分。
- 补充练习可能只记录、不改变到期排期。

方案不能只覆盖短内容、正常网络、首次未评分的一张理想卡。
