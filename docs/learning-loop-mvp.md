# 学习闭环 MVP：已确认的体验与验收规则

## 范围与原则

本次只覆盖宫殿回忆、关联做题、复习安排和结算，包括随心与单宫殿入口。**完全不涉及英语专项或英语功能改造。**长期记忆优先，兼顾考试；不引入新的调度算法或另一套学习进度。

实现应解决状态和规则本身的问题，不用假成功、吞错、虚构进度或自动补分掩盖问题。允许必要清理与重构，但保护真实学习历史、既有数据和其他正在进行的修改。合法的“未完成”“未评分”“提前练习”是正常产品状态，不是错误。

## 评分与复习

- 1「忘记」、2「困难」都不通过，需要重练；3「记得」、4「轻松」才通过。
- 新卡前四轮固定：当天 30 分钟复查 → 第2天 → 第3天 → 第5天，之后交给 FSRS；成熟内容评困难退一档，忘记从第一轮固定复习重来；未通过内容当天仍需练习。
- 低分后按时间等待（10 分钟 → 1 小时 → 当天最后），等待期间重练卡**不在队列里**，继续练其他卡；到点后回到队列（紧跟当前卡），每天最多重练三次。每个内容只保留一个待完成重练位置；源卡角标和顶部横幅显示到点倒计时，不再按“隔几张卡”重练。
- **改分不等于重练。**同一次回忆从2纠正为3，表示点错，按该次回忆开始前的状态重新计算；另一轮真实回忆评3，不能抹掉此前确实发生的困难或遗忘。重练评3从降低后的档位安排；评4按现有规则恢复一档，而不是按从未失败直接升两档。
- 已经产生后续真实评分后，较早尝试只读，不能直接改写或撤销而破坏后续练习的依据；改分针对最近一次练习。只读意味着仍能滑回去看这张图（会话照常打开、`rating_editable: false`），只有评分、改分和撤销被拒绝；这张卡不能因此让进度条留一个永远点不亮的格子，也不能让「完成」停在这张改不了分的卡上。
- 提前练习评3/4不改变原日期或阶梯；评1/2则按低分规则调整并转为今天重练。
- 默认评分后不跳转。评分不替用户打开内容、不移动视角；保留明确的手动翻页。随心页可在「翻卡设置 → 评分后自动翻页」显式打开：保存确认后留约 0.8 秒撤销时间，再翻到队列里最早还没评分的单元（前面跳过的卡也是目标；全部评完则进入结算）；只在被评分的那张仍在视口内时翻页，手动翻页、改分、撤销或关闭开关都会取消这次待翻页。
- 点选评分可立即显示（保存中），但只有保存确认后才计入已通过、完成、到期清空和顶部进度条；没有真正保存上的评分不点亮进度条。一次保存失败先在 5 秒内自动重试（同一操作 ID，服务端去重，重试期间保持保存中、不弹提示），重试仍失败才提示未保存并可手动重试，不把本地选择当作学习成果。
- 关联做题的已做状态、答案对错与宫殿复习评分分开；做题、清除已做状态都不能私自更改宫殿复习日期。

## 收工、续学与结算

- 随时可以结束本次学习，不必把未评分或薄弱内容假装通过。
- 「结束本次学习」与「完成全部任务」是两回事。前者保留剩余任务与原轮次；后者要求相应工作真正完成。
- 下次接着未完成内容学习，可主动加入当天到期内容；原有薄弱项、当前位置和已学记录不能因收工丢失。区分之前留下与今天加入的内容。
- 可选小结算只收起已通过且没有待重练的部分；最终汇总包含小结算，不能重复计数。小结算不询问清除做题进度。
- 最终收工询问保留或清除本轮涉及宫殿的做题进度。范围必须明确；清除的是可重做的已做状态，不是学习历史、评分或复习日期。

## 编辑不处罚学习进度

- 修改旧内容保留所属部分的阶梯和复习日期，是否记得由之后的真实评分决定。
- 新增标记拆分旧部分，两部分继承原进度。
- 新增内容优先继承所属父级分支的进度；父级没有则向上找最近有进度的祖先，不按屏幕距离或布局位置选择。
- 合并不同进度的部分，取较低阶梯与较早日期，避免较弱内容被推迟。
- 完全找不到可继承进度的新内容才进入首次学习。移除标记不是删除历史。

## 关键体验验收

1. 同一张卡误点2后改3：没有错误低分惩罚；确实评2后去重练卡评3：此前降档仍有效，预告日期与保存日期一致。
2. 低分卡反复重练：只有一个待处理重练位置，尝试次数真实；通过后不残留无法完成的重练。
3. 还有未评分和低分内容时收工：可查看真实总结并选择保留/清除做题进度；继续时回到原轮次，剩余内容未被补分。
4. 小结算后最终收工：次数、内容和时间不重复，未通过内容不被收起。
5. 原定下周复习的内容今天额外练习：3/4保持下周日期，1/2进入今天重练。
6. 编辑、拆分、新增子节点、合并标记：遵守继承规则，同样输入不因遍历顺序产生不同进度。
7. 结算期间、长时间离开、跨天恢复：不把闲置时间补计为学习时间。
