# 列表右键菜单

> 最后核对：2026-11-06
> 现行规则：凡是“一行代表一个对象”的列表，鼠标右键或触屏长按都能呼出操作菜单。

## 怎么用

- 桌面：在行上点右键。
- 手机 / 平板：按住约 0.7 秒。
- 菜单打开后：↑↓ 选择，Enter 执行，Esc 关闭；危险项标红并要求二次确认。

同一行仍保留原来的单击、复选框、拖动和行尾按钮，右键不会改变它们的语义。

## 各列表能做什么

| 列表 | 行 | 菜单里的动作 |
|---|---|---|
| 编辑器左侧「记忆宫殿」 | 宫殿 | 打开、复习进度、做题、开始随心复习、重命名、移动到…、收藏/取消收藏、复制链接、删除宫殿 |
| 同上 | 章节 | 在此章节新建宫殿、开始随心复习、重命名、删除章节 |
| 同上 | 学科 / 「未分类」 | 学科：打开学科书架、在知识库编辑章节、在此学科新建宫殿、重命名、删除学科；「未分类」只有在此新建宫殿 |
| 学科书架 / 宫殿列表（`/palaces`、`/palaces/list`） | 宫殿 | 同编辑器；「复习进度」打开行内面板，不跳整页 |
| 随心复习左侧目录 | 宫殿 / 章节 / 学科 | 同编辑器，但没有「开始随心复习」；「打开」表示跳到该宫殿的随心卡片，不离开随心；「单独编辑」打开编辑器，左上角「返回随心」回到本轮 |
| 查看记忆宫殿弹窗（编辑器内，桌面） | 宫殿 / 章节 / 学科 | 同编辑器；「打开」表示在弹窗里预览。窄屏分支是普通列表，没有右键菜单 |
| 知识库（`/knowledge`） | 学科 | 打开学科书架、在知识库编辑章节、在此学科新建宫殿、重命名、删除学科 |
| 同上「关联宫殿」 | 宫殿 | 打开、复习进度、做题、开始随心复习、重命名、移动到…、收藏/取消收藏、复制链接、删除 |
| 题库管理 | 题目 | 编辑题目、选择/取消选择、复制题干、删除题目 |
| 题库回收站 | 题目 | 预览、恢复题目、永久删除 |
| 宫殿模板弹窗 | 模板 | 使用模板、删除模板 |
| 英语听力片库 | 课程 | 打开课程、删除课程 |
| 考前作战室知识图 | 宫殿卡片 | 打开、复习进度、做题、开始随心复习、重命名、移动到…、复制链接、删除（这行没有收藏状态，所以不显示收藏） |
| 全局搜索（`⌘K` / `Ctrl+K`） | 宫殿 / 记忆桩 / 题目 / 章节 | 宫殿与记忆桩：打开、复习进度、做题、开始随心复习、复制链接；题目：打开所属宫殿、开始做题、复制题干；章节：打开知识库 |

## 三个容易踩的点

1. **行内改名**：选「重命名」后，行本身变成输入框，回车或点别处保存，Esc 取消。不要改成弹窗——用户需要看着上下文改名。菜单关闭时 Radix 会把焦点还给触发行，所以 `InlineRenameInput` 会在挂载后短暂重试聚焦，并把 180ms 内的失焦当作菜单拆卸而不是保存。
2. **弹窗里的菜单**：模态弹窗开启了焦点陷阱，菜单必须 portal 到弹窗内部（`RowContextMenu` 的 `container`）。直接 portal 到 `body` 会点不动。命令面板通过 `CommandDialog` 的 `contentRef` 拿到弹窗节点；模板弹窗用 `DialogContent` 的 ref。
3. **收藏只在知道状态时出现**：宿主传了 `isFavorite`（或行数据带 `is_favorite`）才渲染「收藏/取消收藏」。搜索结果、作战室没有这个字段，菜单里就没有收藏。不要为了菜单齐全去猜——猜错会让已收藏的宫殿只能「收藏」、无法取消。

## 代码在哪

| 能力 | 位置 |
|---|---|
| Radix 右键菜单样式封装 | `apps/web/src/shared/components/ui/context-menu.tsx` |
| 菜单条目模型、分区拼接、行包裹 | `apps/web/src/shared/ui/row-context-menu/` |
| 行内改名输入框 | `apps/web/src/shared/ui/inline-rename/InlineRenameInput.tsx` |
| 宫殿 / 章节 / 学科的统一动作、移动对话框 | `apps/web/src/modules/content/ui/palace-menu/` |
| 目录树接入点 | `PalaceDirectoryTree.tsx` 的 `palaceMenu` / `chapterMenu` / `subjectMenu` / `bucketMenu` / `onRename*` |

新列表接入时，只需要：

1. 用 `usePalaceMenuActions()` 拿到 `palaceMenu` / `chapterMenu` / `subjectMenu`；
2. 用 `<RowContextMenu items={...}>` 包住行元素（`asChild`，不额外加 DOM）；
3. 需要行内改名时，把 `rename: { onSelect: beginRename }` 交给菜单，由列表自己渲染 `InlineRenameInput`。

## 刻意没做的列表

纯选择型列表（随心筛选弹窗、随心列表、复习单元面板、题-节点绑定）保留原交互：这些行的目的是勾选、评分或调整顺序，加管理动作会和复选框 / 拖动冲突。设置里的配置表（AI 模型、备份、里程碑）同理，它们已有行内编辑按钮。
