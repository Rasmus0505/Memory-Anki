# 复习间隔与评分规则（用户视角）

> 面向：产品体验者。不出现代码、字段名、表名。
> 技术实现细节见 [复习排期设计](复习排期设计.md)（开发者版）。
> 本文按 2026-10-29 的新策略整理：**二段定锚 + 受控 FSRS**。

---

## 0. 一句话

**新卡只上两次固定闹钟**：当天 **20 分钟**复查一次、**第 2 天**睡醒后隔夜检验一次。
隔夜检验点「记得」→ 直接排到 **3 天后**并交给算法；点「轻松」→ **5 天后**。
**只有「忘记」会当天再练**；「困难」照样通过，只是把下一次间隔压短。

---

## 1. 先统一三个词

| 词 | 含义 |
|---|---|
| **学习日** | 凌晨 **03:00** 翻页。0:00–3:00 做的复习，算「昨天」。 |
| **复习单元** | 脑图上勾了**永久标记**的那一段（含它下游的内容）。**一张卡 = 一个单元**。 |
| **到期** | 每个单元身上记着一个「下次应该复习的日期」。队列只装**到期日 ≤ 今天**的单元。 |

「今天有多少张卡」= 今天到期的单元数 + 今天该学的新单元数，**没有每日限额、不分批释放**；
顺序是：新学优先 → 章节结构顺序。

---

## 2. 四个按钮，按下分别会发生什么

| 按钮 | 产品含义 | 结果 |
|---|---|---|
| **忘记** | 完全没想起来 | 当天重练：10 分钟 → 1 小时 → 3 小时，最多 3 次；之后排明天 |
| **困难** | 想起来了，但很吃力 | **算通过**：下次间隔会被压到上一次的 0.8–1.0 倍（绝不更远） |
| **记得** | 正常通过 | 按定锚期 / 算法排到未来；10 天以内最多 2.5 倍 |
| **轻松** | 太简单 | 定锚期直接毕业（+3 或 +5 天）；10 天以内最多 3.5 倍 |

四条硬规则：

1. **任何「通过」都不会留在今天**（只有首次学会那一次 20 分钟复查例外）。
2. **「困难」绝不会把卡排得更远**：上一次隔了 3 天，这次点困难，下次最多还是 3 天，
   通常是 2–3 天。
3. **提前复习不改期**：卡还没到期就被你评了分，只记录这次评分，**到期日不动、记忆评估也不动**。
   按钮上会明说「记下，不改期 · 某月某日」。
4. **一天最多重练 3 次**。第 4 次直接排明天，按钮显示「今天已重练 3 次 · 明天再练」。

---

## 3. 新卡的两次固定闹钟（定锚期）

| 你现在的状态 | 点记得 | 点困难 | 点轻松 | 点忘记 |
|---|---|---|---|---|
| 第一次学 | 20 分钟后复查 | 同记得 | **免复查，直接 +3 天，毕业** | 当天重练 |
| 20 分钟复查时 | 明天（第 2 天） | 明天 | +3 天，毕业 | 当天重练 |
| 第 2 天隔夜检验 | **+3 天，毕业** | **+1 天，明天再检验** | **+5 天，毕业** | 当天重练 |
| 重练通过（任何时刻） | 直接排明天 | 直接排明天 | 直接排明天 | — |

- 定锚期**只在隔夜检验点「记得/轻松」时毕业**（首次学直接点轻松也可以提前毕业）。
- 重练通过后**不再叠一次 20 分钟复查**：明天的隔夜检验就是确认。
- 隔夜检验点「困难」不会当天重练：它只是让你明天再来检验一次。

> 为什么砍掉「第 3 天」：隔夜成功后记忆稳定性已经跳了一级，第 3 天再考一次时
> 你几乎一定记得（可提取性 96% 以上），大脑不需要费力提取，记忆几乎不增长，
> 却实实在在占掉了当天的复习额度。现在隔夜一过就直接 +3 天。

---

## 4. 交给算法之后：三条护栏

| 你的评分 | 下一次间隔 |
|---|---|
| 忘记 | 当天重练；过关后排明天确认 |
| 困难 | 上一次间隔的 **0.8–1.0 倍**（最少 1 天，最多不超过上次） |
| 记得 | 上一次 **<10 天** 时最多 **2.5 倍**；≥10 天后**不设上限**，交给算法 |
| 轻松 | 上一次 **<10 天** 时最多 **3.5 倍**；≥10 天后**不设上限** |

另外：

- **任何通过至少排到次日**；最长间隔 **365 天**。
- **间隔 ≥7 天**时加一个按单元计算的 **±5%** 抖动，避免同一天学的一大堆卡永远同一天到期。
- 目标记忆率仍是 **90%**：算法按「你什么时候有 90% 把握还记得」来估间隔。

### 老卡忘记有「复活甲」

一张已经隔了 **14 天以上**的成熟卡，如果点了一次「忘记」：

1. 当天 10 分钟后重练一次；
2. 重练通过后先排 **明天**，确认隔夜没忘；
3. 第二天点「记得」，下一次间隔**不会从 1 天慢慢爬**，而是直接恢复原间隔的
   **约 30%**（原间隔 60 天 → 约 18 天）。点「困难」恢复 25%，点「轻松」恢复 35%。

## 5. 时间线（用来校准直觉）

### 5.1 一路都点「记得」

| 复习日 | 下一次 | 这一步的间隔 |
|---|---|---|
| 10-26 首次学 | 10-26（约 20 分钟后复查） | 当天 |
| 10-26 复查 | 10-27 | 明天（隔夜检验） |
| 10-27 第 2 天 | 10-30 | +3（毕业，交给算法） |
| 10-30 | 11-06 | +7（2.5 倍封顶） |
| 11-06 | 11-23 | +17（2.5 倍封顶） |
| 11-23 | 由算法决定 | 上一次 17 天，解除封顶 |

对比旧规则：把一张卡推到 1 个月以上，旧规则要 7 次天级复习，新规则 **4 次**。

### 5.2 第 2 天点了一次「困难」

| 时间 | 操作 | 结果 |
|---|---|---|
| 10-24 晚 | 首次学，记得 | 20 分钟后复查 → 10-25 |
| 10-25 第 2 天 | 点**困难** | 今天过关，排到 10-26，明天再检验 |
| 10-26 | 点**记得** | 排到 10-29（+3），毕业 |

### 5.3 成熟卡点了一次「忘记」

原间隔 60 天：

| 时间 | 操作 | 结果 |
|---|---|---|
| 第 0 天 | 忘记 | 当天重练；记下原间隔 60 天 |
| 第 0 天重练 | 记得 | 排第 1 天（隔夜确认） |
| 第 1 天 | 记得 | **恢复 30%：约 18 天后见** |

## 6. 同一天内的分钟级间隔

| 场景 | 间隔 |
|---|---|
| 第一次学会后的复查 | **20 分钟**（只一次） |
| 重练通过 | **不再复查**，直接排明天 |
| 忘记 第 1 次重练 | **10 分钟** |
| 第 2 次重练 | **1 小时** |
| 第 3 次重练 | **3 小时**（当天最后一次） |
| 一天最多重练 | **3 次**，之后排明天 |
| 学习日只剩不到 15 分钟 | 直接排明天，不再塞回当天 |

重练卡**不占固定位置**：到点后**紧跟当前这张卡**出现。

## 6.5 编辑时就能评分（单元评分页）

编辑宫殿、标完永久标记时，你其实已经主动回忆过一遍了。为了不再去随心重来一次：

- 编辑页左侧、学科目录**上方**有「单元评分」入口，点开是独立页面：左边列这座宫殿的复习单元，
  右边只显示所选单元的内容（不属于它的卡片不显示），下方是四个评分按钮。
- 评分按钮**只在单元到期时可用**，每一档都直接写着 `7天 → 17天 · 11月16日`：
  这一下会把间隔从多少改到多少、下次哪天见。
- 没到期的单元不能评（提前评证明不了什么），但上方有一条**复习等级进度条**：
  左边是当前等级（首学 / 1–2天 / 3–6天 … / 365天以上），**拖动到目标等级松手**，
  确认后按该等级的名义间隔重新排期；确认弹层里也有「明天 / 3天后 / 7天后」快捷项
  和精确日期（最长一年）。拖到「首学」等于重置为第一次学。
  调整只改排期，不改记忆评估；下次评分会按新间隔继续。
- 在画布上点永久标记的徽标，会弹出这个单元的小窗：范围、当前间隔、下次到期，以及「去评分」。

随心卡片上方是**同一条等级进度条**（不再有今天/3天内/本周/本月/更远五个格子），
拖动、确认、快捷项与单元评分页完全一致；评分按钮同样显示「当前 → 下一次」的间隔变化。

## 7. 考试冲刺

- 在考试面板里设**考期**并打开**冲刺开关**。
- 冲刺只做一件事：**不让任何一次复习排到考试之后**。
  - 本该排到考后很远的卡，会被拉回**考前最后一周**，并按单元错开。
  - 考前连一天都放不下时，就按原间隔排在考后。
- 冲刺**只会缩短间隔，永远不会延长**；打开开关时会把已经排到考后的到期日一次性拉回来。

---

## 8. 睡前复习（右侧月亮）

- 把**今天学过的宫殿**追加到当前队列末尾，每座宫殿**一张卡**。
- 这些评分**只记在本轮计划里**：不写复习账本，**不改任何到期日，也不改记忆评估**。
- 今天还没评分的卡本来就在队列里，它们的评分照常生效。
- 过了 03:00 自动清空。

## 9. 你在界面上能看到的「承诺」

| 位置 | 显示什么 |
|---|---|
| 四个评分按钮的第二行 | **评分前**就写着这一下会把卡排到哪：`3天后复习 · 10月30日`、`10 分钟后重练 · 今天`、`20 分钟后回顾一次 · 今天`、`记下，不改期 · 10月30日`、`今天已重练 3 次 · 明天再练` |
| 评分后的浮层 | `7天后见`、`20 分钟后回顾`、`明天见`、`已记下` |
| 左下角「本宫殿」批量评分 | `已选记得 · 今日 3 个到期 · 未首学只改当前卡`（首学的卡不会被批量评分带走） |
| 宫殿列表 / 复习单元面板 | `今天 / 3天内 / 本周 / 本月 / 更远` 的分布，以及每个单元的 `间隔 7天` 或 `今天到期` |
| 队列里的重练卡 | 到点前不在轨道上，只在原卡角标和顶部横幅显示倒计时 |

## 10. 特殊情形

| 情形 | 结果 |
|---|---|
| 同一张卡改判 | 离开前再点另一个按钮，**整体替换**（不是追加两次效果） |
| 撤销 / 修改历史评分 | 只能改**最近一次**；后面已经有新的真实练习就不能改 |
| 编辑宫殿内容 | **不改**已获得的到期日和记忆评估 |
| 增删永久标记 | **不改**已获得的到期日；新内容继承最近祖先的进度 |
| 手动改到期日（复习单元面板） | 独立写入口；**最长一年** |
| 「移除本队列」 | 只是这一轮不练了，**不改排期** |
| 「永久移除」 | 这个单元以后不再安排复习 |
| 规则版本升级 | 只补齐内部计数、**不移动**已排好的日期；新规则从下一次评分开始生效 |

## 11. 这套规则的取舍

1. **两次固定闹钟**：跨过「当天遗忘」和「第一次睡眠遗忘」两个生理节点就够了；
   之后继续写死只会变成无效打卡。
2. **困难 = 通过，但只准缩短**：直接锁死「点困难反而排更远」的算法漏洞，
   让困难真正符合「我觉得吃力，早点再巩固」的直觉。
3. **记得/轻松只封顶不托底**：算法想排得更近就听它的（记忆弱时更安全），
   只拦住「一次跳太远」。
4. **忘记有复活甲**：老记忆重学有节省效应，不应该一朝回到解放前。
5. **20 分钟复查**：够长，需要真正回忆一次；够短，还在同一个学习块里。

## 12. 参数速查（用户语言 → 现在的值）

| 你会问 | 现在的答案 |
|---|---|
| 刚学会多久复查一次 | **20 分钟**，一次 |
| 新卡前几次怎么排 | 20 分钟 → **第 2 天** → 记得 **+3 天** / 轻松 **+5 天**，然后交给算法 |
| 一直点记得，多久见一次 | 3 天 → 7 天 → 17 天 → 之后由算法决定 |
| 点了困难会怎样 | 照样通过，下一次不超过上一次间隔（0.8–1.0 倍） |
| 点了忘记会怎样 | 当天再来（10 分钟起，最多 3 次）；成熟卡隔夜确认后恢复约 30% |
| 重练最多几次 | **3 次/天**，之后排明天 |
| 重练的间隔 | 10 分钟 → 1 小时 → 3 小时 |
| 最长多久复习一次 | **365 天** |
| 目标记忆把握 | **90%** |
| 间隔会不会错开 | 会，**≥7 天**的间隔有 **±5%** 抖动 |
| 考试冲刺会不会把卡推远 | 不会，**只拉近**，且散在考前 7 天内 |
| 睡前复习算不算数 | 不算，**不改任何到期日** |
| 提前复习算不算数 | 只记录，**不改期** |
| 「今天」几点结束 | **凌晨 3 点** |
