# 题库精简（按考点留题）

最后执行：2026-11-07　对象：教育学原理（694 → 405 题）

## 一句话

同一考点只留一道代表题，真题、简答题、做错过的题一律不动，其余软删除。

## 和「题库去重」的区别

| | 题库去重（`docs/题库去重.md`） | 题库精简（本文） |
|---|---|---|
| 解决的问题 | 同一道题被多个来源重复录入 | 同一考点堆了太多变体，刷不动 |
| 判定 | 语义上是同一道题 | 不是同一道题，只是同一考点的重复练习 |
| 删除后 | 考点仍有一条 | 考点仍有一条代表题 |
| 例外 | 跨宫殿不合并 | 真题 / 简答 / 错题不动 |

## 保留口径

按优先级取并集，未命中的软删除：

1. 题干带「333真题 / 统考 / ××年，311」的真题。
2. `question_type = short_answer` 的简答题。
3. 作答记录里错过（`attempt_count > correct_count`）的题。
4. 每个 `node_uid` 一道代表题：前三条没覆盖到的考点，按来源优先级 冬青基础 → 凯程自编 → 丹丹自命题，取一道。

## 执行步骤

1. 只读导出：宫殿 → 章节、`palace_quiz_question_node_bindings`、在世题目（`deleted_at IS NULL`）。
2. 生成保留/删除清单，校验每个有活题的 `(palace_id, node_uid)` 至少保留一道。
3. 整库快照：`sqlite3` backup API → `学习数据\memory_palace.before-question-prune-<时间戳>.db`。
4. 调 `POST /api/v1/palace-quiz-questions/batch-delete`（软删除，走应用层）。
5. 复核在世题量、逐章题量、考点覆盖。

## 恢复

```bash
curl -X POST "http://127.0.0.1:8012/api/v1/palace-quiz-questions/<题号>/restore"
```

或整库回滚到快照。清单在 `deliverables/题库精简-2026-11-07-教育学原理-清单.json`。
