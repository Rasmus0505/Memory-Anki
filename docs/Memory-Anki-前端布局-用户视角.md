# Memory Anki 前端布局（用户视角）

> 面向产品体验者。不出现代码、组件名和字段名。
> 想先了解功能怎么用，请看《[Memory Anki 用户视角介绍](Memory-Anki-用户视角介绍.md)》。
> 本文按 2026-11-04 的界面整理，重点讲「每一块东西为什么在那里、手机上会怎么变」。

---

## 0. 一句话先建立地图

整个产品只有**三套页面骨架**，所有页面都是其中一种：

| 骨架 | 长什么样 | 用在哪 |
|---|---|---|
| **标准页** | 左侧导航 + 中间一条有最大宽度的内容列，从上往下滚 | 书架、宫殿列表、做题、进度、洞察、设置 |
| **脑图页** | 左侧导航 + 一整块铺满窗口的画布，页面本身不滚，只有侧栏滚 | 宫殿详情、宫殿编辑、知识树 |
| **沉浸页** | 左侧导航贴边保留（手机上隐藏）、没有内容边距，一屏一张卡，上下翻页 | 随心、单宫殿复习 |

再加一个外壳：**手机端把左侧导航换成底部标签栏**，其余内容按同一套页面自适应。

理解这三套骨架，后面每个页面就只是「往骨架里放什么」。

## 1. 桌面外壳：左侧固定栏 + 主内容区

### 1.1 左侧导航栏

桌面端左侧是一条**固定不动的导航栏**，从上到下：

1. **品牌区**：方形「记」标志、产品名「Memory Anki」，下面一行日期和时间；
2. **返回 / 前进**：一对小箭头，只在当前分区内走；
3. **主导航**：随心、知识、英语、创建、进度、洞察；
4. **底部一行**：「设置」、调试工具按钮（圆点图标）、收起导航。

调试工具全部收在那个圆点按钮里：复制最近 1/2/5 分钟的操作给 AI、复制上一次点击的位置、查看并补充说明、调用与错误日志，最下面是当前版本（`Stable` / `Dev` + 提交号）。手机上这个按钮在顶栏右侧；随心这类没有顶栏的沉浸页，它浮在右上角。

导航栏有两种宽度：

- **完整栏**（宽屏）：图标 + 文字 + 右侧小箭头；
- **图标栏**（窄屏或手动收起）：只剩图标，鼠标悬停有提示。

**有自己目录的页面**（随心、宫殿编辑、宫殿详情、知识树）一进来导航就是图标栏，目录紧贴在它旁边，看起来是同一条侧栏，不再是两条并排的栏。底部的「展开导航」按钮可以临时展开成完整栏。

这些页面里的目录（宫殿目录、学科栏、单元列表、宫殿信息）：

- 收起按钮在目录自己的标题行里，不再单独占一列；
- 收起后只在画布边上留一个竖着的小标签，点它再展开；
- 目录和导航用同一种底色，和画布之间只有一条分隔线，可以拖动这条线调宽度；
- 手机上目录是盖在画布上的抽屉，点遮罩或标题行的按钮关闭。

窗口宽度分三档：

| 窗口宽度 | 导航形态 |
|---|---|
| 手机（窄于约 768px） | 没有左侧栏，改用底部标签栏 |
| 平板/小窗（约 768–1024px） | 左侧图标栏，始终可见 |
| 桌面（大于约 1024px） | 完整左侧栏，可手动收成图标栏 |

几个容易忽略的行为：

- **每个分区会记住你上次看到哪**：从别的分区点回「知识」，回到的是上次那座宫殿/书架，而不是永远回根页面；
- **已经在当前分区时再点一次标签**，会回到该分区的根（比如「创建」回到新建页，「随心」回到随心首页）；
- **返回 / 前进**只在当前分区内走，不会一下跳回另一个分区；
- 日志抽屉从调试工具菜单打开，用来排查「为什么没保存/没刷新」。

### 1.2 主内容区

- 标准页的内容不会无限拉宽：外层最多约 1600px，里层再按页面收窄成「常规宽度」或「宽页」两档；所以大屏上文字不会被拉成一条超长线。
- 页面内边距随屏幕变：手机 8px 左右，桌面 24–36px；手机上的段落间距也会更紧，避免第一屏全是空白。
- 页面底色是平的冷灰，没有颗粒和光晕；只有考前两周，屏幕边缘会有一圈很淡的呼吸提醒。
- 标准页切换路由时有一个很轻的**纵深过渡 + 纸张声**；沉浸页和脑图页没有这个转场。
- 顶部还有一条**后台任务条**（有生成/导入/备份任务时才出现），不占常驻高度。

### 1.3 三种骨架的差别（重要）

| | 标准页 | 脑图页 | 沉浸页 |
|---|---|---|---|
| 左侧导航 | 悬浮圆角卡片，和内容有间距 | 贴住窗口左边缘，无圆角 | 贴边；桌面保留，手机隐藏 |
| 内容边距 | 有统一内边距 | 无内边距，画布铺满 | 无内边距，卡片贴边 |
| 页面滚动 | 整页滚 | 页面不滚，画布内部操作 | 整页纵向吸附滚动 |
| 环境氛围/转场 | 有 | 有氛围，无页面转场 | 无 |
| 手机底部栏 | 显示 | 显示 | 隐藏 |

## 2. 手机外壳：底部标签栏 + 全屏内容

### 2.1 底部标签栏

手机底部固定一排标签：

- 几个**学习主入口**（随心、知识、进度等）；
- 最右是 **「更多」**：点开是一个从底部升起的面板，里面放「创建」「洞察」「设置」。

为什么不是七个标签平铺：七个标签在手机上每个只剩约 50px，字小、容易点错。现在主入口保持大触控区，次级入口收进「更多」，但都还能一步到达。

进入**沉浸页（随心）时，底部标签栏整体隐藏**——这一屏只属于卡片，分区切换放在随心页眉的「更多」菜单里。

### 2.2 手机上的通用规则

- **安全区**：所有贴顶/贴底的东西都会避开刘海、灵动岛和底部 Home 条；页眉、评分条、底部按钮都按安全区留白。
- **全局返回按钮**：手机左上角浮着一个小胶囊（返回/前进），标准页和脑图页都会出现；沉浸页和系统全屏时不显示，避免压住卡片。
- **触控尺寸**：手机上的按钮普遍至少 44px 高；书架卡片上的「做题/编辑/更多」会换到第二行，给标题让出宽度。
- **手机弹窗不是缩小版桌面弹窗**：
  - 需要看内容的弹窗用**全高面板**：占满可视高度（扣除安全区），**只有中间内容区滚动**，标题和主按钮始终可达；
  - 选择类/操作类用**底部抽屉**：最高约 85% 屏高，向上滑出；
  - 内容优先：题目、脑图、列表至少占可视区的 2/3，次级工具条会折叠或收进「更多」。
- **PWA 全屏**：手机 PWA 里点「全屏」是**占满可用可视区域**，不承诺隐藏系统状态栏和 Home 条；桌面端则优先用系统全屏，失败时退回视口全屏。

## 3. 知识书架页（标准页）

这是「知识」分区的首页，也是整个知识库的门面。

### 3.1 从上到下的结构

1. **页头**：标题「学科书架」；右侧「知识树编辑」「新建宫殿」。
2. **工具条**：搜索框（搜学科或宫殿）+ 右侧「全部收起」。
3. **一棵树**：像文件管理器一样一层层展开，**学科 → 章节 → 节 → 宫殿**。

### 3.2 每一行显示什么

- **学科行**：颜色点、学科名；右边「N 座宫殿」、红色数字（现在就能复习的单元数）、黄色数字（今天稍后能复习）；鼠标移上去出现「打开这本书」按钮，进入下面 3.3 的学科页。
- **章节行**：章节名；右边这一章有几座宫殿，以及这一章（含下面所有节）一共有多少单元到期。
- **宫殿行**：文件图标 + 宫殿名，点名字直接进编辑页；右边是
  - 复习按钮：「开始标记」（紫）/「立即复习」（主色）/「某月某日复习」（灰、不能点，鼠标悬停说明为什么今天不出现）；
  - 「N/M 单元」（宽屏才显示）、考试星标、收藏星；
  - 鼠标移上去才出现的「做题 N」和「⋯」（复习进度、删除）。手机上这些一直显示。
- 只有一座宫殿的章节不再单独占一层，直接显示成那座宫殿的一行。
- 「未分类」的宫殿放在树底部的「未分类」里，也有「打开」入口。
- 搜索时所有层自动展开，匹配到的字会高亮。
- 展开到哪一层会在这次打开应用期间记住；刷新页面后回到全部收起。

### 3.3 学科内的宫殿列表页

从学科行的「打开这本书」进入：

- 页头显示学科名，可「返回书架」，也可「新建宫殿」；
- 下方先是这个学科的**复习等级阶梯**（可点某一档，只看这一档的宫殿）；
- 再是搜索框 +「全部收起」，下面是同一种树，只是不再显示学科那一层，章节默认全部展开；
- 如果选了某一档，会出现一条提示「下方只显示这一档的 N 座宫殿」，可一键查看全部。

### 3.4 状态页

书架/列表都有三种兜底：骨架屏（加载）、错误卡（带重新加载）、空状态（引导创建第一个宫殿）。它们都占据主体位置，不会让页面只剩一片白。

## 4. 宫殿详情页（脑图页）

从书架点宫殿标题进入，这里是**只读**脑图。

### 4.1 页面结构

- **顶部紧凑页头**：`宫殿详情` 小字 + 宫殿标题 + 一个「只读脑图」徽标；右侧是收起按钮，可以把页头压成一条细条，把高度让给画布。
- **右侧信息栏**（可以拖动宽度、可以收起）：
  - 概要：宫殿描述；
  - 关联章节：章节名 + 所属学科；
  - 附件：点开新窗口查看。
- **左侧画布**：整块铺满剩余空间，画布工具栏在顶部。

### 4.2 画布工具栏

从左到右是通用画布能力（适应整树、展开/折叠、缩放等），右侧是业务动作：

- **做题**：进入这座宫殿的做题页；
- **半屏编辑**（桌面）：把画布切到半屏编辑态；
- **全屏编辑**：进入系统/视口全屏；
- **清屏**：隐藏画布上的浮动 UI，只看图。

进入全屏后，页头和右侧信息栏都会消失，退出全屏再回来。

### 4.3 手机上的变化

- 右侧信息栏不再是「挤占宽度」，而是**浮在画布之上**；打开时后面有一层半透明遮罩，点遮罩或收起按钮关闭；
- 画布允许单指拖动，缩放用双指；翻页不靠画布手势，靠右侧翻页器。

## 5. 宫殿编辑页（脑图页）

这是「大改结构」的地方，布局和详情页相似，但左侧多一个目录栏。

### 5.1 页面结构

1. **紧凑、可收起的页头**：宫殿标题；右侧是「从模板创建」「存为模板」、保存状态徽标（保存中/已保存/未保存/保存失败）。
2. **错误横幅**：加载失败、自动保存失败会紧贴页头下方出现，写明「内容会保留并稍后重试」，不会把你踢出页面。
3. **左右分栏**：
   - **左栏**（可拖动宽度、可收起）：
     - 顶部是**「单元评分」入口**；
     - 下面是**宫殿目录树**，可以在宫殿之间切换、查看结构；
   - **右栏**：整块画布卡片。
4. **画布顶部**在「学习」模式下会出现三张入口卡：
   - **主动回忆**：连续揭示并回忆整张脑图；
   - **开始随心复习**：带着这座宫殿进入随心；
   - **做题训练**：进入这座宫殿的做题页。
5. **画布工具栏**：文字、永久标记、更多；永久标记打开时显示「已标 N」，点节点即保存。
6. **导入抽屉**：「文字转脑图」等导入从侧边滑出，先预览、再确认应用到画布。

### 5.2 全屏

点「全屏编辑」后：

- 页头、左栏、错误横幅全部让位；
- 画布铺满整个窗口；
- 退出全屏回到原来的分栏宽度和位置。

### 5.3 冲突与保存

- 两台设备改同一座宫殿时，会弹**文档冲突对话框**，把本地和远端各放一边，必须显式选一个；冲突未解决时画布只读，也不能移动宫殿；
- 自动保存是后台进行的，页头徽标会一直告诉你当前状态；
- 关页/刷新前会把草稿写到本地，下次打开可以恢复。

## 6. 单元评分页（独立标准页，但铺满高度）

从编辑页左栏或宫殿卡片「更多 → 复习进度」进入。

### 6.1 结构

- **顶栏**：`返回编辑` + 标题「单元评分 · 宫殿名」；
- **左右分栏**：
  - **左栏：复习单元列表**
    - 顶部一行「N 个 · 今日到期 N」；
    - 每个单元一行：单元名；下面左边是「今天到期」或「间隔 N 天」，右边是具体日期；
    - 手机上和桌面一样收成抽屉/浮层。
  - **右栏：单元内容**
    - 顶部画布工具栏的中间是**复习等级进度条**，可拖动改档；
    - 下面一行单元标题 + 「当前间隔 · 下次到期 · N 个节点」；
    - 画布只显示这个单元覆盖的节点，其他节点不显示；
    - 底部是**四档评分条**；未到期时按钮禁用，并写明「这张卡 X 月 X 日才到期 · 可在上方进度条调整进度」。

这个页面没有用常规页头，而是自己的一条顶栏——因为它需要把几乎所有高度留给「列表 + 画布 + 评分」。

## 7. 随心页（沉浸页）

随心是唯一一个「一屏一卡」的页面。

### 7.1 滚动方式

- 整个页面是一个**纵向吸附滚动容器**：一次滚一格，松手自动对齐到整张卡；
- 滚动条隐藏；
- 上下相邻的卡片有轻微的**纵深/叠压**效果：下一张在后面稍小、稍暗，翻过去时像纸页压过来；
- 卡片本身不内滚（脑图除外），所以「翻卡」和「翻页」是两件事：卡片内翻节点用回车，卡片之间翻页用滚轮/手势/右侧翻页器。

### 7.2 页眉（HUD）

页眉在文档流里，**不浮在卡片上**，卡片恰好从页眉底边开始。从上到下：

1. **一条 20px 的进度细线**：每个刻度一张卡；已评分实色、未评分淡色、重练是琥珀色圆点；
2. **当前宫殿 + 轮次计数**（如 `29/55`），点击打开「本轮安排」；右侧是「更多」菜单；
3. **一条被截断的里程碑行**：倒计时 + 最近的日子，点击展开全部分组。

页眉会实时测量自己的高度，并把高度告诉下面的所有浮层（顶部通知、未保存提示、清宫横幅、季度标签、边缘提示）。所以换字体、换机型，浮层都不会压住卡片。

### 7.3 卡片内部

从上到下：

1. **画布工具栏**：做题、文字、永久标记、更多；
2. **单元标题行**：宫殿名、单元名、重练徽标等；
3. **脑图/题目**：记忆宫殿卡是整张脑图；做题卡是题干 + 选项/简答；
4. **底部评分条**：忘记 / 困难 / 记得 / 轻松，按钮第二行写清「这一下的后果」。

评分条是**贴底浮层**，不占卡片布局高度；手机上加安全区留白。

### 7.4 右侧翻页器

右边缘、垂直居中一列「玻璃」按钮：

- 最上面是**月亮**（睡前复习）；
- 上一张；
- 下一张；
- 完成（对勾）。

原因：手机单手持机时，拇指就在右侧；如果把它挪到评分条上方，会多出一条横条，还会压住脑图。桌面上保持同一位置，肌肉记忆一致。

### 7.5 浮层与整页覆盖

随心里的「大块内容」不是弹小窗，而是**整页覆盖层**：

- **开始页**：今天的概览 + 昨日回顾 + 「开始学习」；
- **配置预览**：告诉你这一轮会怎么出题，再开始；
- **部分结算**：小结算页，盖住翻页器，但保留可见的「退出」；
- **收尾结算**：本轮结束页，翻页器让位；
- **本轮安排**：从底部升起的抽屉，有「按宫殿 / 按学科 / 按进度」三种看法；
- **本轮配置**：居中大对话框，手机上接近全高，底部按钮固定在安全区上方；
- **历史 / 做题叠加层 / 睡前复习确认**：各自独立浮层。

这些覆盖层都遵守同一条规则：**盖住下面的翻页和快捷键**，避免你在看结算页时按回车又翻了一张卡。

### 7.6 手机上的随心

- 底部标签栏隐藏；
- 页眉两行都留出右上角的通道，给「会话录音」浮标；
- 评分条贴底；
- 翻页器仍在右侧；
- 次级工具（删除、永久移除等）在手机上折叠进「更多」，不会一次铺满评分条上方。

## 8. 做题页（标准页）

### 8.1 宫殿做题页

从上到下：

1. **页头**：`宫殿做题` 小字 + 「宫殿名 · 配套习题」；右侧「查看记忆宫殿」和题数徽标；
2. **页签**：`做题` / `管理`；
3. **做题页签**：
   - 筛选/范围条：按宫殿范围、视图模式、搜索等；
   - 统计/操作行：当前范围题数、清空进度等；
   - **题卡**：题型徽标、绑定知识点、题干、选项或简答输入、提交按钮；
   - 底部：上一题 / 下一题；
   - 选择题即时判对错；简答题提交后显示参考答案与解析；
4. **管理页签**：
   - 批量选择、全选当前范围、批量删除；
   - 新建/编辑表单（题干、选项、答案、解析、绑定节点）；
   - 导入入口；
5. 手机端整体单列，工具栏换行或收进按钮，题卡占主要高度。

### 8.2 随心里的做题叠加层

它**不是**把信息流切成题目队列，而是在当前卡片上开一个对话窗口：

- 首次打开先是一页设置：出题范围（本轮复习单元 / 整个宫殿）、抽取顺序、评分显示、快捷键；
- 之后打开直接进题目；
- 题目上方有题型、绑定知识点、「本轮最低 N」或「本轮尚未复习」徽标；
- 底部是选项/提交和上一题/下一题；
- 对话框打开时，下面的信息流快捷键暂停，↑↓ 不会翻卡。

节点上绑定的题目还有一个小窗版本（从节点菜单打开），布局同理，只是不带整套设置。

## 10. 进度页（标准页，但用了一套自定义排版）

进度页没有用常规的页头卡片，而是自己的一套「学习全景」版式：

1. **页头**：标题「进度」；右侧「刷新」；
2. **概览区**：当前范围的总体指标；
3. **里程碑面板**：考试/目标倒计时；
4. **知识版图工作区**：
   - 左侧是浏览器：面包屑（全部学科 → 学科 → 章节 → 宫殿）、搜索、筛选（全部状态 / 待复习 / 尚未覆盖 / 有未做题目）、排序（知识顺序 / 覆盖从少到多 / 待复习优先）；
   - 视图可切「层级 / 分布 / 题目」；
   - 支持批量展开层级（全部收起 / 展开一级 / 展开两级 / 展开三级）；
   - 行内显示复习进度条和题目进度条；
   - 点某一行进入下一层，右侧显示该范围的明细；
5. 空数据时是一张引导卡「还没有宫殿」，带「前往知识书架」。

配色和全站一致：绿色 = 已复习，琥珀 = 待复习；选中行、按钮、聚焦用主色靛紫。里程碑每行在中等宽度下分两行：第一行日期、标题、分类、完成、删除，第二行提前提醒天数和状态。

它的信息密度比别的页面高，所以在宽屏上会同时显示「浏览器 + 明细」，窄屏则收成一列。

## 13. 通用版式与交互约定

### 13.1 页头与页面容器

- **常规页头**直接放在页面底色上（不套卡片）：标题、可选说明、右侧动作；标题和按钮同一行，放不下才换行；手机上说明可以隐藏。
- **脑图页的页头**是紧凑版，并且可以**收起成一条细条**，只留标题和一个展开按钮。
- **页面容器**有两档宽度：常规页和宽页；宽页用于书架、列表、洞察这种卡片多的页面。
- 内容间距手机 16px、桌面 24px；同一页里不要混用两套节奏。

### 13.2 卡片与按钮

- 整体是冷灰底 + 靛紫主色，界面本身安静，颜色只留给状态（绿=记得、琥珀=困难/待复习、红=忘记、蓝=新学）。
- 卡片是圆角、浅阴影、细边框；鼠标移上去会轻轻浮起；重要信息用大数字，说明用弱化小字。
- 按钮按下会轻微缩小，用键盘切换时有一圈清楚的主色描边。
- 手机按钮最小 44px；桌面可以到 32px。
- 危险操作（删除宫殿、清空进度、永久移除）一律用**确认对话框**，写清「会发生什么、能不能撤销」；部分操作需要二次按压。
- 空状态、错误状态、加载状态都有固定样式，且都带一个明确的下一步动作（重新加载 / 创建 / 返回）。

### 13.3 浮动层

- **桌面对话框**：居中浮层，长内容内部滚动，底部按钮固定；部分对话框会记住你上次拖出的宽高比例。
- **手机全高面板**：标题和主按钮固定，只有中间滚；顶部/底部避开安全区。
- **手机底部抽屉**：从下方滑出，最高约 85% 屏高，适合选择、安排、更多入口。
- **侧边抽屉**：日志、导入、历史等从右侧或左侧滑出，不打断当前页面。
- 任何浮层打开时，下面的页面快捷键暂停；关闭后焦点回到触发按钮。

### 13.4 键盘与手感

- `Ctrl/Cmd + K` 打开命令面板；`?` 打开快捷键说明；`Ctrl + N` 新建宫殿；`/` 直接搜宫殿。
- 随心/复习里：回车翻卡、退格收卡、↑↓ 翻页、WASD 平移画布；**空格不再翻页**，留给卡片内输入。
- 编辑器打开时，所有学习快捷键让路。
- 反馈只有三种：声音、触感、CSS 果冻动效；没有粒子、没有全屏特效；系统开启「减少动态效果」时会收敛。
- 翻卡有「墨迹先行 → 弹簧回弹 → 落地压一下」的手感；收卡时子卡被父卡吸回并缩小淡出，整批有节流，不会一次爆开。

### 13.5 布局的几条硬规则

1. **卡片从页眉底边开始**，页眉高度是唯一偏移来源，不允许用魔法数字留白；
2. **画布就是这一页**：脑图页不加圆角、不加外投影，工具栏和评分条浮在画布上，不在画布外留一条异色底；
3. **手机上内容优先**：题目/脑图/列表至少占 2/3，工具收进「更多」或折叠；
4. **翻页器固定在右侧**，手机和桌面同一位置；
5. **沉浸页不显示底部导航**，避免和评分条抢底部空间；
6. **全屏时页头、侧栏、错误横幅全部让位**，只留画布或卡片；
7. **浮层不改变后面的布局**，只覆盖；关闭后页面位置不变。

## 15. 一句话记住每个页面的「重心」

- **书架**：重心是「书」——学科颜色、封面、多少宫殿/章节；
- **宫殿详情**：重心是「图」——信息栏只是补充，画布才是主角；
- **编辑页**：重心是「左目录 + 右画布」——改结构时不用来回跳页；
- **单元评分**：重心是「一个单元」——左选单元，右只看这个单元，底部直接评；
- **随心**：重心是「当前这张卡」——页眉告诉你在哪，评分条告诉你能做什么；
- **做题**：重心是「当前这道题」——筛选和统计都在题卡外围，不抢注意力；
- **进度/洞察**：重心是「全局」——用层级、颜色和数字让你知道下一步该去哪。
