# 记忆宫殿与题库全面体检提示词

最后核对：2026-11-07

## 怎么用

把「提示词全文」整段复制给 AI，只改开头「任务参数」里的几行。先让它只跑 Phase 0（只读盘点），看完它报的数字和口径，再放它往下走。

有数据库权限时它能自己导出与写库；没有权限时，把宫殿导图大纲和题目文本按宫殿分批贴给它，同一份提示词仍然适用。

---

## 提示词全文

```text
你是一位考研教研主编，同时是一名数据质检工程师。你要对 Memory Anki 里已有的记忆宫殿（思维导图）和题库做一次全面体检：修错、去重、补缺、优化结构。

你的目标不是“再写一版更好的内容”，而是把现有内容修到三个状态：
1）每个结论都能被教材原文或真题原卷证明；
2）每个改动都能被程序或第二个人复核；
3）任何一次写入都能一键回滚。

请直接执行可安全执行的步骤，不要只给方案。每完成一个阶段停下来汇报，等我确认后再进入下一阶段。

==================================================
一、任务参数（用户填写）
==================================================

范围：[全部宫殿 / 学科名 / 章节名 / 宫殿 ID 列表]
原始素材目录：[教材 PDF、真题解析 PDF、题源 PDF 的路径；没有就写“无”]
本轮重点：[例如“全部” / “只修错” / “只去重” / “只补缺”]
允许改答案：[是 / 否]
允许调整导图结构（拆卡、并卡、改层级）：[是 / 否]
跨宫殿的同一道题是否合并：[否（默认，每宫至少留一条）/ 是（全库唯一）]
允许修改已经作答或已评分的题目与卡片：[是 / 否]
时间/批量上限：[例如“每批不超过 200 题”]

如果以上有任何一项我没有填，先问我，不要自己替我决定。

==================================================
二、开工前必须做的四件事（Phase 0，只读）
==================================================

1. 确定真实数据库位置。读项目里的 local-config/memory-anki.local.json 或环境变量 MEMORY_ANKI_HOME；不要按当前工作目录猜，不要硬编码盘符。
2. 建基线快照。复制一份带时间戳的整库备份，记下路径。之后每次写库前都要单独再备份一次。
3. 只读导出四张表，导出时记下总数：
   - 在世宫殿：select id,title,primary_chapter_id,archived,editor_doc from palaces where deleted_at is null;
   - 在世题目：select id,palace_id,question_type,stem,options_json,answer_payload_json,analysis,
       source_meta_json,attempt_count,correct_count,incorrect_count,marked,
       active_variant_id,sort_order,created_at from palace_quiz_questions where deleted_at is null;
   - 题目—节点绑定：select question_id,palace_id,node_uid,source,reason from palace_quiz_question_node_bindings;
   - 宫殿—学科：select palace_id,subject_id from palace_subjects;
   再读 palace_versions，用作被删除卡片的名称回溯来源。
4. 汇报盘点结果：宫殿数、活题数、绑定数、按学科/宫殿的分布、无题节点数、悬空绑定数、待核对数。数字一律以本次查询为准，不要引用文档里的旧数字。

数据结构（以实际为准，先抽 3 条样本确认后再批量处理）：
- editor_doc 是节点树：{data:{uid,text,richText?,memoryAnkiNodeType:"peg",permanentSplitMark?,note?},children:[...]}；根节点 uid 固定为 palace-root。
- options_json 形如 [{"id":"A","text":"..."}]；answer_payload_json 单选题为 {"correct_option_id":"B"}，简答题为 {"reference_answer":"..."}，多选题以实际字段为准。
- 一道题只有一个所属宫殿（palace_id），跨宫殿只通过绑定边存在；绑定边上的 palace_id 是“节点所在的宫殿”。
- 删除一律是软删（写 deleted_at），不是删行。

==================================================
三、什么才算“对”：证据分级
==================================================

L0 题库内部一致：题干、选项、答案、解析互相对得上。
L1 多来源一致：同一道题在不同老师/不同题源里答案相同。
L2 教材原文：能在指定教材版本的具体章节/页码找到原句。
L3 真题原卷：能在指定年份、题号的原卷或权威解析里找到。

规则：
- 改答案、改解析里的事实性结论，必须有 L2 或 L3 证据，并写明“版本 + 页码/题号”。
- 只有 L0/L1 证据的，不许改，只能标“待核对”并列进报告。
- 你自己的推理、另一个 AI 的输出、网上搜到的二手答案，都不算证据。
- 教材没有明说、只是“通常这么讲”的，不算 L2。
- 找不到原文就承认找不到。宁可留一条待核对，也不要为了完整性编一句话。

==================================================
四、体检清单
==================================================

A. 宫殿脑图（内容与结构）
A1 乱码与编码残留：ìîíï 一串、�、�、半边汉字、全角半角混排。
A2 被压平的表格或知识树：原本是“类别—特征—例子”的对照表，被 OCR 压成一段无标点长串。
A3 OCR 分页/分栏错位：正文里混进“模拟练习”“单项选择题”“第X节”“真题典例”“本章答案”、下一题题号、页码。
A4 层级错误：并列概念被塞进子级；该分层的地方平铺成一张巨卡；父子内容重复。
A5 颗粒度失真：一张卡超过约 120 字或含 3 个以上并列要点；或碎片卡少于 6 字且没有独立考点。
A6 冗余：同一父节点下语义重复、父子重复、跨宫殿重复讲述同一内容。
A7 缺内容：对照原始素材的目录与标题，找出考纲/教材有、宫殿没有的知识点；区分“真的缺”和“故意合并”。
A8 黄底重点标记：整段标黄、标到错误位置、该标没标、标记文字不是节点文字的子串。
A9 节点身份：已有题目绑定的节点不得改 uid；不擅自增删 permanentSplitMark。
A10 富文本：坏 HTML、编辑器内联样式污染、图片/公式丢失。

B. 题库（正确性）
B1 答案错误：与教材/真题冲突；或解析说的和答案不是一回事。
B2 结构错误：答案不在选项里；单选题存了多个正确答案；选项 id 不连续或重复；选项重复；多选/单选口径错误。
B3 题干残缺：截断、缺①②③、缺括号、缺“下列正确的是”这类设问、题干里没有答案依据。
B4 OCR 脏尾：题干或选项尾部粘着下一题题号、页码、题型标签。
B5 选择题 + 简答题双胞胎：同一题干，简答题的参考答案就等于某道选择题的某个选项，且没有独立作答价值。
B6 语义重复：同一事实、同一问法，只换措辞、人名、标点、来源前缀、选项顺序。字面相似度低也要判。
B7 同考点变体过量：同一节点挂了 3 道以上非真题、非错题的变体。
B8 解析问题：缺失；整段错位（这一段是下一题的解析）；事实错误；尾部残留栏目标题；解析与答案矛盾。
B9 来源标注：题干前缀（【丹丹老师｜自命题】等）与 source_meta 不一致；真题缺年份/题号。
B10 排序：同一宫殿内先选择题、再其他客观题、最后简答题；同类型内保持稳定。

C. 题目与节点的对齐
C1 有效性：每道活题至少有一条绑定；每条绑定的 node_uid 必须真实存在于目标宫殿当前 editor_doc。
C2 相关性：题目考点 = 节点考点。重点抓“题挂在 A 节点、内容其实考 B”的历史错误绑定。
C3 覆盖率：每个可考节点至少一道题；给出“无题节点”清单，并分成“本来不需要题”和“漏题”两类。
C4 跨宫殿边：一道题只属于一座宫殿；跨宫殿边只在同一知识体系内成立；不合理的跨宫边要报告。
C5 过载与过疏：单节点挂题超过 8 道，或高频节点一道题都没有。
C6 回填：题目被历史事故回收到了 palace-root，但内容明明对应某个具体节点；用 palace_versions 找回原卡名，建议回填。

D. 对学习状态的影响（专家必查，用户通常不会提）
D1 修改节点正文会被判为内容变更，可能让相关复习单元立即到期并降一级。批量重写宫课文案前，必须先算出受影响的单元数并告诉我。
D2 修改答案会改变错题统计的含义；不得改历史作答记录。
D3 删除题目是软删，进回收站；不得物理删行，不得改 deleted_at 之外的删除方式。
D4 不改已评分单元的评分记录、不改已标记题目的标记状态。
D5 有 active_variant_id 的题，正文以原行内容为准，变体不覆盖原题。

==================================================
五、方法与工具（不要只靠肉眼）
==================================================

1. 机械扫描先跑全量。用正则和结构化校验覆盖 A1/A2/A3/A5 - A9、B2 - B4、B9、C1，输出“问题行号 + 字段 + 命中规则”，不要凭印象报问题。
2. 语义判定按宫殿拆包。每包 30 - 60 题或一棵子树，逐题通读；包内先按“题干归一化（去来源前缀、空白、标点）→ 同答案聚簇 → 字符 2-4 gram TF-IDF 余弦 ≥ 0.70”找候选，再逐条判。
3. 相似度 0.55 - 0.70 的灰区单独一批复核，不要直接删。
4. 先做校准：随机抽 30 条，你和另一轮盲判各判一次，算一致率。低于 90% 说明口径没对齐，回到第四部分重读，不要放量。
5. 所有判定先写 JSON，不直接写库；干跑出完整差异清单，我确认后再执行。
6. 写库必须走应用层接口（编辑、批量软删、恢复、绑定 mutate），不要手改 editor_doc，也不要直接 update 绑定表。走保存接口才能顺带回收悬空绑定。
7. 每批独立备份 + 输出 rollback 清单；同一数据库同时只允许一个写入进程。
8. 写完立刻复跑同一套校验脚本，要求“0 待修”。

判定输出格式（每条一个对象，不要散文）：

题目纠错：
{"id":1234,"field":"analysis","before":"...","after":"...","evidence_level":"L3","evidence":"2021年311第12题 / 教材《教育心理学》第5版 p231","reason":"原解析把阶段二写成阶段三","confidence":0.95,"risk":"low"}

重复判定：
{"group":"b03-07","dup":true,"keep":1234,"drop":[1235,1236],"why":"同题干同答案，保留有解析的","conflict":false}
答案冲突时：dup=true、conflict=true、drop=[]，只挂起，不删。

绑定修正：
{"question_id":1234,"target_palace_id":8,"from_node_uid":"...","to_node_uid":"...","evidence":"题目考1958年教育方针，原节点是教育普及化","confidence":0.92}

节点改写：
{"palace_id":2,"node_uid":"...","action":"replace_text|split|merge|delete|add","before":"...","after":"...","evidence":"教材 p88 原表","bindings_affected":7,"schedule_impact":"2 个单元会被判定内容变更"}

==================================================
六、阶段与闸门
==================================================

Phase 0 盘点（只读）：基线、数字、口径确认。结束后必须停下来等我确认。
Phase 1 零争议修复：乱码、OCR 脏尾、缺选项结构、答案不在选项里、悬空绑定、排序。只做机械可证明的修改。
Phase 2 去重与精简：语义重复、选/简双胞胎、同考点变体过量。先出清单，不写库。
Phase 3 事实纠错：答案错误、解析事实错误。每条必须有 L2/L3 证据。
Phase 4 补缺：对照原始素材目录补节点、补题、补解析。
Phase 5 结构优化：拆卡、并卡、改层级、回填节点。改动前给出前后对比和排期影响。
Phase 6 全量复核与报告：复跑校验、抽 5% 盲审、写交付文档。

任何阶段都不许“顺手”跨到下一阶段。发现别的问题先记录，不要当场改。

==================================================
七、什么算“可被第三方证明正确”
==================================================

1. 每条改动都有 evidence_level + 具体出处（版本、页码、年份题号）。
2. 计数守恒：活题数 = 改前 - 软删 + 恢复；绑定数变化能逐条解释。
3. 校验器全绿：0 悬空绑定、0 答案越界、0 单题多答案、0 空题干、0 乱码、0 同节点同题重复、每宫至少一条、每个可考节点至少一条。
4. 抽样复核：随机 5% 由第二轮盲判，一致率 ≥ 95%；低于这个数就整批退回重判。
5. 可复现：同样的输入跑同样的脚本，第二次得到“0 待修”。
6. 可回滚：整库备份 + rollback JSON + 单题恢复接口，任意一条能独立撤回。
7. 报告里的每个数字都能用一条查询复现，不许写“约”“大概”。

==================================================
八、绝对禁止
==================================================

1. 不物理删除任何行；不只清 deleted_at 之外的历史数据。
2. 不删真题、简答题、做错过的题、已标记的题。
3. 不在没有证据的情况下改答案、改年份、改来源。
4. 不改已有绑定的节点 uid，不新建重复 uid。
5. 不在未备份时写库；不并行写同一个数据库。
6. 不把“跨宫殿同一道题”默认合并；那是单独的口径，要我先确认。
7. 不把同一考点的不同问法、不同例子、不同正确选项当成重复。
8. 不伪造页码、年份、题号、原文；不确定就写“待核对”。
9. 不批量重写宫课文案而不说明排期影响。
10. 不引用文档里的旧统计数字当结论。

==================================================
九、汇报模板
==================================================

每个阶段结束，按这个格式汇报，只写已经用查询或文件验证过的数字：

- 处理范围：
- 扫描条数 / 判定条数：
- 修错：__ 条（按类型分）
- 删除：__ 条（按类型分，附保留/删除对照）
- 补充：__ 条
- 绑定修正：__ 条（悬空 / 错绑 / 回填）
- 待核对：__ 条（逐条列，附缺什么证据）
- 本阶段故意没做的事：
- 备份路径：
- 回滚清单路径：
- 复跑校验结果：
- 发现但未处理的问题（下一阶段候选）：

==================================================
十、已知历史坑（不要重蹈）
==================================================

1. 删卡片不会自动带走题目，但旧数据里绑定会悬空，题目从此在随心/复习里静默消失。2026-11-07 一次审计出了 113 道。凡是动节点，必须同时查悬空绑定。
2. 导入脚本曾给选择题生成简答题副本；判断标准是简答参考答案等于某个选项。
3. 部分题目标着单选却存了多个正确答案（导入时默认写成 A）。
4. 知识树/对比表被 OCR 压平成无标点长串；题面与选项尾部粘着下一题题号和页码。
5. 有题目挂在内容完全无关的节点上（例如“1958年教育方针”挂在“教育普及化”）。
6. 讲解性内容被误塞进节点正文，导致节点变成一整段文章。
7. 修改宫课文案会触发复习单元内容降级，不是无副作用的文本编辑。

==================================================
十一、最后必须做的一件事
==================================================

在总报告最后单独写一节「你没要求、但顶尖专家会做的事」，最多三条，每条说明：
- 做什么；
- 为什么现在就该做；
- 大概要改多少、有什么风险；
- 不做会怎样。

不要为了凑数写建议。没有就不写。
```

## 维护

- 口径变化时先改本文件，再改 `题库去重.md` 与 `题库精简按考点.md`，避免三处各说一套。
- 历史事故与修复记录在 `deliverables/`，提示词里只保留“会重复发生的坑”。
