# Memory Anki 用户视角介绍

> 面向产品体验者。不出现代码、表名和接口名。
> 想先看评分与间隔规则，可直接跳读《[复习间隔与评分规则（用户视角）](复习排期-用户视角.md)》。
> 最后核对：2026-11-04。

---

## 一、它是什么

Memory Anki 是一个**自用的本地学习产品**，把三件事拧在一起：

1. **记忆宫殿**：把教材、考点整理成一张张可翻的思维导图；
2. **间隔重复**：给导图上勾出来的「复习单元」各自排期，到期才出现在今天的队列里；
3. **做题检验**：宫殿可以挂题库，用选择题、简答题检查自己是不是真的会了。

它不是公开的在线服务，也不做多账号。它运行在你自己的两台 Windows 电脑上，桌面端和手机 PWA 用的是**同一套界面**，默认打开就是「随心」页面。数据放在本机的同步文件夹里，跨设备由应用之外的同步工具搬运；同一时间只让一台设备写数据。

一句话概括日常用法：

> **整理宫殿 → 勾出复习单元 → 每天打开随心，翻卡、评分 → 到期的自动回来 → 做题查漏 → 看进度。**

## 二、先认识几个名词

| 名词 | 在人话里是什么意思 |
|---|---|
| **学科** | 最顶层分类，比如「教育学」「政治」。一座宫殿可以属于多个学科，但只有一个主学科。 |
| **章节** | 学科下面的分组，可以一层套一层。宫殿挂在章节下。 |
| **宫殿** | 一张完整的思维导图，也就是一个知识主题。它是学习的基本单位。 |
| **节点** | 导图上的一张卡片。一张卡可以有子卡，也可以有正文、图片、公式。 |
| **永久标记** | 你在节点上钉下的「这一段要长期复习」。钉了标记，这一段才会变成复习单元。 |
| **复习单元** | 由永久标记划分出来的一段内容（含它下游的子卡）。**评分只作用于复习单元，题目不能评分。** |
| **整宫** | 在宫殿根节点钉永久标记后，整座宫殿作为一个复习单元参与排期和评分。 |
| **题** | 绑在节点上的练习题。界面统一叫「题」。 |
| **学习日** | 以**凌晨 3 点**为界。0:00–3:00 做的复习算「昨天」，这样熬夜复习不会被拆成两天。 |
| **到期** | 每个复习单元身上记着一个「下次该复习的日期」。到期日不晚于今天的单元，才会进今天的队列。 |

「今天有多少张卡」= 今天到期的单元 + 今天该第一次学的单元。系统**没有每日限额，也不分批释放**；顺序固定为「先新学，再到期」，宫殿内可以按知识结构或随机，宫殿之间可以一座刷完再下一座、轮流交错或考试优先。

## 三、主线闭环

```text
新建/导入宫殿
   ↓
编辑整理结构、写内容
   ↓
给要长期记的节点打「永久标记」 → 生成复习单元
   ↓
每天打开「随心」：翻卡回忆 → 四档评分 → 系统按间隔排下一次
   ↓
到期自动回来；忘记的当天重练
   ↓
随时用「做题」检查，看「进度 / 洞察」了解全局
```

## 四、宫殿：知识的基本单位

### 4.1 书架

侧栏「知识」进入书架。书架有两种看法：

- **学科书架**：按学科汇总，显示每个学科里有多少宫殿、多少复习单元、多少立即到期；
- **宫殿列表**：一座宫殿一张卡，可以搜索，也可以切换单列、双列、网格，以及舒展/标准/紧凑三种密度。

每张宫殿卡片上会直接告诉你它现在是什么状态：

- **开始标记**：这座宫殿还没有永久标记，先去编辑页把要复习的段落钉出来；
- **立即复习**：有单元已经到期，点一下直接进入复习；
- **某个日期**：还没到期，按钮上写着下次复习的日子；
- 另外还有「N 个复习单元」「N 个到期」，以及「为什么今天不出现」的说明。

卡片右侧有三个常用动作：**做题**、**编辑**、**更多**（复习进度、删除）；标题旁还有一颗**收藏星标**。

点宫殿标题进入**只读脑图详情**：看整张图、章节归属、附件；也可以从这里直接进做题或全屏编辑。

### 4.2 知识树

「知识树」页面管学科和章节：新增学科、建章节、把宫殿归到章节下。它和宫殿是两份独立文档，切换时会先保存当前这份。

### 4.3 复习单元是怎么来的

你不需要手动画「卡」。做法是：

1. 在宫殿里找到要长期记住的那一段；
2. 打开「永久标记」，点节点上的图钉；
3. 这一段（连同它下面的子卡）就成为一个复习单元，开始有自己的排期。

同一段内容改文字、加子卡，**不会**重置已经获得的到期日和记忆评估；删掉标记也不会把进度清零，重新钉回来还是原来那一行进度。

根节点也可以钉永久标记：它会显示「整宫」徽章，表示**整座宫殿作为一个复习单元**参与排期和评分；在记忆查找里可以直接给这个宫殿级单元评分。

## 五、编辑模式

编辑有两个入口，分别对应「大改结构」和「边学边改」。

### 5.1 宫殿编辑页（大改）

从书架点铅笔，或从「创建」进入。页面通常是三块：

- **左侧目录**：学科 → 章节 → 宫殿的目录树，可以直接切换宫殿（保留展开位置和滚动），也可以切到这座宫殿的节点目录；
- **中间画布**：思维导图本体，可缩放、拖拽、折叠分支；
- **工具栏**：文字、永久标记、更多，以及全屏/半屏切换。

在这里可以做的事：

- 增删改节点、拖动子树、折叠/展开分支；
- 给文字加**黄色重点底纹**（知识重点，不是教材下划线）；
- 开关**永久标记**，工具栏会显示「已标 N」；
- **学习组**：把若干节点圈成一个局部范围，作为内容分组，方便局部查看和管理；
- **单元评分**：左侧目录上方有入口，标完标记后可以直接给这座宫殿的复习单元评分，不用绕回随心；
- **开始随心复习**：带着这座宫殿进入随心；
- **做题训练**：带着这座宫殿进入做题；
- **从模板创建 / 存为模板**：常用的宫殿骨架可以复用；
- **文字转脑图**：把手写的 JSON 结构一次性变成导图；
- **版本与恢复点**：每隔几分钟留一个版本，改坏了可以回看、恢复。

保存是自动的：

- 每次完整动作（加卡、删卡、改文字、切标记）都会立刻保存，没有「保存」按钮要你按；
- 页面会显示「保存中 / 已保存 / 保存失败，重试」；
- 编辑内容会先写一份本地草稿，关页、刷新后可以恢复；
- 两台设备同时改同一座宫殿会触发冲突提示，让你选保留哪边，不会悄悄覆盖；
- 冲突没解决前，不允许把宫殿移到别的学科。

### 5.2 随心里的内联编辑（边学边改）

在随心卡片上**双击节点**（或双击空白画布）就进入编辑，再双击回到复习。它和编辑页共用同一份文档，但更轻：

- **进入编辑范围**可选「当前专线」或「整座宫殿」：默认只打开你正在复习的这一条线，不把整棵树摊开；
- **翻卡进度会保留**：编辑时已经翻开的枝干保持打开，没翻到的分支仍然折叠；
- 清空一张卡的全部文字（全选剪切，或删光后提交）等于**删除这张卡**，子卡会上提，可以撤销；根卡不能清空；
- 永久标记在编辑模式里是一个独立开关，点一下就保存；
- 编辑会话打开时，空格、回车、上下键这些学习快捷键会让路，避免打字时误翻卡；
- 返回学习时先显示本地内容，再在后台和复习进度对账，不会卡在白屏上。

## 六、随心模式：每天的主入口

随心是唯一的沉浸式学习界面，也是默认首页。

### 6.1 开始页

每天第一次打开，先看到一页概览：

- **待复习**：多少座宫殿、多少个复习单元；
- **第一次学**：今天还没学过的新单元；
- **近期里程碑**：最近的考试/目标倒计时；
- **昨天的回顾**：昨天学了几个宫殿/单元，以及昨天比较薄弱的单元；
- 底部一个「**开始学习**」。没有到期内容时，按钮会直接写「暂无需要学习的内容」。

概览只是参考，读失败也不会挡住学习，页面上仍然有「直接开始学习」。

### 6.2 一轮怎么配

点「开始学习」后（或在「本轮安排 → 调整配置」里），先决定这一轮练什么：

| 设置 | 选项 |
|---|---|
| **训练方向** | 记忆宫殿（翻节点回忆结构）/ 做题（只出题）/ 混合模式（两者按比例组合） |
| **学科** | 多选，或全选。不选等于所有学科 |
| **宫殿范围** | 只挑几座宫殿，或按学科全部 |
| **宫殿顺序** | 一座刷完再下一座 / 多宫殿轮流交错 / 考试优先 |
| **单元顺序** | 按知识结构 / 随机打乱；新学与到期是固定的「先新学，再到期」 |
| **混合比例** | 比如记忆宫殿 : 做题 = 2 : 1，或先刷完一边再进另一边 |
| **刷题怎么出** | 出题范围（本轮单元 / 整宫）和抽取顺序（优先新学 / 随机）；题型等细化在「做题」叠加层里选 |

保存配置时，如果这一轮已经有进度，会问你：

- **保留** → 继续这一轮，只重排还没开始的卡片；
- **不保留** → 开一轮全新的，旧进度不带过来。

### 6.3 一轮里的界面

从上到下：

1. **顶部细进度线**：每个刻度是一张卡；已评分填实色，未评分是淡色；重练卡是带「第几次」的小圆点，颜色沿用源卡（新学蓝 / 复习琥珀）；关联题答错的单元刻度会变红，题目改对后立即消失，全部答对则变绿；
2. **宫殿与轮次**：例如 `29/55`，点它是「本轮安排」；
3. **里程碑条**：倒计时和最近的日子；
4. **卡片**：工具栏 → 单元标题 → 脑图；
5. **底部评分条**：忘记 / 困难 / 记得 / 轻松；
6. **右侧翻页器**：上一张、下一张、完成；
7. **右侧月亮**：睡前复习。
8. **最底下一条小城（地平线）**：今天这座岛。今天评过分的每座宫殿是一栋楼，一张卡一扇窗，评过就亮，越熟越亮；忘记的楼门口立一块「待修」牌，不拆楼；一座宫殿的卡今天全评过一遍，屋顶变金色。宫殿查看、编辑、复习页和知识树底部也有这一条，当前宫殿居中插小旗。它自己占一行高度，不盖住内容，也不响应点击和按键；打字时会自动淡出。

一轮里会出现四种卡：**复习单元卡**（脑图 + 评分）、**做题卡**（只判对错，不改排期）、**重练卡**（琥珀色，角标是本轮第几次重练）、**睡前复习卡**（进度条上有月亮标记）。

卡片上方还有「更多」：更新队列、同步进度（换设备后把这一轮接上）、历史、返回书架、切换模块。

**本轮安排**可以按「进度」或「按宫殿」看同一批卡：点刻度跳到那张卡，拖动（手机是上移/下移）调整顺序，批量跳过/恢复，或重置本轮。

### 6.4 一轮怎么结束

右侧「完成」按钮永远只做两件事之一：

- 跳到**最早还没评分**的单元；如果已经在未评分卡上，就走到下一张未评分，到末尾回绕；
- 全部评完了，就打开**结算**。

结算分两级：

- **小结算**（工具栏「结算已完成单元」）：把已经处理完的分组从信息流、进度条和本轮安排里收掉，分母变小，但这一轮还能继续；
- **大结算**（收尾页）：本轮真正结束后出现，显示本轮通过/新学/重练、今日清空的宫殿、宫殿总进度，以及按学科展开的明细。底部是「**结算**」。

「结算」会按当前配置直接开启下一轮全新的队列，不会把上一轮的评分带过去；如果今天已经没有内容，就回到开始页。

## 七、翻卡：随心模式的核心动作

记忆宫殿不是「看一遍」，而是**先回忆，再翻开对答案**。

### 7.1 一张卡长什么样

- 默认只显示节点标题，子卡是折叠的；
- 你按「翻卡」（默认回车），当前卡翻出内容，子卡按层级逐张翻出；
- 再按「收卡」（默认退格），子卡收回去，回到「还没回忆」的状态；
- 鼠标点节点也能翻；鼠标点卡**不会**移动视野，只有键盘翻卡才会自动把翻出的卡挪进视野（可在设置里关掉「翻卡镜头追踪」）。
- 单元标题旁有一个 `已翻/需翻` 徽标：只统计本单元的成员节点和锚点，0 张红色、部分黄色、全翻完绿色；它回答「这个单元翻到哪了」，不是「记住了多少」。

### 7.2 六项可调设置

「翻卡设置」里可以调：

| 设置 | 含义 |
|---|---|
| **翻卡颗粒度** | 逐张翻，或同一层批量翻 |
| **揭示方式** | **两阶段**：先出「待回忆」占位，再翻出内容；**直接显示**：一次出内容（适合只是阅读/对照） |
| **可翻范围** | 「专线模式」只翻当前复习单元这条线；「随心模式」可以翻整座宫殿 |
| **进入编辑范围** | 双击进编辑时，只打开当前专线，还是整座宫殿 |
| **翻卡镜头追踪** | 翻出的卡自动移入视野，或视角保持不动 |
| **评分后自动翻页** | 默认关：评完停在原卡，留出改判时间；打开则评完自动跳到最早未评分的单元 |

快捷键也可以整套改：翻卡、收卡、上一张/下一张、评分；**空格被明确留给卡片内输入，不再翻页**；W / A / S / D 是固定的视图平移键，不参与翻卡。

### 7.3 翻卡和评分的关系

翻卡只是「看」，**评分才写进度**。你可以翻很多张、来回跳，未评分的单元不会因此算完成。评分的四档是：

- **忘记**、**困难**、**记得**、**轻松**。

一次评分只作用于**当前这一个复习单元**；不会顺手把兄弟单元也标成通过。

## 八、评分与排期

### 8.1 四个按钮按下会发生什么

| 按钮 | 含义 | 结果 |
|---|---|---|
| **忘记** | 完全没想起来 | 当天重练：10 分钟 → 1 小时 → 3 小时，最多 3 次；之后排明天 |
| **困难** | 想起来了但很吃力 | **算通过**，但下次间隔只会缩短或持平（上一次的 0.8–1.0 倍） |
| **记得** | 正常通过 | 按定锚期或算法排到未来 |
| **轻松** | 太简单 | 定锚期直接毕业；以后的间隔可以放得更长 |

几条硬规则：

1. 任何「通过」都不会留在今天；只有第一次学会后的 **20 分钟复查** 是例外；
2. 「困难」绝**不会**把卡排得更远；
3. **提前复习不改期**：还没到期就评分，只记录这次评分，到期日和记忆评估都不动，按钮上会写「记下，不改期」；
4. 一天最多重练 3 次，之后排明天。

### 8.2 新卡的两段定锚

- 第一次学：点记得/困难 → **20 分钟后**复查一次；
- 20 分钟后复查：点记得/困难 → **明天**（第 2 天隔夜检验）；
- 第 2 天：点记得 → **+3 天**，交给算法；点轻松 → **+5 天**；点困难 → 明天再检验一次。

之后交给受控 FSRS：目标记忆率 90%，FSRS 基准最长间隔 365 天，叠加 ±5% 抖动后实际最多约 383 天；间隔 ≥7 天会加一点随机抖动，避免一堆卡永远同一天到期。

### 8.3 按钮上写清了「下一步」

评分按钮的第二行会直接告诉你这一下的后果，例如：

- `3天后复习 · 10月30日`
- `10 分钟后重练 · 今天`
- `20 分钟后回顾一次 · 今天`
- `记下，不改期 · 10月30日`
- `今天已重练 3 次 · 明天再练`

评完还会有一个轻提示，例如 `7d后`、`间隔 3d → 7d`、`直推 5d 后`、`记下，不改期`、`已记录`、`今日已重练 3 次 · 明天再练`。

### 8.4 改分、撤销、手动调期

- 同一张卡在离开前再点另一个按钮，是**整体替换**，不是叠加两次；
- 再次点击已选中的评分，会把它清回未评分；
- 只能改**最近一次**真实练习；后面已经有新的真实练习，就只能只读回看；并且只允许改**当前这次还没结束的回忆**，或**今天刚结束的最近一次**——昨天的评分不能再改；
- 「本轮安排」和进度条上可以**移除本队列**（这一轮不练了，不改排期）或**永久移除**（以后不再安排）；
- 复习等级进度条可以拖动：从当前等级拖到目标等级，确认后按该等级的名义间隔重新排期（快捷项：明天 / 3 天后 / 7 天后；最长约 383 天）；
- 编辑页的「单元评分」只在单元**到期**时开放评分，但进度条随时可调。

### 8.5 睡前复习

右侧翻页器上方有一个**月亮**。点开它会问：

- 把今天学过的**每座宫殿各一张卡**追加到本轮末尾；
- 这些评分只记在本轮记录里，**不写复习账本、不改到期日、不改记忆评估**；
- 过了凌晨 3 点后的下一次进入或重建本轮时清掉（不是到点瞬间消失）。

它的作用是「睡前再整体过一眼」，而不是再算一轮复习。

### 8.6 考试冲刺

在考试面板里设好考期、打开冲刺开关：

- 任何一次复习都**不会被排到考试之后**；
- 该排到很远的卡，会被拉回考前最后一周，并按单元错开；
- 冲刺**只缩短，不延长**；打开时会把已经排到考后的日期一次性拉回来。

## 九、做题

做题和记忆宫殿是**两条独立的证据链**：做题的完成度**不会**改变宫殿复习单元的排期，反过来也一样。

### 9.1 宫殿做题页

从书架卡片的「做题」进入，分「做题 / 管理」两个页签：

- **选择题**：提交后立即判对错，累计答对/答错/作答次数；有多个正确选项时，选完再点提交，按选项集合完全一致判对；
- **简答题**：提交后显示参考答案与解析；
- **打乱**：选项可以手动打乱/恢复；「打乱题库」保证每次点击都换出可见的新顺序，题池不足两题时会明确提示；
- **重新作答**：`Ctrl+Z` 只清当前题的作答和草稿并重新计时，不清累计统计；重答后旧的 AI 点评不会写回；
- **版本与换题**：每道题保留变体历史，可以在题目上查看/切换/删除版本；答得又快又稳时会被自动标记「待换题」（阈值在设置里调），管理面板支持批量换题；
- 每题可以显示它绑定的知识点；没绑定的题会提示你去宫殿里关联；
- 可以给题打**标记**（玫瑰色书签）；
- 「清空进度」只清当前筛选范围内的答题统计，不删题；
- 「管理」页可以手动增删改题，或把题和节点绑定。

### 9.2 随心里的「做题」叠加层

在随心卡片工具栏点「做题」，会在当前卡片上打开一个题目窗口，**不会**把整个信息流换成题目队列。它的默认出题范围很克制：

- **本轮复习单元（默认）**：只出这一轮真正排到的单元，以及从宫殿根到该单元锚点的整条路径上的题；
- **整个宫殿（主动开启）**：这座已排期宫殿里的所有题。

另外可以选：

- 客观题 / 主观题 / 混合；
- 跨宫殿打乱，还是一座宫殿刷完再换；
- 客观主观的先后顺序。

每道题上方会显示它绑定知识点在**本轮**的最弱评分：

- 有 1–4 就显示分数；
- 知识点本轮还没排到，或已经画成完成，就不显示「本轮尚未复习」；
- 点这个徽标可以直接跳到对应宫殿的那个知识点。

作答时题号胶囊和节点绑定点的颜色以**当前答案**为准：答错红色，改对后立即恢复；一个单元的非空绑定题全部答对时单元标绿，红色优先。答错题会让对应复习单元进入「错题优先」，只提前这些单元，不会把整座宫殿都提前。

做题窗口里可以直接改当前题：保存后会清除这道题的旧作答状态，避免旧的「已答对」徽章描述已不存在的文本。

叠加层的答题进度会随本轮保存，刷新、换设备都能接上；开新一轮或结算时，可以按宫殿选择「保留」或「清空」。

## 十、进度、洞察与考试

- **进度**：一张「知识版图」，按学科 → 章节 → 宫殿 → 复习单元 → 题目逐层展开，看每个层级的复习进度和题目进度；可以按「待复习 / 尚未覆盖 / 有未做题目」筛选，按知识顺序、覆盖从少到多、待复习优先排序；
- **洞察（仪表盘）**：分成「考试 / 动态 / 宫殿」三栏——考试今日、倒计时与薄弱项，学习热力图与近期动态，新宫殿概览；桌面宽屏并排显示，手机用分段按钮切换；
- **考试**：设考期、看倒计时、开冲刺；考试面板也负责把复习往考前收。

## 十一、其他日常能力

- **复习提醒**：可以配置提醒时间和 Bark 推送，到点提醒你回来复习；
- **备份**：每天首次启动做一次滚动备份，关键操作前留救援快照，也可以手动整库备份/恢复；宫殿另有版本快照；
- **反馈中心**：页面只保留两段试听、1–3 个音色组成的音色池和全局音量；屏幕微震、分类通道和逐场景音量仍按默认值参与，不再在页面上编辑；会尊重系统的「减少动态效果」；没有粒子或全屏特效；
- **英语**：听力课程（本地字幕导入、听写、单句/连续播放）和完形阅读，另有查词面板；英语练习与宫殿复习是两条独立轨道；
- **搜索**：全局搜索宫殿、节点和题目；
- **侧栏**：分隔线可以拖拽调宽，双击恢复默认；
- **AI 能力集中在设置里**：模型接入、场景模型和提示词仍可配置；**AI 出题、讲解、纠错、自由提问已经关闭**，不会在答题时突然调用模型。

## 十二、一天怎么用（示例）

```text
早上打开 → 随心开始页：待复习 8 座宫殿 / 63 个单元，第一次学 12 个
        → 点「开始学习」
        → 第一张卡：先回忆，回车翻卡，子卡逐张翻开
        → 评「记得」→ 按钮提示「3天后复习 · 11月7日」
        → 某张卡完全想不起来 → 评「忘记」→ 10 分钟后重练
        → 继续翻、继续评；评过的刻度变实色
        → 中途想查漏 → 点「做题」，只做本轮单元相关的题
        → 全部评完 → 「完成」→ 结算页：本轮通过/新学/重练、今日清空的宫殿、学科明细
        → 点「结算」，系统按配置开新的一轮
晚上 → 点月亮「睡前复习」，每座学过的宫殿追加一张卡，只记本轮、不改排期
```

## 十三、几个容易被误解的点

1. **翻卡不等于学会**：翻只是看，评分才推进排期。
2. **做题不等于复习**：做题的对错不会改宫殿的到期日。
3. **「忘记」不是惩罚**：它只是告诉你这张卡今天需要再见几次；薄弱评分不会打断连击，也没有损失机制。
4. **提前评分不改期**：按钮上写「记下，不改期」时，那一评分只留记录。
5. **「今天」到凌晨 3 点才结束**：0:00–3:00 的学习算前一天。
6. **没有每日限额**：今天到期多少就排多少，顺序由「新学优先 + 章节结构」决定。
7. **一轮的进度是服务器账本**：刷新、重启、换设备都不会把已经评过的卡变回未评分；只有结算或你主动清空才会收掉。
8. **编辑不会打乱复习**：改内容、加子卡、删标记都不会重置已经获得的到期日；新内容继承最近祖先的进度。
