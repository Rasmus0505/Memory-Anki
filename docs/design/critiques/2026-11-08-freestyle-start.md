Method: dual-agent (A: design-review · B: detector-browser)

目标：`apps/web/src/modules/practice/ui/freestyle/components/FreestyleStartOverview.tsx` + `ImmersiveFreestylePage.tsx` 的开始浮层。  
证据：两个隔离评估（设计评审 / 检测器 + 浏览器实测），1440×900 与 390×844。  
日期：2026-11-08。

## 设计专属性

构图偏通用：768px 居中栏 + 顶部标题/日期 + 两张卡 + 底部全宽 CTA 的骨架，换掉名词可以套到健身、阅读、财务应用。  
专属的是“导图即复习单元”和“一座宫殿 64 / 复习单元 107”的双粒度口径，但后者只被画成通用 KPI，没有让布局解释“部分复习”。纸墨灯的品牌气质是专属的，构图不是。

## 证据（Assessment B）

- 1440 与 390 均无横向溢出（`scrollWidth === innerWidth`）。
- 浮层内只有两个可聚焦控件：`知道了`（52×24）与 `开始学习`（742×44 / 340×44），均 ≥24px。
- **焦点逃逸**：从浮层第一个控件 Tab 两次后进入 `睡前复习 / 下一张 / 完成` 等被浮层覆盖的控件；浮层没有焦点陷阱。
- **加载态**：首轮 3 秒时移动端 CTA 为 disabled、透明度 0.4；概览落定后才可用。与启发式 #1 相互印证。
- 页面级检测器 29 条：19 条 `text-occlusion` 是浮层遮挡的上下文误报；`dark-glow`（CTA 琥珀投影）字面成立但属于品牌灯色；`low-contrast` 命中的是搜索框 placeholder 3.5:1；`nested-cards` 1 条在评分坞。
- 控制台噪声：每次加载会用客户端生成的 `freestyle-round-<timestamp>` 请求 3 次并得到 400，随后 `/rounds/active` 200。功能不受影响，但错误日志被污染。

## 优先问题

### [P1] 加载态谎报“今天没内容”

`FreestyleStartOverview.tsx` 在 `loading` 时 `hasWork=false`，按钮文案与禁用态直接走空态分支。同步盘慢盘或首次读库时，用户最需要被推动的一刻被告知没事可做。  
修法：`loading` 时显示骨架/“正在读今天的学习记录…”，并保留“直接开始学习”可用。

### [P1] 浮层没有焦点约束

无 `role="dialog"` / `aria-modal`，焦点两次 Tab 后落到被遮住的评分控件。键盘与读屏用户会进入“看不见但能操作”的区域。  
修法：给浮层加 `role="dialog" aria-modal="true" aria-label="今天的学习"`，打开时聚焦第一个控件，Tab 循环在浮层内，Esc 关闭（或明确不提供关闭时去掉可聚焦背景）。

### [P1] 输入框 placeholder 对比度 3.5:1

`Input` 的 `placeholder:text-muted-foreground/80` 把 4.96:1 压到约 3.5:1，低于 WCAG 4.5:1。  
修法：placeholder 用完整 `text-muted-foreground`（4.96:1），不降透明度。

### [P2] “知道了”只是把回顾挪进概览

点击后 `dayRecapOpen=false`，`hideYesterday=false`，概览卡内又渲染一份“昨天的回顾”，并且换成红 pill 的另一种视觉语言。看起来像按钮坏了。  
修法：二选一——彻底隐藏，或让概览卡接管并沿用 recap 的版式。

### [P2] 门先汇报失败，再给动作

首屏上方三分之一是“还比较薄弱 + 忘记 50% ×3”，CTA 在底部；`64/107` 与 CTA 同为琥珀，争同一个焦点。  
修法：先把“今天要做什么 + 开始”立住；回顾压成一行摘要或可展开项。

### [P2] “开始学习”不说明要开始什么

`round.counts.remaining` 只用于 `hasWork`；中途退出再进来仍写“开始学习”，不显示剩余/已做。  
修法：有进行中的轮次时写“继续本轮 · 还剩 N 个单元”。

## 优点

1. 单一主操作，桌面与 390 都成立，没有第二个等权按钮。
2. 衬线 + 等宽数字的诚实统计，双粒度口径表达正确。
3. 错误路径不拦路：概览失败仍可直接开始。

## 次要观察

- 两个指标下重复同一句“宫殿 / 复习单元”；按项目文案法则应只出现一次。
- “知道了”高度 24px，达到 WCAG 2.5.8 最低线，但低于产品承诺的 40px。
- 浅色主题下舞台保持黑，底部城市带是全页饱和度最高的一带，形成第二个视觉落点。
