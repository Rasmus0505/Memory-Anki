# 设计评审：随心复习卡（答题纸）

Method: dual-agent (A: design-review · B: detector-browser)

目标：随心复习卡——顶栏、脑图画布、评分条、右侧翻页器。  
证据：两个隔离评估，1440×900 与 390×844；检测器（源码正则）与浏览器实测。  
日期：2026-11-08。

## 设计专属性

回合轨、重练编号点、预印“N 天后 · 日期”、复习等级星是产品独有的；纸面本身（点阵画布 + 胶囊节点 + 四色评分）仍可套到通用闪卡应用。纸的隐喻此前只落在颜色上，没有落在结构上。

## 当时版本的改动记录（部分外观已撤回）

1. **一张纸**：复习卡的画布、页眉、评分条统一为 `--color-paper-card`；评分条去掉圆角/整圈边框/投影，改成纸上的印刷条（只留顶部发丝线）；翻页器改成贴边的纸签（只留左侧发丝线）。
2. **移除降权**：桌面端“移除本队列 / 永久移除”从与评分同尺寸的按钮降为文字级操作，四档重新成为唯一的主决策。
3. **对比度**：纸面 `text-stage-faint` 从 74% 混合改为完整次级墨；实测里程碑行 2.88:1 → 4.96:1 以上。
4. **模态焦点**：开始闸门补 `focusin` 兜底——焦点一旦逃到浮层外会被拉回“开始学习”。

## 保留的问题

- **四档同时“计算中…”**：这是真实状态（效果未返回），改成单行状态需要改测试与按钮高度，暂保留并记录。
- **HUD 信息量**：44 段彩轨、两行头部、编辑器入口仍然偏多；已缩小收藏星、把编辑场景的紫尾改成朱砂，但未重排结构。
- **翻页器语义**：月亮/上一张/下一张/完成同列；完成会结算，触屏只能靠 aria 解释。未改行为。
- **键盘路径**：桌面从文档起点到评分键约 160 次 Tab（左侧目录在前）。移动端第 16 次到达。未加 skip link。

## 浏览器证据（B）

- 1440 与 390 均无横向溢出。
- 对比度：头部宫殿名 15.97:1；里程碑 4.69:1（其中“2 天后”2.88:1，本轮已修）；单元身份 15.92:1；评分次级行 14.6–14.9:1；翻页图标 8.01:1。
- 触控目标：评分键 171×54 / 86×50；翻页 40×40 / 44×44，均 ≥24。
- 焦点：开始浮层此前无 modal 语义，首次 Tab 即逃逸；本轮已补焦点兜底。
- 控制台：每次进入复现 3 次 `freestyle-round-<timestamp>` 的 400（随后 `/rounds/active` 成功）；数据层噪声，非视觉问题。

## 后续校正（2026-11-08）

用户实际查看后否决了“答题纸”全浅色 chrome：顶栏、评分条、翻页器变浅后，整页层级不清且与原有深色舞台割裂。该方案已撤回；上述纸面统一、低对比度结论仅记录当时提案，不代表当前界面。当前恢复深色顶栏/评分坞/翻页栏与四色评分键，保留浅色脑图画布和紧凑 HUD；以实际运行界面为准。
