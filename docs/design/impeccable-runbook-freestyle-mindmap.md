## 当前有效方向（用户验收后校正）

用户实际查看后明确否决了全浅色的“答题纸”方案：顶栏、评分条、翻页器与浅色画布挤在同一亮度区间，导致界面缺少层次且难以辨认。该 chrome 方案已撤回，不能再作为当前设计依据。

当前方向恢复随心的深色舞台顶栏、深色评分坞、深色右侧翻页栏与四色评分键（忘记红、困难赭、记得绿、轻松蓝）；脑图内容画布仍保持浅色，并以细暗桌面边缘分开。保留已完成的一行紧凑 HUD、进度轨和功能交互，不回滚无关行为。点阵仍用于脑图画布。

## 历史提案与保留改动

### 已撤回：全浅色 chrome

曾将顶栏、评分坞、翻页器与脑图都统一成纸色，并把评分按钮改为纸面标签、卡片边框改为纸线。用户实际查看后反馈层级不清且不如此前配色，现已完整撤回这套 chrome。不要重新加回 `fs-paper-chrome` / `freestyle-pager` 或移除深色评分底。

### 仍保留

- 画布：`.react-flow__pane` 保留 22px 极淡点阵（`--memory-anki-mindmap-dot`）。
- 深色舞台顶栏、评分坞与翻页栏重新承担功能区对比；评分键恢复四色语义和键帽层次。
- 卡片留有细暗色桌面边缘；HUD 保持紧凑单行布局。
- 收藏星、进度轨与交互行为改动继续保留。

### 重要度边框（9）

三颗星的宫殿原本是 2px 金色渐变框；改为 1px，保留“重要的页”这一信号，但不再像贴纸边框。

### 评分条变体（24）

- A 现状：色点 + 名称 + 下次间隔。
- B 墨水印章：只留名称与色块，间隔收进提示——信息不足，否决。
- C 四段连排：一条评分刻度，标签用档位墨色，间隔在第二行。
- 结论：保留 A 的结构（移除按钮与四档同排，手机上还有托盘行），吸收 C 的**档位墨色标签**与更紧的字号层级。

### 修复的运行时问题

- `useDirectQuestionSetQuiz.ts` 从一个不存在的 `palace-quiz/model` 桶导入；改为直接指向 `questionBankOrder` 与 `quizNodeBindingAggregation`（不改变行为，让开发服务器可启动）。
- 同步盘在 03:12–03:14 分批写入 `useImmersiveQueue.ts` / `FreestyleCardArea.tsx`，期间 Vite 读到过半文件并报语法错误；等待同步完成后自行恢复，未回滚。

## HUD 收口（第二轮）

- **一行头**：里程碑不再占第二行，折进唯一的状态行（标题 · 回合数 · 倒计时 · 下一里程碑 · 操作）。头部从约 88px 降到约 44px，每张卡多出 44px 给画布。手机上里程碑隐藏，只保留宫殿、回合数和操作。
- **轨降噪**：非当前 tick 在纸面上下调饱和度到 55%、透明度 78%，只有当前段保持满色；收藏星从“每个单元”改为“每座收藏宫殿的第一格”。
- **倒计时降权**：`距考试 N 天` 从朱砂改为次级墨，日期与“N 天后”保持墨色层级。
- 相关测试同步更新（收藏星数量、头部槽位顺序），732 条随心/考试子集与 2723 条全量均通过。

## 评审与审计结果

- 设计健康分 **26/40**：结构与对比度的问题在本轮修掉；HUD 信息量、键盘路径、翻页语义保留并记录。
- 浏览器实测：1440/390 无横向溢出；评分键与翻页器均 ≥24px；头部/身份行/评分次级行对比度 14.6–16:1。
- 修复：纸面统一（画布/页眉/评分条同一纸色，评分条与翻页器去掉整圈边框与投影）、桌面移除操作降为文字、纸面 faint 文字提到完整次级墨、开始闸门加 `focusin` 兜底。
