# 产品术语（统一口径）

> 界面文字、接口字段注释和文档都以这里为准。改口径时先改这里。

| 术语 | 含义 | 代码里的对应 |
|---|---|---|
| 宫殿 | 知识库里的一张思维导图整体（一个知识主题）。 | `Palace` |
| 章节 | 宫殿的分组，可以嵌套（有子章节），挂在学科下。 | `Chapter`（`parent_id` 形成树） |
| 学科 | 最顶层分类。宫殿可以属于多个学科，但只有一个主学科。 | `Subject` |
| 节点 | 思维导图上的一张卡片，可以有子节点。节点的「题数」包含子节点。 | 思维导图节点（`MindMapNode`） |
| 题 | 绑定在节点上的题目。界面统一叫「题」。 | 绑定题（quiz） |
| 复习单元 | 按「永久标记」划分出的每一个复习单元，也就是随心模式里每次评分的那个单元。**评分只作用于复习单元，题不能评分。** | `ReviewUnitState`（一行一个复习单元） |
| 评分 | 对复习单元的一次打分：1 忘记、2 困难、3 记得、4 轻松。 | `ReviewUnitRatingOperation.rating` |
| 已学 / 第一次学 | 已学 = 该复习单元评过 3 或 4；第一次学 = 尚未评过 3 或 4。 | `ReviewUnitState.has_passed` |
| 待复习 | 复习单元的到期日不晚于今天。 | `ReviewUnitState.due_date <= today` |
| 完成 | 随心卡片上，该复习单元在本轮已评过分。 | 随心单元 encounter 已评分 |

## 数字写法

- 同一格里的两个数字统一写成「宫殿/复习单元」，例如 `5/22` 表示 5 个宫殿、22 个复习单元。
- 进度条长度 = 节点（或宫殿、章节）绑定的题数 ÷ 上一级的题数。分母是整张思维导图、所在章节或学科，而不是复习单元。

## 颜色语义（摘要）

- 类型色：第一次学 = 蓝（`memory-new`），复习 = 琥珀（`memory-medium`）。
- 完成：实色 = 完成，淡色 = 未完成。
- 对错：绿 / 红，只在答题反馈里出现。
- 书架和结算页的进度条填充用中性灰，不占用类型色。
