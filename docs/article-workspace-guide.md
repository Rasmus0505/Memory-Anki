# 文章与思维导图：使用指南

## 阅读与编辑

1. 打开宫殿，在导图上方选择 **文章**。手机默认优先文章（如果本设备已有选择则沿用）。
2. 默认是阅读模式，点击 **编辑文章** 才开始修改。标题就是导图节点，标题下正文随节点一起保存。
3. 点击知识点，编辑标题与正文；用 **新增同级 / 新增下级** 添加结构节点。章节操作可提升/降低层级、移动或删除；也可把标题转为列表项。
4. 正文编辑器支持格式、链接、代码块、表格、图片和公式。在已保存的宫殿中，图片可从文件选择或直接粘贴；支持 PNG/JPEG/GIF/WebP，单图上限 20 MiB。
5. 空段落输入 `#`（最多六个）或列表符号再按空格可创建结构节点。正文中已有的嵌套列表仍属于正文，不会意外拆成一堆节点。
6. **撤销 / 重做** 与导图共用历史；切回 **思维导图** 查看同一文档，不需要执行另一次同步。

## 长文和学习

- **目录** 提供标题/正文搜索及跳转。文章始终展开，用缩进、字号和左侧层级线区分上下级。隐藏回忆内容不会参与搜索泄露答案。
- **字号** 切换阅读大小；**进入全屏 / 退出全屏** 沿用原工作区能力。
- **主动回忆** 遮挡正文，点击揭晓。宿主已有的学习状态、题目和绑定动作会显示在知识点操作区；只读或练习场景不会获得额外编辑权限。
- **定位导图** 返回对应节点。视图切换保留阅读位置；**接续阅读** 恢复服务器或本机暂存的节点与段内位置。
- 视图选择只属于本设备，阅读锚点与文档版本独立保存；阅读不会制造文档编辑历史。

## 导入与导出

在宫殿编辑器的更多操作中打开 **文章导入 / 导出**。

- 普通 Markdown：便于外部阅读、编辑、分享；不能完整表达题目关联。
- 完整 ZIP：包含 Markdown、文档身份、支持的附件与题目/绑定/学习组内容。它不是整库备份，不复制学习历史或调度记录。
- 导入会先预览；可选新建宫殿、插入当前节点、更新原导出宫殿、替换整个宫殿。
- 要可靠更新已有宫殿，请保留完整包身份和唯一 UID 锚点。缺失、重复或冲突时不要靠标题相似度猜测绑定。
- 不支持安全迁移的外链图片、跨宫殿引用或其他关系会明确报错，请先处理，不会静默忽略。

## 保存冲突

遇到旧草稿、远端新版本或并发保存冲突时，系统不直接覆盖。对话框保留本地/远端版本，可下载恢复 JSON，再明确选用某一方；存在真实共同基线且修改不冲突时才允许安全合并。

两台电脑仍使用外部 Syncthing，同步完成后再切换使用。**不要同时在两台电脑上写同一同步 SQLite 数据库。**
