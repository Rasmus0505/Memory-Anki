# 果冻按钮演示

离线打开 `deliverables/peach-jelly.html` 即可体验。页面为单文件实现，样式和脚本内联，不依赖外部库或 CDN。

## 操作

- 鼠标、触屏或键盘（空格 / Enter）按住按钮；按住时间越长，释放回弹越明显。
- 点击右上角“音效”开关，可开启或关闭由 Web Audio API 合成的按压与释放音。
- 状态栏显示 `idle`、`pressing`、`charging`、`releasing`、`settling` 和按住时长。

## 动效与无障碍

动画由 `requestAnimationFrame` 驱动；按压包括下压和横向拉伸，蓄力包含呼吸形变与扩散柔光，释放包含过冲、阻尼余震、涟漪和表面波纹。指针移动会带动镜面高光。

页面响应 `prefers-reduced-motion`：减少动态形变与波纹，保留简化的按压反馈。按钮可通过键盘操作，并显示可见焦点。

## 调参

动画常量集中在 HTML 内联脚本的 `config` 对象中，包括按压时间、蓄力时长、弹簧刚度、阻尼、过冲幅度和波纹时长。
