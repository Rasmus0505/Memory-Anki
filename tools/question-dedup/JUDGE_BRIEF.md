# 重复题判定规则（给判定代理）

你在帮一位考研学生清理题库里的重复题。输入是一批「候选重复簇」，每簇 2 道及以上题目，它们是机器用文字相似度挑出来的，一定会有误报。

## 判定口径

1. **算重复**：同一知识点、同一考法、答案实质相同。措辞不同、选项顺序不同、题干带着不同来源前缀（如【丹丹老师｜自命题】【冬青老师｜333选择题｜2027版】）、标点或繁简差异，都算同一道题。
2. **同一题干 + 选择题 / 简答题两版**：若简答题的参考答案就等于选择题的正确选项（例如选择题答案 A=说服教育法，简答参考答案也是「说服教育法」），视为同一道题，保留信息更全的一条（一般是有选项、有解析、有作答记录的选择题）。
3. **不算重复**（务必保守，宁可不删）：
   - 知识点相同但考查角度不同：一个问「谁提出／哪年」，另一个问「含义／评价／意义／局限」；
   - 同一材料/情境但问题不同（例如同一段案例，一个问用了什么德育方法，一个问体现了什么原则）；
   - 选项不同导致正确答案不同（是两道不同的题）；
   - 一道单选一道多选且选项集合不同；
   - 只是题干里数字、人名、年份不同（是两道变式题，都要留）。
4. **答案冲突**：若两条题实质相同但答案不一致，`conflict=true` 且 `dup=true`、`drop` 为空数组 —— 交人工决定，不要自动删。
5. **保留谁**（当确认重复时）：作答次数多 > 有解析 > 选项更完整 > id 更小（更早导入）。`drop` 是除 `keep` 之外的其余 id。

## 输出

对每个输入组输出一条：

```json
{"g": "b00-03", "dup": true, "keep": 5352, "drop": [5353], "why": "同题干同答案，保留有选项的", "conflict": false}
```

- `dup`：false 时 `keep`/`drop` 可省略，`why` 写一句为什么不是重复。
- `why` ≤ 25 个汉字。
- 只输出 JSON 数组，不要解释文字。

- 每组独立判断，不要跨组推断。
- 只读：不要改数据库，不要改本目录之外的文件。
