# 跨设备同步学习进度

两台设备通过一个 **GitHub 私有仓库** 传递「学习进度快照」。快照只含数据库：宫殿、题库、复习排期、做题与随心记录；PDF 资料和英语视频不随快照走。

- 快照大小：约 **13 MB**（数据库 75 MB 压缩后）
- 同步方向：**一台一台用**。换设备前先上传，到另一台先下载
- 整份替换：下载会用远端快照替换本机学习数据，服务端会先留一份 rescue 备份
- 版本一致：两台设备的程序必须处于同一个数据库版本，否则下载会拒绝导入并提示先更新

## 日常操作

双击项目根目录的三个入口，不用输入菜单编号：

| 文件 | 作用 |
|---|---|
| `上传学习进度.bat` | 离开这台设备前，把本机进度传到远端 |
| `下载学习进度.bat` | 到另一台设备后、开始学习前，取回远端进度 |
| `查看同步状态.bat` | 看双方最新快照与上次同步时间 |

第一次点「上传」时，脚本会询问是否在你的 GitHub 上创建私有仓库 `Memory-Anki-Data`。只有你自己能看见。

## 前提

- 本机 Memory Anki 正在运行（`start-all.bat`）
- GitHub 已登录：在终端运行一次 `gh auth status`，未登录则 `gh auth login`
- 推送认证失败时运行一次 `gh auth setup-git`

## 传输方式

走 GitHub Releases（`api.github.com` / `uploads.github.com`），不依赖 GitHub 网页端口，也不在仓库历史里反复堆二进制。仓库里只有一个发布页 `latest`，挂两个附件：

```
learning-data.zip   学习进度包
snapshot.json       来源设备、时间、校验和、关键表行数
```

上传时覆盖同名附件，所以远端永远只有最新一份。这台网络访问 `github.com:443` 时通时断，但 API 稳定，因此选 Releases 而不是 git push。

## 安全规则

- 远端永远只保留一份快照；上传会覆盖上一份。脚本在覆盖前会检查远端是否比本机上次同步更新，若是则停下来让你先下载。
- 本机在最后一次同步后还有学习记录时，下载会先提醒；确认后才会替换。
- 每次导入前，服务端都会在 `日志缓存/backups/rescue` 留一份可恢复的备份。
- 不要两台设备同时学习。同时学习需要逐条合并，当前版本没有实现。

## 文件

```
tools/cross-device-sync/github-sync.ps1   同步脚本（status / init / push / pull / menu）
上传学习进度.bat / 下载学习进度.bat / 查看同步状态.bat   项目根目录的双击入口
```

同步目录默认 `C:\MemoryAnki\github-sync`，里面有：

```
learning-data.zip        最新下载/导出的快照
snapshot.json            这份快照的元数据
.remote/                 远端元数据缓存
sync-state.json          本机同步水位
```
